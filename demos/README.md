# Demos

Small games and levels made with Heron Brush, each with its maps and an engine project
ready to run. Open a `.map` in Heron Brush to edit it; the build or export script in
each folder writes the engine project again.

| Demo | Engine | What it shows |
| --- | --- | --- |
| [Lantern Lane](lantern_lane/README.md) | Godot, three.js | A fantasy canal quarter touring every FPS-kit entity: portals, doors, lifts, pickups, water |
| [Canal Relay](canal_relay/README.md) | Godot | A three-chapter game built on a custom export profile |
| [Motion Lab](motion_lab/README.md) | Godot | Keyframe-animated platforms, a lift, a rotor and a door |
| [Bevy FPS](bevy_fps/README.md) | Bevy | An exported level with physics, collision and sensors |
| [Water Lab](water_lab/README.md) | Bevy, three.js, Defold, Unity, Flax | Water volumes and their priorities |
| [Relay Yard](relay_yard/README.md) | map only | An industrial yard built from asset-library props |
| [Quake: the lift](quake_libre/README.md) | Quake (LibreQuake) | A door, a button, an ambush, a lift and an exit, compiled with ericw-tools |
| [Hexen II: the keep](hexen2_heron/README.md) | Hexen II (the demo) | A door, a button, an ambush whose lights fade up and an exit, compiled with ericw-tools or Raven's tools |
| Feature Lab | all 14 targets | One station per export feature, for [the feature matrix](../docs/feature-matrix.md) |

Lantern Lane, Motion Lab and Water Lab are also in the editor's welcome window, under
Examples.
