# Water Lab

A small self-authored fixture for Bevy, Three.js, Defold, Unity and Flax water
adapters: a basin floor, a water_volume, a custom class opted into water with a
higher overlap priority and its own material, and an explicitly disabled volume.
The map uses face colours, so no external texture pack is needed.

Open it from the editor's example chooser or export it to one of the five targets.
For native controller checks and setup see [water export](../../docs/water-export.md).
The other engine demos retain their existing game-owned water implementations.
