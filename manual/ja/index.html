    #はじめに

    Heron Brush はブラシベースのレベルエディターです。凸型のブラシでレベルを組み立て、面にペイントやテクスチャーを施し、エンティティを配置し、ドアや足場をアニメーションさせ、結果をゲームエンジンへエクスポートします。内蔵アセット、パラメトリック形状、エンジンのエディターとのライブリンク、共同編集セッション、静止画のレンダリングも備えています。このマニュアルはアプリケーションに同梱されており、オフラインでも読めます。

    macOS では、このマニュアルで Ctrl と書かれている箇所はすべて Cmd でも操作でき、Option は Alt に相当します。

    #ようこそ画面

    マップを開かずに Heron Brush を起動すると、ようこそ画面が開きます。左側には ○○ を続ける（○○ は最後に開いていたマップ）、新しいマップ、既存の .map を開く 参照 に加えて、ゲーム、マニュアル、環境設定 があります。右側には最近使ったマップがサムネイル付きで並び、その下に サンプル があります。星（一覧の先頭に固定）はマップをリストの先頭に固定し、ゴミ箱（ゴミ箱へ移動）はファイルをシステムのゴミ箱へ移すので、あとで復元できます。矢印キーで画面内を移動し、Enter でフォーカス中の項目を開きます。ファイル → ようこそ でいつでもこの画面に戻れます。

    #最初のマップ

    1. ようこそ画面で 新しいマップ を選ぶか、ファイル → 新しいマップ（Ctrl+N）を選びます。
    2. ツールストリップで ブラシツール（B）を選び、2D ビュー内でドラッグして選択中の形状を描きます。別の 2D ビューで奥行きを確認します。
    3. ブラシを選択し、ドラッグして移動します。面 タブでマテリアルや色を設定します。
    4. Ctrl+S でソースマップを保存します。ゲームで使う準備ができたら、ファイル → エクスポート を開き、使用するエンジン向けのシーンを書き出します。

    #ファイルと保存

    .map ファイルが編集用のソースです。こまめに保存してください。エクスポート、ライブリンク、レンダリングがマップを保存してくれることはありません。ファイル → 名前を付けて保存（Ctrl+Shift+S）では、拡張子を省略すると .map が付加されます。ファイル → 保存済みのマップに戻す は、未保存の変更を破棄してファイルを読み込み直します。未保存の変更があるままウィンドウを閉じたり別のマップを開いたりすると、Heron Brush は 保存、破棄、キャンセル のどれにするかを尋ねます。

    保存済みのマップに未保存の変更があるあいだは、10 分ごとに番号付きのバックアップがマップと同じ場所の autosave フォルダーに書き込まれます。新しいものから 50 個のバックアップが保持されます。

    Heron Brush の実行中にマップを開くと、そのマップは実行中のウィンドウに渡され、ウィンドウが前面に出ます。別のウィンドウで開きたい場合は、コマンドラインで --new-instance を指定します（「コマンドライン」を参照）。

    #インターフェース

    メインウィンドウには、メニューを含むタイトルバー、その下のツールストリップ、マップビュー、右側のインスペクター、下端のステータスバーがあります。

    #タイトルバーとメニュー

    タイトルバーには、ロゴ、メニュー、中央のマップ名、ウィンドウボタンが表示されます。macOS では、おなじみの赤・黄・緑のボタンが左端にあります。タイトルバーをドラッグするとウィンドウを移動でき、ダブルクリックすると最大化します。バックグラウンドで何かが動いているときは、バーの右端近くにインジケーターが表示されます。エンジンとのライブリンク、ライブセッション、または MCP 実行中 です。インジケーターをクリックすると、ライブリンクを停止したり、該当するウィンドウを開いたりできます。

    • ファイル：ようこそ、新しいマップ（Ctrl+N）、マップを開く（Ctrl+O）、保存（Ctrl+S）、名前を付けて保存（Ctrl+Shift+S）、保存済みのマップに戻す、エクスポート、画像をレンダリング、プラグイン、環境設定（Ctrl+,）。
    • 編集：元に戻す（Ctrl+Z）、やり直す（Ctrl+Shift+Z）、切り取り、コピー、貼り付け、複製（Ctrl+D）、削除、すべて選択（Ctrl+A）、直前の操作を繰り返す（Ctrl+R）、繰り返し操作の履歴を消去。
    • 表示：3D ビューを別ウィンドウで表示、移動先、グリッドにスナップ（Alt+0）、グリッドを表示（0）、アニメーションをプレビュー、除外した面を表示。
    • 形状：3D テキストを挿入、角を接合、面をパッチに変換、選択範囲をエンティティの外へ移動、リンクグループを同期。
    • アニメーション：キーフレームアニメーション、アニメーションをプレビュー、3D ビューからカメラを配置（Ctrl+Alt+0）。
    • マップ：ポイントファイルを読み込む、ポイントファイルを再読み込み、ポイントファイルを解除、ポータルファイルを読み込む、ポータルファイルを再読み込み、ポータルファイルを解除。マップコンパイラーが書き出したリークの軌跡やポータルを表示します。
    • 共同作業：ライブセッション、エージェント用サーバーを起動 (MCP)。
    • ヘルプ：マニュアル、このアプリについて。

    #ツールストリップ

    ツールストリップにはすべてのツールが並んでいます。最初のグループは常に使うもので、選択、ブラシ、クリップ、頂点、辺、面、回転、拡大縮小です。2 番目のグループには、せん断、組み立て、スイープ、制御点、フィレット、ペイントがあります。ボタンにポインターを合わせると、名前とショートカットが表示されます。アクティブなツールをもう一度クリックすると、選択ツールに戻ります。

    ツールの後には 水平方向に反転 と 垂直方向に反転、続いて 2 つのスイッチがあります。ロック はブラシを移動してもマテリアルのマッピングを保ち、UV はブラシを回転しても保ちます（U で切り替え）。その後にアクティブなツール固有の設定が続きます。ブラシツールでは形状とそのオプション、フィレットツールでは半径・面数・角と 適用 が表示されます。右端には、ツール名、グリッドサイズ（グリッド 16 など。クリックで別のサイズを選択）、そして グリッド設定 メニューがあり、グリッドにスナップ、グリッドを表示、アニメーションをプレビュー、除外した面を表示、キーフレームアニメーションが含まれます。

    #マップビュー

    ビューは 4 つあります。3D ビューと、3 つの平面ビュー、上面 (XY)、正面 (XZ)、側面 (YZ) です。環境設定 → 表示 → レイアウト で、単一ビュー、2 分割、3 分割、4 分割 を選べます。区切り線をドラッグするとペインの大きさを変えられます。ビュー内をクリックすると、そのビューがキーボード入力を受け取ります。Space は一度に 1 つのビューを表示するペインを次のビューに切り替え、Ctrl+Space はキーボード入力を受けているビューを最大化し、もう一度押すとレイアウトを元に戻します。

    どのビューでも、ドラッグせずに右クリックすると、選択範囲とポインター下のオブジェクトに対するコンテキストメニューが開きます。グループ化、レイヤー、リンクグループ、エンティティの作成、ブラシのエンティティへの出し入れ、マテリアル名のコピー、マテリアルブラウザーでの表示などができます。

    #インスペクター

    右側のインスペクターには 4 つのタブがあります。左端をドラッグすると幅を変えられます。

    • マップ（Ctrl+1）：レイヤー、グループ、プラグイン、問題、表示 セクションのフィルター、タグ。
    • エンティティ（Ctrl+2）：エンティティブラウザー、エンティティ定義、選択したエンティティのプロパティ、そしてボタンやトリガーの場合はアニメーショントリガー。
    • 面（Ctrl+3）：UV、マテリアル、色、スイープ、フィレット、パッチ、インセットとベベル。各セクションは折りたためます。
    • アセット：再利用できるブラシモデルのライブラリ。

    Ctrl+5 でインスペクターの表示／非表示を、Ctrl+Alt+T でツールストリップの表示／非表示を切り替えられ、ビューを広く使えます。

    #ステータスバーと出力ペイン

    下端のステータスバーには、エディターの最新のメッセージが表示されます。エラーは赤で表示されます。バーをクリックするか Ctrl+4 を押すと、メッセージの全履歴を表示する出力ペインが開きます。ほとんどのコマンドは、クリップしたブラシの数など、実行した内容をここに報告します。

    #ダイアログと外観

    環境設定、エクスポート、画像をレンダリング などのダイアログは、独立したウィンドウとして開きます。環境設定 → 表示 → 配色 で、デスクトップの設定に従う、ライト、ダーク を選べます。概要ページの パネルの不透明度 (%) を使うと、ビューの上に重なるパネルが半透明になります。ウィンドウのボタンはシステムに合わせたスタイルで描画されます。macOS ではネイティブ、Windows では Windows 11 風、Linux では GNOME 風です。

    #ナビゲーションとキーボード

    #3D ビューでの移動

    右ボタンを押したままドラッグすると周囲を見回せます。中ボタンでドラッグするとパンします。ホイールで前後に移動します。W、A、S、D で前・左・後ろ・右へ飛行し、Q で上昇、X で下降します。Shift を押すと移動幅が大きくなります。環境設定 → マウス で Alt + 中ボタンドラッグでカメラを移動 をオンにすると、Alt と中ボタンで視線方向に沿って移動します。速度、反転、視野角の設定は 環境設定 → マウス にあります。

    #2D ビューでの移動

    中ボタンでドラッグするとパンし、ホイールでポインターを中心にズームします。1 つの平面ビューでパンやズームをすると、他のビューも揃って動きます。この動作は 環境設定 → マウス の 2D ビューを連動 で切り替えます。Ctrl+Alt+Z でズームをリセットし、Ctrl+Shift+U で平面ビューを原点に戻します。

    Ctrl+U で選択範囲をすべてのビューに収めます。表示 → 移動先（Ctrl+Alt+M）では、入力した座標へカメラを移動したり、マップファイルの指定した行にあるものを選択したり、入力した量だけ選択範囲を移動したりできます。

    #グリッドとスナップ

    + と - でグリッドサイズを変更し、数字キー 1～9 で 1～256 単位のサイズを直接選べます。0 または # でグリッドの表示／非表示を切り替え、Alt+0 でスナップのオン／オフを切り替えます。S は選択したブラシの頂点を現在のグリッドにスナップし、Ctrl+Shift+V は整数単位に、Ctrl+Alt+Shift+V はグリッドにスナップします。

    #よく使うショートカット

    • Ctrl+S：マップを保存。Ctrl+Shift+S：名前を付けて保存。
    • Ctrl+Z：元に戻す。Ctrl+Shift+Z または Ctrl+Y：やり直す。
    • Ctrl+C、Ctrl+X、Ctrl+V：コピー、切り取り、貼り付け。貼り付けたオブジェクトはポインターの位置に置かれます。Ctrl+Alt+V では元の座標が保たれます。面を選択している場合、コピーではマテリアルと UV 設定がコピーされます。
    • Ctrl+D：複製。Ctrl+Shift+D：グループのリンク複製。
    • Delete または Backspace：選択範囲を削除。
    • Esc：進行中のドラッグをキャンセルし、アクティブなツール内で 1 段階戻り、選択ツールに戻り、最後に選択を解除します。Shift+Esc で直接選択ツールに戻ります。
    • Ctrl+R：直前の繰り返し可能なコマンドを繰り返す。Ctrl+Shift+R：その履歴を消去。
    • Ctrl+Alt+0 または Ctrl+Alt+Num0：レンダーカメラを 3D ビューの位置に配置。
    • F5：マテリアルを再読み込み。F6：エンティティ定義を再読み込み。

    #選択のショートカット

    • Ctrl+A：すべて選択。頂点・辺・面ツールがアクティブなときは、すべてのハンドルを選択。Ctrl+Shift+A：選択を解除。Ctrl+Alt+A：選択を反転。
    • Ctrl+B：同じエンティティまたはグループ内の他のオブジェクトを選択。
    • Ctrl+T：選択したブラシに接するものをすべて選択。Ctrl+E：ブラシの内側にあるものをすべて選択。Ctrl+Shift+E：ビューの軸方向で、ブラシと同じ列にあるものをすべて選択。これらの操作では、選択に使ったブラシは消費されます。
    • Ctrl+I：選択範囲だけを表示。Ctrl+Alt+I：選択範囲を非表示。Ctrl+Shift+I：すべてを再表示。
    • Ctrl+G：グループ化。Ctrl+Shift+G：グループ解除。

    #変形のショートカット

    • 矢印キーと Page Up / Page Down は、アクティブなビューで指している方向へ選択範囲をグリッド 1 ステップ分移動します。Ctrl を押していると移動しながら複製し、Alt を押していると回転します。
    • Alt+X、Alt+Y、Alt+Z：その軸を中心に 90 度回転。Shift を加えると逆方向。
    • Ctrl+F：ビューの左右方向に反転。Ctrl+Alt+F：上下に反転。Ctrl+Shift+X と Ctrl+Shift+Y は X または Y に沿ってミラーします。
    • Insert：選択範囲の中心にポイントエンティティを配置。
    • Tab：ブラシを選択しているとき、選択 → 頂点 → 辺 → 面 → 選択 の順に切り替え。

    #Blender キーマップ

    環境設定 → キーボード → キー割り当て では、Heron Brush（既定。このマニュアルではこちらを前提にしています）と Blender を選べます。Blender では、G で選択して移動、R で回転、S で拡大縮小、E でスイープ、1、2、3 で頂点・辺・面ツールの選択、K でクリップ、B で選択、A ですべて選択、Alt+A で選択解除、X で削除、Shift+D で複製、H で非表示、Alt+H ですべて表示、Ctrl+Shift+Z でやり直しです。それ以外の操作はどちらも同じです。

    #ブラシとモデリングツール

    ブラシは平面で定義される凸型のソリッドです。1 つのブラシを凹型にしようとするのではなく、複数の単純なブラシを組み合わせて複雑なオブジェクトを作ります。単純な形状で十分な箇所では、ブラシの数を少なく抑えましょう。

    #ブラシの描画

    ブラシツール（B）を選び、ビュー内でドラッグします。ツールストリップに 描画する形状 が表示され、直方体、階段、アーチ、円柱、円錐、回転楕円体 (UV)、回転楕円体 (正二十面体)、3D テキストを挿入 から選べます。Alt+1～Alt+7 で形状を直接選択できます。形状に応じて、ストリップには 中空化 と 厚さ:、階段では 段の高さ: と 方向:、円形の形状では 軸:、側面数: と円の作り方、球では リング数:、正二十面体では 精度: が表示されます。オプションはドラッグする前に設定してください。結果は複数のビューで確認しましょう。

    #選択

    ブラシをクリックすると選択され、Ctrl を押しながらクリックすると選択に追加されます。何もない場所からドラッグすると選択ボックスを描けます。3D ビューでは、Shift を押しながらクリックすると面を 1 つだけ選択し、Ctrl+Shift を押しながらクリックすると面を追加します。選択中のブラシをドラッグすると移動し、未選択のブラシをドラッグすると、そのブラシだけを選択して移動します。

    3D ビューで、選択中のブラシの面を Shift を押しながらドラッグすると押し出せます。別の面を Alt を押しながらクリックすると、選択中の面のマテリアルと配置をその面にコピーします。Alt+Ctrl ではマテリアルだけを、Alt+Shift では回転をコピーします。

    #形状編集ツール

    • 選択（Esc）：選択と移動。
    • 頂点（V）、辺（E）、面（F）：角、辺、面をドラッグします。辺や面の中央から Shift を押しながらドラッグすると、そこに角を追加します。Delete で選んだ角を削除します。
    • 回転（R）、拡大縮小（T）、せん断（G）：ハンドルで選択範囲を変形します。
    • クリップ（C）：2 点または 3 点をクリックして切断面を定義します。Enter で切断し、Ctrl+Enter で残す側を選び、Backspace または Esc で最後の点を取り消します。
    • 組み立て（N）：立体を囲むように点を置き、Enter を押すと、それらの点から凸型のブラシを作成します。Backspace で最後の点を取り消します。
    • スイープ（Y）：後述の「スイープ」を参照。
    • 制御点（P）：パッチの制御グリッドを変形します。
    • フィレット（O）：辺をクリックして丸めるか、各ツールで辺や頂点を選んで Enter を押します。面数を増やすほど滑らかになりますが、ジオメトリも増えます。
    • ペイント（K）：「マテリアルと UV」を参照。

    #ブラシの結合

    • Ctrl+J：選択したブラシを凸包に統合。
    • Ctrl+K：選択したブラシを、接しているブラシから減算。
    • Ctrl+Shift+K：選択範囲を中空化。壁の厚さはグリッド 1 ステップ分。
    • Ctrl+L：選択範囲の交差部分を残す。

    #スイープ、フィレット、パッチ、ベベル

    スイープ は、選択した面からパスに沿ってジオメトリを生成します。面を選択し（スイープツールでは Alt を押しながらクリック）、面タブのスイープセクションで 移動、回転（軸と角度）、拡大縮小、ステップ数、パス（整数 または 自由 の配置、円弧、直線、S 字カーブ）を設定して、スイープ を押します。コントロールの下の行に、作成されるブラシの数が表示されます。

    フィレット セクションでは、選んだ辺を 半径、面、角（留め継ぎ または 丸め）の設定で丸めます。面を 1 にすると面取りになります。

    パッチ には選択したパッチの 列 と 行 が表示され、ボタンで 1 組ずつ追加・削除できます。形状 → 面をパッチに変換（Ctrl+P）で、選択した面からパッチを作成します。

    インセットとベベル は選択した面に作用します。インセット は面を辺から内側に縮め、深さ は面を外側へ（負の値なら内側へ）押し出します。面をベベル は両方を適用します。3 番目のボタンは、深さの符号に応じてパネルを追加するか、くぼみを彫ります。角を接合 は、2 つのブラシを留め継ぎまたは丸めた角で接合するダイアログを、プレビュー付きで開きます。

    #3D テキスト

    形状 → 3D テキストを挿入（ブラシツールの形状リストの最後の項目でもあります）で、テキストからブラシを作成します。フォントは内蔵のポリゴンフォント Heron Block で、角が切り落とされたデザイン、プロポーショナルな字幅、チェコ語のアクセント記号を備えています。小文字は大文字の字形で作られます。テキスト を入力し、高さ（キャップハイト。アクセント記号はその上にはみ出します）と 深さ を設定し、ライブプレビューを確認して 挿入 を押します。

    操作で有効なジオメトリを作れない場合は、寸法を調整するか、元に戻して形状を単純にしてください。

    #マテリアルと UV

    #マテリアルの読み込みと適用

    面タブの マテリアル セクションを開きます。フォルダーを読み込む は画像のフォルダーを、.wad を読み込む はテクスチャーパッケージを追加します。どちらも コレクション の下に表示され、× ボタンで削除できます。マテリアルを絞り込む に入力するとリストを絞り込めます。マテリアルをクリックして現在のマテリアルにし、選択範囲に適用 を押すと、選択中のすべての面に適用されます。選択 には このマテリアルのブラシを選択 と このマテリアルの面を選択 があります。置換 は、マップ全体または選択範囲内だけで、あるマテリアルを別のマテリアルに置き換えます。

    ペイント ツール（K）は、ポインター下の面に現在のマテリアルを適用します。クリックで 1 つの面を、ダブルクリックでブラシ全体をペイントします。Shift を押しながらクリックすると、スポイトのようにその面のマテリアルを現在のマテリアルとして取得します。

    #UV エディター

    面タブの UV セクションには、選択した面のマテリアルと輪郭が表示されます。キャンバス上のマウス操作は次のとおりです。

    • ホイールでポインターを中心にズームします。右ボタンまたは中ボタンでドラッグするとパンします。右ボタンをダブルクリックすると面が再びフレームに収まります。別の面を選択すると自動的にフレームに収まります。
    • 左ドラッグでマテリアルを移動します。面の輪郭はその場に留まります。リングはマッピングを回転し、角のハンドルは拡大縮小し、中央のハンドルはこれらの変形の原点を設定します。
    • タイルの辺を Alt を押しながら左ドラッグするとせん断します。Shift を押しながら中ボタンでドラッグしても同じです。
    • 1 回のドラッグが 1 回の取り消し単位になり、Esc で進行中のドラッグをキャンセルできます。

    キャンバスの下には オフセット、拡大縮小、角度、そしてゲームが使用する場合は コンテンツフラグ、サーフェスフラグ、サーフェス値 があります。ボタンは リセット、ワールド基準にリセット、フィット、左右反転、上下反転、そして 2 つの 90° 回転です。整列 は面のいずれかの辺に沿ってマテリアルを回転させます（もう一度押すと次の辺、Shift を押すと前の辺）。4 つの位置揃えボタンは、マテリアルを辺に寄せます。U にフィット と V にフィット は、面がちょうど整数個のタイルで覆われるように拡大縮小します。もう一度押すと次の個数になり、Ctrl を押したままにするとトリムシートの分割が保たれます。

    #UV のキー操作

    面を選択しているとき、矢印キーでマテリアルを移動し、[ と ] で 15° 回転し、, と . でスケールを半分または 2 倍にし、Ctrl+F と Ctrl+Alt+F で反転し、Shift+R でリセットし、Alt+Shift+R でワールド軸基準にリセットし、Ctrl+Shift+F で各面にフィットさせます。

    ツールストリップの ロック はブラシの移動中にマッピングを保ち、UV（U）はブラシの回転中に保ちます。

    #ツール用マテリアル

    • skip：その面をエンジンへのエクスポートから除外します。
    • clip：目に見えるジオメトリなしでコリジョンを作成します。
    • origin：ブラシエンティティのピボットを示します。

    これらの名前は、エクスポートウィンドウの ツール用マテリアル カードで変更できます。隠れているとわかっている面には skip を使ってください。

    #面をエクスポートから除外する

    面を選択し、UV セクションで エクスポートから面を除外 をオンにします。UV プレビューではオレンジ色の斜線で示されます。マテリアルとペイントは保存されたままで、ブラシは閉じた状態を保ち、編集もできます。エクスポートされる描画用メッシュではその面が省かれますが、コリジョンは残ります。立方体の四角形を 1 つだけ残すと、描画用の三角形は 2 つになります。この機能で面が両面表示になったり、メッシュが結合されたりすることはありません。

    覆われた面を除外 は、静的なブラシで完全に覆われた面をマークします。接している同一の面や、内側に閉じ込められたブラシも対象です。選択したブラシに作用し、何も選択していないときは、表示中でロックされていないワールドジオメトリ全体に作用します。ブラシエンティティ、透明なマテリアル、すでに除外した面を持つブラシはスキップされます。一部だけ覆われた面は分割されません。1 回の取り消しですべて元に戻ります。表示 → 除外した面を表示 で、エディターのビューでこうした面の表示／非表示を切り替えます。クリックによる選択には引き続きブラシ全体が使われます。

    #色とグラデーション

    面タブの 色 セクションでは、マテリアルの上から単色やグラデーションで面をペイントします。レベルのブロックアウトや、スタイライズされたアートに役立ちます。ペイントした面はビュー内で実際の色のまま表示され、選択状態は輪郭線で示されます。

    #パレットと混合色

    12 個あるパレットの色見本のいずれかをクリックすると、選択した面、または選択したブラシ全体をその色でペイントします。不透明度 は次のペイントの不透明度をパーセントで設定します。混合 にはカラーピッカーを開く色ボタンがあります。ピッカー内でドラッグすると選択範囲がリアルタイムで追従し、ペイント を押すと混合色を 1 回の操作として適用します。マテリアルに戻る はペイントを取り除き、面が再びマテリアルを表示するようにします。セクション上部の行には、何が選択されていて、それに何が適用されているかが表示されます。

    #カラーピッカー

    エディター内のどの色ボタンも、同じピッカーを開きます。四角形の中をドラッグして彩度と明度を、その横の帯をドラッグして色相を選びます。下には R、G、B の値があり、色に不透明度がある場合は 不透明度 スライダーもあります。16 進数フィールドには #RRGGBB または #RRGGBBAA を入力でき、有効な色でないあいだは赤く表示されます。コピー は 16 進コードをクリップボードにコピーします。ピッカーの外をクリックすると閉じます。

    #グラデーション

    グラデーション では 線形グラデーション と 放射状グラデーション を選び、その横のボタンで色の並びを反転します。各分岐点には色ボタンと 位置 (%) があり、両端の間にある分岐点には削除ボタンがあります。色の分岐点を追加 は最も広い間隔に分岐点を追加します。分岐点は 1 つのグラデーションにつき最大 8 個です。グラデーションの角度 は線形グラデーションの方向を設定し、+45° と −45° のボタンがあります。

    プレビューの下には、分岐点ごとにマーカーが付いたレールがあります。レールをクリックすると分岐点を追加し、マーカーをクリックするとそのピッカーを開き、マーカーをドラッグすると移動し、マーカーを右クリックすると削除します。レールの下にある 3 つの色見本はプリセットで、暖色グラデーション、寒色グラデーション、グレースケールのグラデーション です。グラデーションへの変更は、選択範囲にリアルタイムで適用されます。

    グラデーションでは向きが重要です。無関係な面をまたぐのではなく、屋根の傾斜や曲がったオブジェクトに沿って向けてください。ペイントした後は、モデルを両側から確認しましょう。

    #サーフェスマテリアル

    サーフェスマテリアル では、粗さ（0 は光沢、100 はつや消し）、金属度（木材・石・プラスチックは 0、金属は 100）、発光（0～8。サーフェスはグラデーションを含め自身の色で光りますが、周囲のオブジェクトを照らすことはありません）を設定します。変更は選択した面やブラシにリアルタイムで適用されます。既定のサーフェスを使用 で上書きを解除します。すべての変更は元に戻せます。

    サーフェスの効果は、ライティングされた 3D ビューとカメラのレンダリングに表示されます。フラット表示とワイヤーフレーム表示では、意図的にハイライトを省いています。ブルームを使うと、発光するサーフェスの周りにグローを加えられます。Godot と glTF/GLB にはマテリアルの値が渡され、Unity のインポーターは粗さを滑らかさ（smoothness）に変換します。各出力先の制限については docs/surface-materials.md を参照してください。

    #アセット、レイヤー、グループ

    #アセットライブラリ

    アセット タブを開きます。フォルダーを追加 で .map モデルのフォルダーを追加します。内蔵ライブラリは常に利用できます。アセットを絞り込む に入力して検索します。モデルをクリックして選択し、ダブルクリックするか、Enter を押すか、挿入 をクリックすると、最後にポインターがあった位置に追加されます。モデルをビューにドラッグすることもできます。アセットのブラシは 1 つのグループとして挿入されるので、モデル全体がまとまって動きます。

    選択範囲をアセットとして保存 は、選択したブラシを .map としてライブラリに書き込みます。ライブラリのアセットは通常の編集可能なブラシで、インポートしたメッシュではありません。

    #レイヤー

    マップタブの レイヤー リストで、広いエリアを整理します。名前を入力して 追加 をクリックするとレイヤーを作成でき、Enter を押すと現在のレイヤーの名前を変更します。各レイヤーは、非表示、ロック、エクスポート対象外にできます。ここへ移動 は選択範囲を現在のレイヤーに移動します。ビューのコンテキストメニューにも、レイヤーへ移動、アクティブレイヤーに設定、レイヤーを非表示、指定レイヤーのみ表示 があります。

    #グループとリンクグループ

    Ctrl+G で選択範囲をグループ化し、Ctrl+Shift+G でグループを解除します。マップタブの グループ セクションにはグループが一覧表示され、開く、名前を変更、マージ、グループ解除、取り出す、抽出 を使えます。リンクグループは、編集内容を共有するコピーの集まりです。Ctrl+Shift+D でリンク複製を作成し、形状 → リンクグループを同期 でコピーを更新し、リンク解除 でコピーを独立させます。エンティティタブでは、リンクグループを同期するときに、プロパティをそのコピー固有の値として残すように設定できます。

    #共通のスケール

    既定のエクスポートスケールは 1 メートルあたり 32 マップ単位です。内蔵のプレイヤースタートマーカーは高さ 64 単位で、2 メートルの基準になります。出入口、乗り物、家具、植物などをこれと比べてください。エクスポートスケールは意図がある場合にだけ変更し、関連するアセットの一貫性を保ちましょう。

    #エンティティとゲームプレイ

    よく使うエンティティ定義は内蔵されており、常に利用できます。ライト、プレイヤースタート、ドア、ボタン、足場、トリガー、静的なプロップ、サウンド、ウェイポイントです。エンティティタブの エンティティ定義 でプロジェクトの FGD を読み込むと、同じ名前のクラスが置き換えられ、それ以外の内蔵クラスはそのまま残ります。

    #エンティティの配置

    エンティティタブの エンティティ ブラウザーで、クラスを絞り込む に入力してクラスを選びます。ライトのようなポイントクラスは、配置 をクリックするかクラスをダブルクリックします。Insert で選択範囲の中心に 1 つ配置します。ドアやトリガーのようなブラシクラスは、ブラシを選択して 作成 をクリックします。クラスをビューにドラッグすることもできます。

    #プロパティ

    プロパティリストでは、選択したエンティティを編集します。同じクラスのエンティティはまとめて編集されます。プロパティを追加 では、定義にないキーも追加できます。既定値 では、既存のプロパティを既定値に戻したり、足りないプロパティを追加したりできます。クラスで定義されていてもエンティティにないプロパティは淡色で表示され、値を入力すると追加されます。エンティティ同士をつなぐには targetname と target を使います。

    #エクスポートでできること

    Godot のディレクティブは、ネイティブのノード、コリジョンボディ、トリガーエリアを作成します。Unity と Unreal は一般的なライトをネイティブに扱い、Unreal はさらに PlayerStart アクターも作成します。その他のデータは、出力先のインポーターが許す範囲で保持されます。

    ドアエンティティを置いただけでは、ゲームの動作は加わりません。移動、トリガーへの反応、プレイヤーコントローラー、プロジェクトのスクリプトは、エンジン側で作り込む必要があります。Defold はエンティティのプロパティとコリジョンオブジェクトをエクスポートし、Flax はモデルと汎用エンティティを配置します。ゲームプレイを組み立てる前に、エンジンで結果を確認してください。

    #アニメーション

    Heron Brush では、簡単な動きをプレビューしたり、ブラシエンティティのキーフレームアニメーションを編集したりして、それを複数のエンジンへエクスポートできます。

    #アニメーションのプレビュー

    表示メニュー、アニメーションメニュー、グリッド設定メニュー、またはマップタブの表示セクションで アニメーションをプレビュー をオンにします。start_on が有効な場合、エンティティの axis、speed、direction、travel、wait の各プロパティを使って、func_rotate の回転と func_shuttle の往復運動を再生します。また、開始時に再生 に設定されたキーフレームクリップも再生します。扇風機と風車のアセットには、最初から回転するパーツが含まれています。

    プレビューをオフにすると、元のポーズに戻ります。ビュー内をクリックすると、選択や編集の前に再生が止まります。カメラ操作はそのまま使えます。プレビューは、マップ、取り消し履歴、エクスポートを変更せず、物理演算やゲームロジックも実行しません。

    #キーフレームエディター

    アニメーション → キーフレームアニメーション、またはグリッド設定メニューから開きます。ビューの下にドッキングされ、3D ウィンドウが分離しているときはそのウィンドウ内にドッキングされます。見出しにあるウィンドウアイコンを押すと独立したウィンドウに移り、フレームと取り消し履歴は保たれます。アニメーションを編集 はビューをアニメーションのポーズに切り替え、マップを編集 は静止状態のジオメトリに戻します。アニメーションモードでは、各ビューの下部に アニメーションを編集 とフレーム番号が表示されます。

    アニメーションさせるには、ブラシエンティティ、またはブラシやブラシのグループを選択します。入れ子のないブラシグループは 1 つのアニメーションとピボットを共有します。複数のエンティティを含むグループには、それぞれ別のアニメーションが必要です。

    #クリップ

    アニメーション セレクターで、名前付きのクリップを切り替えます。アニメーション名 に名前を入力して 名前を付けて保存 をクリックすると、現在のクリップをその名前でコピーします。削除 はクリップを削除します。移動 は回転のない translate クリップを作成します。ドアのアニメーション は、現在のピボットを中心に 90 度回転する滑らかな open と close のクリップを作成します。先にピボットを蝶番の位置へ移動してください。開始時に再生 を使うと、レベルの開始時にクリップが再生されます。ドアのプリセットではオフになります。

    #トランスポートと再生

    トランスポートボタンは 先頭、前のキー、再生、次のキー、末尾 です。フレーム は現在のフレームを表示・設定し、長さ（秒） はクリップの長さを設定します。モードは 1 回のみ、ループ、往復 です。

    #タイムライン

    タイムラインには、再生ヘッドのあるルーラーと、位置（X、Y、Z をまとめてキー設定）および各回転角 RX、RY、RZ のレーンがあります。ルーラーをクリックまたはドラッグすると再生ヘッドが移動し、そのポーズがすべてのビューでプレビューされます。中ボタンでドラッグするとタイムラインをパンします。キーをドラッグすると時間方向に移動します。Shift で選択に追加し、レーンをダブルクリックするとキーを挿入し、Ctrl+ホイールでズームします。カーブ はレーンの代わりに値のカーブを表示します。

    その上にあるボタンは キーを追加、削除、コピー、貼り付け、複製 です。フレームにスナップ はキーを整数フレームに揃え、フィット はクリップ全体を表示します。キーの時間を変更 を開くと、時間スケール、オフセット（フレーム）、再生ヘッドを基準に拡縮、再生時間を延長、選択キーの時間を変更 があります。

    タイムラインの横にあるキーインスペクターでは、選択したキーを編集します。フレーム、値（位置キーの場合は 3 つの座標）、補間方法の 線形、一定、ベジェ、入力側の傾き と 出力側の傾き、そして 接線を滑らかにする です。

    #エディター内のキー操作

    タイムラインがキーボード入力を受けているとき、Space で再生／一時停止、左右の矢印キーで 1 フレームずつ移動、Ctrl+A ですべてのキーを選択、Ctrl+C、Ctrl+X、Ctrl+V でキーのコピー、切り取り、貼り付け、Ctrl+D で複製、Delete で削除、Ctrl+Z で取り消し、Esc でドラッグをキャンセルします。タイムラインの外では、Esc でアニメーションモードを終了します。取り消しを行っても、ズーム、選択、再生ヘッドはそのまま保たれます。

    #ビューでのポーズ設定

    タイムラインの下の行には、近くのポーズをゴーストとして表示する オニオンスキン（表示数と 間隔 を指定）、ピボット の座標、自動キー、そしてポーズツールの 移動、回転、ピボット があります。

    • キーを追加 は自動キーをオンにし、再生を一時停止します。自動キーがオンで 移動 を選んでいるとき、3D ビューで選択したエンティティのハンドルの色付きの軸をドラッグすると、現在のフレームに位置のキーが打たれます。
    • 2D ビューで、選択したブラシまたはそのグループのメンバーをドラッグすると、見えている 2 軸に沿った移動がグリッドスナップ付きでキーとして記録されます。この操作では自動キーをオンにする必要はありません。
    • 回転 では、2D ビューでオレンジ色のピボットマーカーを中心にブラシをドラッグします。上面ビューでは RZ、正面ビューでは RY、側面ビューでは RX にキーが打たれ、グリッドの角度にスナップします。
    • ピボット では、任意の 2D ビューで黄色の回転中心をドラッグします。グリッドにスナップし、奥行きは保たれます。キーと静止状態のジオメトリは変わりません。

    2D と 3D に表示されるシアンのパスは、ピボットの軌跡を示します。パス上の点をクリックするとその時刻とキーを選択し、ドラッグすると位置を変更します。自動キーがオンのときは、3D ビューでもパスの点をドラッグできます。ラベルにはフレーム番号が表示され、破線の区間はジャンプを示します。Esc でこれらのドラッグをキャンセルでき、ドラッグ全体を 1 回の取り消しで元に戻せます。

    新しいアニメーションは、時刻 0 にキーがある静止状態から始まります。別のフレームでポーズを変えると動きが生まれます。鋭い L 字型の経路にするには、始点、角、終点にキーを打ち、線形 と 往復 を使います。

    #ボタンとアニメーションの接続

    func_button、trigger_multiple、trigger_once のいずれかを選択します。エンティティタブのプロパティの上に アニメーショントリガー が表示されます。リストからターゲットを選ぶか、ビューで対象を選択 をクリックしてから、任意のビューでアニメーションするオブジェクトをクリックします。Esc で選択をキャンセルします。ターゲットやクリップが見つからない場合は、コントロールの下に表示されます。リンク表示がオンのとき、エンティティのリンクはターゲットへの矢印で示されます。

    アクション では、起動時の動作を選びます。再生 は名前付きのクリップか選択したアニメーションを開始します。切り替え は open と close があればそれらを交互に再生し、なければ選択したアニメーションを最初から再生します。開く と 閉じる はそれぞれのクリップを開始します。一時停止 はポーズを保持し、再開 は続きを再生し、停止 は元のポーズに戻します。一度だけ はクラスの既定値を上書きします。繰り返し間隔（秒） は起動の最短間隔を設定します。最初の起動が遅れることはありません。

    トリガーをテスト は、マップを編集したり取り消しステップを追加したりせずに、プレビュー内でアクションを実行します。プレビューをリセット は元のポーズに戻し、一度だけの状態とクールダウンの状態をクリアします。プレイヤーとの衝突やゲームスクリプトはシミュレートされません。

    #エクスポートでのアニメーション

    Godot には、カーブや動くコリジョンを含む、ネイティブの AnimationPlayer と AnimationLibrary リソースがエクスポートされます。CharacterBody3D がボタンのエリアに入ると、そのターゲットが起動します。Godot でこれらのクリップに加えた編集はマップには戻らず、次のエクスポートで置き換えられます。

    raylib へのエクスポートでは、C で書かれたアニメーションプレイヤーを含む <map>_animation.h と、フリーカメラのプレビューを含む <map>_preview.c が追加されます。ビルド方法は <map>_raylib.md に従ってください。プレビューでは、SPACE で一時停止、R で既定のクリップを最初から再生、N で名前付きクリップを順に切り替えます。Defold では、ドキュメント化された heron_*_animation メッセージを使って、再生処理がエンティティスクリプトに組み込まれます。Unity の Build Level は HeronBrushAnimation とキネマティックボディを追加します。Bevy へのエクスポートには heron_animation.rs と説明書が含まれます。Godot、Unity、Defold、Bevy、raylib は、トリガーのリンク、一度だけのフラグ、繰り返し間隔を保持します。プレイヤーの登録と、独自のボタンを各ランタイムの API に接続する作業は、ゲーム側で行う必要があります。

    #Motion lab サンプル

    ようこそ画面のサンプルから motion_lab を開きます。L 字型の経路を動く足場、リフト、回転する足場、ボタン付きの蝶番式ドアがあります。隣にある godot/project.godot を Godot で開き、F5 を押します。WASD とマウスでプレイヤーを動かし、Space でジャンプ、1～4 で各ステーションへ移動、R で現在のステーションをやり直します。色の付いたパッドに乗ると、そのターゲットが起動します。再エクスポートの方法は、同梱の README で説明しています。

    #エンジンへのエクスポート

    ファイル → エクスポート で、エクスポートウィンドウが開きます。左側にエンジンがロゴ付きで並んでいます。Godot、Defold、three.js、Bevy、raylib、Unity、Unreal Engine、Flax Engine、Cocos Creator、Wavefront .obj、glTF .gltf、GLB .glb、そして最後に .map です。右側のページには、その出力先に何が書き出されるかが説明されています。書き出す で書き出し、検証 は書き出さずにレベルをビルドして問題を一覧表示し、閉じる でウィンドウを閉じます。

    エクスポートは保存とは別の操作で、.map は編集用のソースとして残ります。各コントロールは変更されるとすぐにそのエンジンの設定を保存するので、エンジンごとに設定が保持され、ウィンドウは前回閉じたときの状態で開きます。

    #共通オプション

    • 拡大縮小：1 メートルあたりの単位数。既定は 32。
    • 出力する内容：衝突形状。
    • 最適化：静的メッシュを1024単位のセルにまとめる、形状内部に埋もれた面を除去、同一平面上の面を結合、衝突形状を結合。
    • プロジェクトのパス：レベルとそのリソースをプロジェクト内のどこに置くか。
    • ツール用マテリアル：clip、skip、origin の各マテリアルの名前。
    • その他：ノード名に使用する値、レイヤーとグループを親ノードとして再構成、三角形の頂点順序を反転 などのエンジン固有のスイッチ、テクスチャー座標の反転、そして ライトマップのテクセル で指定するベイクライト用の 2 つ目の UV セット。
    • マップに追従：マップを保存するたびに書き出す。そのエンジンへ一度エクスポートすると使用できるようになります。そのエクスポートで書き出し先が決まるためです。

    静的セルは、ワールドブラシを中心位置に基づいて 1024 単位のセルに割り当て、セルごとにマテリアル単位でまとめるので、エンジンはマップのより小さな部分ごとにカリングできます。コリジョンは保持され、ゲームプレイ用のエンティティは別のまま残ります。ワールド全体を 1 つのメッシュにする場合よりドローコールが増えることがあるため、既定ではオフです。単体の OBJ、glTF、GLB エクスポートではセルを使いません。

    #出力先ごとの注意

    • Godot：テクスチャーとマテリアルの res:// パス、トリガーの物理レイヤー、ライトマップ用の UV2。エクスポート先には Godot プロジェクト内のフォルダーを選んでください。
    • Defold：アセットのリソースディレクトリ、モデルのマテリアル、テクスチャーサンプラー（選択したマテリアルに存在する必要があります）。
    • Unity：OBJ メッシュとエディター用インポーター。プロジェクトの Assets フォルダー内にエクスポートします。
    • Unreal Engine：生成されるインポートスクリプトとコンテンツパス（通常は /Game/）。
    • Flax Engine：プロジェクトの Content フォルダーからの相対パスで指定するモデルのコンテンツパス。
    • three.js、Bevy、raylib、Cocos Creator：各ランタイム向けのシーンまたはコード。エクスポート先に説明書が付きます。
    • glTF / GLB：対応ツール向けの汎用的なジオメトリ。GLB はそのバイナリ形式です。OBJ：モデリングツール向けのジオメトリとマテリアル。
    • .map：出力形式 で Valve 220、標準、Quake 2、Quake 2 (Valve) を選びます。選んだ方言で失われるものはウィンドウに表示されます。

    書き出した後は、テクスチャーの欠落などの警告を確認してください。警告はウィンドウ内の 検証結果 に一覧表示されます。

    #ライブリンク：Godot、Unity、Defold、Flax

    ライブリンクは、作業中に Heron Brush の未保存の編集内容をエンジンのエディターへ送ります。送信は一方向で、エンジン側で行った編集は戻ってきません。ライブリンクはマップウィンドウごとに 1 つだけ実行できます。エンジンを切り替える前に停止し、エクスポートオプションを変更した場合は再起動して反映させてください。操作は、エクスポートウィンドウの各エンジンのページにある Godot とライブリンク などのカードで行います。

    タイトルバーのインジケーターがリンクの状態を示し、クリックするとリンクを停止します。マップを閉じたり置き換えたりすると、送信は停止します。インポートに失敗した場合は、問題を修正してからリンクをもう一度開始してください。

    #Godot

    1. Godot プロジェクトに一度エクスポートします。
    2. Godot アドオンをインストール をクリックします。
    3. Godot のプロジェクト設定 → プラグイン で Heron Brush Live を有効にします。
    4. ライブリンクを開始 をクリックし、Godot のドックから、開いている 3D シーンにマップをアタッチします。

    アドオンは自身が生成したブランチだけを置き換え、アタッチ先の配置やその他のノードはそのまま残します。Godot のシーンは自分で保存し、独自のスクリプトやノードは生成されたブランチの外に置いてください。

    #Unity

    1. Unity プロジェクトの Assets フォルダー内に一度エクスポートします。
    2. Unity アドオンをインストール をクリックし、Unity にコンパイルさせます。
    3. Unity で Window → Heron Brush → Live Link を開きます。
    4. リンクを開始し、アクティブな Unity シーンにマップをアタッチします。

    Unity のライブウィンドウは開いたままにしてください。Play モードと Prefab モードでは更新が一時停止します。置き換えられるのは、マップオブジェクトの子である Generated だけです。生成されたファイルは編集しないでください。

    #Defold

    1. Defold プロジェクトに一度エクスポートし、そのプロジェクトを Defold で開いたままにします。
    2. ライブリンクを開始 をクリックします。アドオンは不要です。
    3. Defold で heron_brush_live/preview.collection を開くか、独自のシーンから参照します。

    リンクは別の生成フォルダーに書き込み、最終的なエクスポートと game.project には手を付けません。実行中のゲームをホットリロード を使うと、Defold から起動したゲームも更新されます。オブジェクトを追加したりコリジョンを変更したりした場合は、レベルの再起動が必要になることがあります。接続に失敗した場合は自動的に再試行されます。

    #Flax

    プロジェクトの Content フォルダーにエクスポートし、Flax アドオンをインストール をクリックします。Flax にコンパイルさせてからリンクを開始し、開いている Flax シーンで Tools → Heron Brush: attach live map を選びます。生成されたルートは配置が保たれ、その他のオブジェクトには手が加えられません。シーンは自分で保存してください。Play モードでは更新が一時停止します。Tools → Heron Brush: stop live map で受信を一時停止します。

    #共同編集ライブセッション

    共同作業 → ライブセッション で、ほかの Heron Brush ユーザーとのセッションをホストしたり、セッションに参加したりするためのウィンドウが開きます。これは複数の人でマップの編集を共有する機能で、エンジンとのライブリンクとは別のものです。

    #ホストと参加

    あなたの名前 を入力します。ホストする場合は セッションをホスト を選び、セッションを開始 をクリックして、接続情報をコピー でコピーした情報をゲストに送ります。参加する場合は セッションに参加 を選び、情報を貼り付けて 参加 をクリックします。参加すると開いているマップがホストのマップに置き換わるので、先に作業を保存してください。

    標準ビルドはローカルネットワークで動作し、ローカルネットワークのポート でポートを設定します。インターネット経由のセッション（インターネット経由で接続）には、オプションのネットワーク機能を含むビルドが必要です。参加者には、3D ビュー内でお互いのカメラマーカーと名前が表示されます。

    ウィンドウを閉じてもセッションは続き、タイトルバーのインジケーターに状態が表示されます。セッションを停止 または セッションから退出 で終了します。2 人が同じオブジェクトを編集した場合は、ホスト側の順序で最終的な状態が決まり、取り消しも共有された編集として扱われます。できるだけ別々のエリアで作業し、こまめにチェックポイントを保存しましょう。

    #3D 表示とセカンドモニター

    #表示モード

    マップタブの 表示 セクションで、ビューに描画するものを切り替えます。ブラシ、ポイントエンティティ、エンティティモデル、エンティティのクラス名、グループの輪郭、パッチ、マテリアル、除外した面を表示、アニメーションをプレビュー、ワイヤーフレーム、辺、ブラシエンティティの輪郭 です。ワイヤーフレームは、対角線や面の裏側の辺も含めて三角形の辺をマテリアルなしで描画します。一時的なデバッグ用の表示で、エクスポートやレンダリングには影響しません。

    3D ビューのライティング、影、アンビエントオクルージョン、反射、ブルーム、スムージングは 環境設定 → レンダラー にあります。これらはプレビュー用の設定で、最終的な画像にはレンダーカメラ自身の設定が使われます。

    #3D ビューを別ウィンドウにする

    表示 → 3D ビューを別ウィンドウで表示 で、3D ビューを独立したウィンドウに移し、別のモニターに置けます。カメラ、ドキュメント、ツールは共有され、メインウィンドウでは平面ビューがその分の領域を使います。このウィンドウのメニューには、マテリアル、ソリッド表示、ワイヤーフレーム、表示 サブメニュー（除外した面を表示、アニメーションをプレビュー、辺、グループの輪郭、ポイントエンティティ、エンティティモデル、ブラシエンティティの輪郭）、選択範囲にフォーカス、選択範囲（またはカメラ前方の点）を中心にカメラを回り込ませる 正面、側面、上面、3D ビューからカメラを配置、全画面（F11）、画像をレンダリング、メインウィンドウに戻る があります。ウィンドウを閉じると、ビューは再びドッキングされます。

    #プロシージャルスカイ

    プロシージャルスカイは 3D ビューで既定でオンになっており、環境設定 → レンダラー → ライト でオフにできます。レンダーカメラには独自の プロシージャルスカイ スイッチがあり、マップと一緒に保存されます。空、地平線、地面の色はエンバイロメントの設定から取得され、太陽はシーンのライティングに従います。空にはジオメトリがなく、エクスポートもされません。

    #レンダーカメラと PNG 画像

    ファイル → 画像をレンダリング でレンダリングウィンドウが開きます。左側にカメラとその設定、右側にライブプレビューがあり、設定を変更すると再描画されます。カメラは .map 内のエディター専用の Render cameras レイヤーに保存され、このレイヤーはエンジンへのエクスポートから除外されます。

    #カメラの配置

    3D ビューで構図を決めて Ctrl+Alt+0（または Ctrl+Alt+Num0）を押すか、3D ビューからカメラを配置 をクリックします。カメラを選択していない場合は、保存されている最初のカメラが更新され、カメラがない場合は新しく作成されます。この操作は取り消し可能で、出力とライティングの設定は保たれます。マップ内のカメラを選択、マップからカメラを読み込む、3D ビューをカメラ位置へ移動 は逆方向の操作です。3D ビューのカメラ枠 は出力範囲の境界を表示し、3D ビューからカメラを操作 をオンにすると、通常のナビゲーションで保存済みのカメラを動かせます。

    #設定

    • カメラ位置：X、Y、Z、ヨー、ピッチ。
    • 出力とレンズ：プリセット（フル HD、正方形、縦向き）、幅、高さ、サンプル数、垂直視野角、遠方クリップ。
    • ライティング：昼光、夕日、曇天 から選ぶか、露出、太陽・空・地平線・地面の色、プロシージャルスカイ、影、アンビエントオクルージョン、ブルーム を個別に設定します。
    • 被写界深度：被写界深度を有効化、合焦距離、ピントの合う範囲、ぼかし半径。選択範囲にフォーカス は、カメラの前にある選択オブジェクトの中心にピントを合わせます。

    カメラと設定を保存 でフォームの内容をマップに保存します。ディスクに残すには、マップも保存してください。

    #レンダリング

    PNG をレンダリング は保存先を尋ねてから、プログレッシブレンダリングを開始します。プレビュー内でサンプルごとに画像が仕上がっていきます。サンプル数を増やすほど画質は上がりますが、時間がかかります。レンダリングをキャンセル は、ファイルを書き出さずに停止します。レンダラーはパストレーシングではなく、エディターのラスタライズパイプラインを使います。PNG の背景は不透明で、アニメーションはレンダリングされません。非常に大きな画像では、エディターが一時的に止まることがあります。

    #環境設定

    ファイル → 環境設定（Ctrl+,）で設定を開きます。変更はすぐに反映され、保存されます。サイドバーには 概要、ゲーム、表示、色設定、マウス、キーボード、レンダラー が並びます。上部の検索フィールドでは、どのページの設定でも名前や説明から探せます。変更した設定にはそれぞれ既定値に戻すボタンがあり、既定値に戻す で現在のページ全体をリセットします。

    #各ページ

    • 概要：よく使う設定をまとめたページ。外観（パネルの不透明度 (%)、配色、レイアウト、言語）、編集設定、表示、マニュアル。
    • ゲーム：ゲーム、そのファイルの場所、共同作業で使う名前。ゲームは、どのマップ形式で書き出すか、どのエンティティ定義を読み込むか、マテリアルがどこにあるかを決めます。ゲーム設定は、設定フォルダー内の games フォルダー（Linux と macOS では ~/.config/heron-brush/games、Windows では %LOCALAPPDATA%\heron-brush\games）と、アプリケーションと同じ場所にある games フォルダーから読み込まれます。パッケージには同梱の設定がこちらに入っています。
    • 表示：レイアウト、配色、言語、ワールド軸、グリッドの不透明度、リークチェックのセルサイズ、マッピングのロック。
    • 色設定：ビュー、ジオメトリ、ハンドルの色。
    • マウス：見回し・パン・移動の速度と反転、飛行速度、視野角、2D ビューを連動、ハンドルのサイズ。
    • キーボード：キー割り当て（Heron Brush または Blender）。
    • レンダラー：リアルなシェーディング、選択範囲の輪郭、ライト、影、アンビエントオクルージョン、反射、ブルーム、サーフェス。

    #言語

    言語 では、デスクトップの設定に従う と、翻訳済みのすべての言語を選べます。インターフェースはすぐに切り替わります。マニュアルは、翻訳がある場合はインターフェースの言語で、ない場合は英語で開きます。

    #プラグインと MCP

    #プラグイン

    プラグインは Rhai スクリプトでエディターを拡張します。ファイル → プラグイン でプラグインウィンドウが開きます。プラグインをインストール は .rhai ファイルを、プラグインフォルダーをインストール は main.rhai を含むフォルダーをインストールします。任意の plugin.toml メタデータで、プラグインとその設定を記述します。プラグインは 有効なプラグイン と 無効なプラグイン に分けて表示され、プラグインを有効化 で個別にオン／オフを切り替えます。この設定は再起動後も保持されます。プラグインを再読み込み は、スクリプトをディスクから読み込み直し、パネルの値をリセットします。

    有効なプラグインは、マップタブの プラグイン セクションにも、設定、アクションボタン（実行）、出力とともに表示されます。アクションは選択範囲に、何も選択していないときはすべてに作用し、1 回の取り消し単位になります。同梱の Selection inspector は、個数と、上へ移動・下へ移動のアクションを表示します。

    #MCP

    共同作業 → エージェント用サーバーを起動 (MCP) を使うと、AI エージェントやほかのツールが、Model Context Protocol を通じて開いているエディターを操作できます。ウィンドウにはローカルアドレスと コピー が表示され、サーバーを停止 で終了します。実行中は、タイトルバーに MCP 実行中 と表示されます。コマンドラインオプション --mcp を使うと、同じインターフェースをウィンドウなしで実行できます。クライアントは、ジオメトリ、アセット、プロパティ、アニメーション、エクスポート、セッション向けのツールを検出できます。MCP とエディターのプラグインは別々のインターフェースです。

    #コマンドライン

    プログラム名は heron-brush です。オプションなしで起動すると、ようこそ画面が開きます。

    #ファイルを開く

    heron-brush map.map [entities.fgd] [materials/] はマップを開きます。エンティティ定義とマテリアルフォルダーも指定できます。空の引数を渡すと、その項目を省略できます。たとえば heron-brush map.map "" materials/ です。エディターがすでに起動している場合は、そこでマップが開きます。代わりに別のウィンドウで開くには --new-instance を使います。

    #コマンド

    • --help または -h：使い方を表示。--version または -V：バージョンを表示。
    • --mcp：ウィンドウなしで、標準入出力経由で MCP を提供します。
    • --merge-map <base> <ours> <theirs> [<output>]：git 用の .map ファイルの 3 方向マージ。出力先の既定は ours です。競合は表示され、終了コードは 0 以外になります。
    • --obj-to-map <in.obj> <out.map> [size] [thickness] [snap] [material]：メッシュをブラシに変換します。size は最も長い辺のマップ単位での長さ（既定は 256）、snap は角を合わせるグリッド（0 でなし）です。solid または layered を指定すると、細いくさび形の代わりに、グリッド状の箱または凸型の板を作ります。
    • --render-preview <in.map> <out.png> [size]：マップの PNG サムネイルを書き出します。既定は 512 ピクセル。
    • --run-script <script.rhai> <in.map> [out.map] [key=value ...]：すべてを選択した状態でマップにプラグインスクリプトを実行し、結果を書き出します（既定では入力ファイルに上書き）。key=value でプラグインの設定に値を渡します。

    #トラブルシューティング

    #表示がおかしいとき

    • マテリアルが見つからない：マテリアルのフォルダーやパッケージと、エクスポートのプロジェクトのパスを確認します。
    • モデルのサイズがおかしい：64 単位のプレイヤーマーカーやエクスポートスケールと比べます。
    • グラデーションの向きがおかしい：グラデーションの角度と面の向きを確認します。
    • エンジンのシーンが空：エクスポートの警告を読み、出力先のインポート手順に従います。
    • ライブリンクが待機したまま：アドオンがインストールされていること、シーンがアタッチされていること、更新が一時停止していないことを確認します。
    • 線だけで面が表示されない：マップタブの表示セクションでワイヤーフレームをオフにするか、3D ウィンドウのメニューでマテリアルまたはソリッド表示を選びます。
    • ビューからオブジェクトが消えた：Ctrl+Shift+I で非表示のオブジェクトを表示し、レイヤーと 表示 セクションのフィルターを確認します。
    • キーが効かない：まずビューをクリックしてキーボード入力を受け取れるようにし、環境設定 → キーボード でキー割り当てを確認します。
    • 編集に失敗した：元に戻してジオメトリを単純にし、マップタブの 問題 セクションにある マップを検証 と リークを検査 を使います。
    • ファイルマネージャーからマップが開けない：すでに起動しているエディターに渡された可能性があります。そのウィンドウを探してください。

    #設定とバックアップ

    環境設定、最近使ったマップ、星、エクスポート設定、プラグインは設定フォルダーに保存されます。Linux と macOS では ~/.config/heron-brush、Windows では %LOCALAPPDATA%\heron-brush です。自動保存のバックアップは、各マップと同じ場所の autosave フォルダーにあります。

    #バグの報告

    エディターのバージョン（ヘルプ → このアプリについて）、オペレーティングシステム、問題を再現できる小さなマップ、正確な手順を添えてください。出力ペイン（Ctrl+4）に原因が表示されていることがよくあります。いろいろ試す前に、コピーを保存しておきましょう。

    #このマニュアルの使い方

    左側の目次から章を選びます。Ctrl+F で目次を表示して検索フィールドに移動します。Esc で検索をクリアし、検索が空のときはマニュアルを閉じます。目次 は章リストの表示／非表示を切り替え、文字サイズ はフォントサイズを変更します。どちらの設定も記憶されます。上部の言語リストで、利用できる翻訳を切り替えられます。
