    #시작하기

    Heron Brush는 브러시 기반 레벨 에디터입니다. 볼록한 브러시로 레벨을 만들고, 면에 색을 칠하고 텍스처를 입히고, 엔티티를 배치하고, 문과 플랫폼에 애니메이션을 주고, 결과를 게임 엔진으로 내보냅니다. 내장 에셋, 파라메트릭 도형, 엔진 에디터와의 라이브 링크, 공동 편집 세션, 정지 이미지 렌더링 기능도 갖추고 있습니다. 이 매뉴얼은 애플리케이션에 포함되어 있어 오프라인에서도 볼 수 있습니다.

    macOS에서는 이 매뉴얼에 Ctrl이라고 적힌 곳 어디서나 Cmd를 쓸 수 있으며, Option은 Alt에 해당합니다.

    #시작 화면

    Heron Brush를 맵 없이 실행하면 시작 화면이 열립니다. 왼쪽에는 <맵 이름> 계속하기(마지막으로 열었던 맵), 새 맵, 기존 .map을 여는 찾아보기, 그리고 게임, 매뉴얼, 환경설정이 있습니다. 오른쪽에는 썸네일이 붙은 최근 맵 목록이 있고 그 아래에 예제가 이어집니다. 별(항상 위에 표시)은 맵을 목록 맨 위에 고정하고, 휴지통(휴지통으로 이동)은 파일을 시스템 휴지통으로 옮기므로 나중에 복원할 수 있습니다. 화살표 키로 화면을 이동하고 Enter로 포커스된 항목을 엽니다. 언제든 파일 → 시작 화면으로 이 화면을 다시 열 수 있습니다.

    #첫 번째 맵

    1. 시작 화면에서 새 맵을 선택하거나 파일 → 새 맵(Ctrl+N)을 선택하세요.
    2. 도구 모음에서 브러시 도구(B)를 고르고 2D 뷰에서 드래그해 선택한 모양을 그리세요. 다른 2D 뷰에서 깊이를 확인하세요.
    3. 브러시를 선택하고 드래그해서 옮기세요. 면 탭에서 재질이나 색상을 지정하세요.
    4. Ctrl+S로 원본 맵을 저장하세요. 게임에서 쓸 준비가 되면 파일 → 내보내기를 열고 엔진용 씬을 출력하세요.

    #파일과 저장

    .map 파일은 편집 가능한 원본입니다. 자주 저장하세요. 내보내기, 라이브 링크, 렌더링은 맵을 대신 저장해 주지 않습니다. 파일 → 다른 이름으로 저장(Ctrl+Shift+S)은 확장자를 생략하면 .map을 붙여 줍니다. 파일 → 저장된 맵으로 되돌리기는 저장하지 않은 변경 사항을 버리고 파일을 다시 불러옵니다. 저장하지 않은 변경 사항이 있는 상태에서 창을 닫거나 다른 맵을 열면 Heron Brush가 저장, 버리기, 취소 중 무엇을 할지 묻습니다.

    저장된 적이 있는 맵에 저장하지 않은 변경 사항이 있으면 10분마다 맵 옆의 autosave 폴더에 번호가 붙은 백업이 기록됩니다. 가장 최근 백업 50개가 보관됩니다.

    Heron Brush가 이미 실행 중일 때 맵을 열면 실행 중인 창으로 전달되고 그 창이 앞으로 나옵니다. 별도의 창이 필요하면 명령줄에서 --new-instance를 사용하세요(명령줄 참고).

    #인터페이스

    메인 창에는 메뉴가 있는 제목 표시줄, 그 아래의 도구 모음, 맵 뷰, 오른쪽의 인스펙터, 하단의 상태 표시줄이 있습니다.

    #제목 표시줄과 메뉴

    제목 표시줄에는 로고, 메뉴, 가운데의 맵 이름, 창 버튼이 표시됩니다. macOS에서는 익숙한 빨강, 노랑, 초록 버튼이 왼쪽에 있습니다. 제목 표시줄을 드래그하면 창을 옮길 수 있고, 더블클릭하면 최대화됩니다. 백그라운드에서 무언가 실행 중이면 표시줄 끝 근처에 표시기가 나타납니다. 엔진 라이브 링크, 라이브 세션 또는 MCP 활성입니다. 표시기를 클릭하면 라이브 링크를 중지하거나 해당 창을 엽니다.

    • 파일: 시작 화면, 새 맵(Ctrl+N), 맵 열기(Ctrl+O), 저장(Ctrl+S), 다른 이름으로 저장(Ctrl+Shift+S), 저장된 맵으로 되돌리기, 내보내기, 이미지 렌더링, 플러그인, 환경설정(Ctrl+,).
    • 편집: 실행 취소(Ctrl+Z), 다시 실행(Ctrl+Shift+Z), 잘라내기, 복사, 붙여넣기, 복제(Ctrl+D), 삭제, 모두 선택(Ctrl+A), 마지막 명령 반복(Ctrl+R), 반복 명령 기록 지우기.
    • 보기: 별도 창의 3D 뷰, 이동, 그리드에 스냅(Alt+0), 그리드 표시(0), 애니메이션 미리보기, 제외된 면 표시.
    • 지오메트리: 3D 텍스트 삽입, 모서리 연결, 면을 패치로 변환, 선택 영역을 엔티티에서 꺼내기, 연결된 그룹 동기화.
    • 애니메이션: 키프레임 애니메이션, 애니메이션 미리보기, 3D 뷰 위치에 카메라 배치(Ctrl+Alt+0).
    • 맵: 포인트 파일 불러오기, 포인트 파일 다시 불러오기, 포인트 파일 닫기와 포털 파일 불러오기, 포털 파일 다시 불러오기, 포털 파일 닫기. 맵 컴파일러가 기록한 누출 경로와 포털을 표시합니다.
    • 협업: 라이브 세션, 에이전트용 서버 시작 (MCP).
    • 도움말: 매뉴얼, 정보.

    #도구 모음

    도구 모음에는 모든 도구가 모여 있습니다. 첫 번째 그룹은 늘 쓰는 도구로 선택, 브러시, 자르기, 정점, 모서리, 면, 회전, 크기 조절입니다. 두 번째 그룹에는 전단, 조립, 스윕, 제어점, 필렛, 칠하기가 있습니다. 버튼 위에 마우스를 올리면 이름과 단축키가 표시됩니다. 활성 도구를 다시 클릭하면 선택 도구로 돌아갑니다.

    도구 다음에는 좌우 반전과 상하 반전, 그리고 두 개의 스위치가 있습니다. 잠금은 브러시가 이동할 때 재질 매핑을 유지하고, UV는 브러시가 회전할 때 매핑을 유지합니다(U로 전환). 그 뒤에는 활성 도구의 설정이 이어집니다. 브러시 도구는 모양과 옵션을, 필렛 도구는 반경, 면, 꼭짓점과 적용을 표시합니다. 오른쪽 끝에는 도구 이름, 그리드 크기(그리드 16 등, 클릭해서 다른 크기 선택), 그리고 그리드에 스냅, 그리드 표시, 애니메이션 미리보기, 제외된 면 표시, 키프레임 애니메이션이 들어 있는 그리드 설정 메뉴가 있습니다.

    #맵 뷰

    뷰는 네 가지입니다. 3D 뷰와 세 개의 평면 뷰인 상단 (XY), 정면 (XZ), 측면 (YZ)입니다. 환경설정 → 보기 → 레이아웃에서 단일 뷰, 2분할 뷰, 3분할 뷰, 4분할 뷰 중 하나를 고릅니다. 구분선을 드래그하면 창 크기를 조절할 수 있습니다. 뷰를 클릭하면 그 뷰가 키보드 입력을 받습니다. Space는 한 번에 뷰 하나만 보여 주는 창을 다음 뷰로 전환하고, Ctrl+Space는 키보드 입력을 받는 뷰를 최대화했다가 다시 원래 레이아웃으로 되돌립니다.

    아무 뷰에서나 드래그하지 않고 마우스 오른쪽 버튼을 클릭하면 선택 항목과 포인터 아래 대상에 대한 컨텍스트 메뉴가 열립니다. 그룹화, 레이어, 연결된 그룹, 엔티티 생성, 브러시를 엔티티 안팎으로 옮기기, 재질 이름 복사, 재질 브라우저에서 보기 등을 제공합니다.

    #인스펙터

    오른쪽의 인스펙터에는 탭이 네 개 있습니다. 왼쪽 가장자리를 드래그하면 너비를 바꿀 수 있습니다.

    • 맵(Ctrl+1): 레이어, 그룹, 플러그인, 문제, 보기 섹션의 필터, 태그.
    • 엔티티(Ctrl+2): 엔티티 브라우저, 엔티티 정의, 선택한 엔티티의 속성, 그리고 버튼과 트리거의 경우 애니메이션 트리거.
    • 면(Ctrl+3): UV, 재질, 색상, 스윕, 필렛, 패치, 인셋 및 모따기. 각 섹션은 접을 수 있습니다.
    • 에셋: 재사용 가능한 브러시 모델 라이브러리.

    Ctrl+5는 인스펙터를, Ctrl+Alt+T는 도구 모음을 숨기거나 표시해 뷰에 더 많은 공간을 줍니다.

    #상태 표시줄과 출력 창

    하단의 상태 표시줄에는 에디터의 최신 메시지가 표시됩니다. 오류는 빨간색으로 표시됩니다. 표시줄을 클릭하거나 Ctrl+4를 누르면 전체 메시지 기록이 담긴 출력 창이 열립니다. 대부분의 명령은 수행한 작업을 여기에 알려 줍니다. 예를 들어 브러시 몇 개가 잘렸는지 표시합니다.

    #대화 상자와 모양

    환경설정, 내보내기, 이미지 렌더링 같은 대화 상자는 별도의 창으로 열립니다. 환경설정 → 보기 → 색 구성표에서 시스템 설정 따르기, 밝게, 어둡게 중 하나를 고릅니다. 개요 페이지의 패널 불투명도 (%)를 낮추면 패널 너머로 뷰가 비쳐 보입니다. 창은 시스템 스타일에 맞춰 버튼을 직접 그립니다. macOS에서는 네이티브 스타일, Windows에서는 Windows 11 스타일, Linux에서는 GNOME 스타일입니다.

    #탐색과 키보드

    #3D 뷰에서 이동하기

    마우스 오른쪽 버튼을 누른 채 드래그하면 주위를 둘러봅니다. 가운데 버튼으로 드래그하면 화면을 팬합니다. 휠은 앞뒤로 이동합니다. W, A, S, D는 앞, 왼쪽, 뒤, 오른쪽으로 비행하고, Q는 위로, X는 아래로 이동합니다. Shift를 누르고 있으면 더 크게 이동합니다. 환경설정 → 마우스에서 Alt + 가운데 버튼 드래그로 카메라 이동을 켜면 Alt와 가운데 버튼으로 시선 방향을 따라 이동합니다. 속도, 반전, 시야각은 환경설정 → 마우스에 있습니다.

    #2D 뷰에서 이동하기

    가운데 버튼으로 드래그해 팬하고, 휠로 포인터를 중심으로 확대/축소합니다. 평면 뷰 하나를 팬하거나 확대/축소하면 다른 뷰도 맞춰 정렬됩니다. 이 동작은 환경설정 → 마우스의 2D 뷰 연결로 제어합니다. Ctrl+Alt+Z는 확대/축소를 초기화하고 Ctrl+Shift+U는 평면 뷰를 원점으로 되돌립니다.

    Ctrl+U는 모든 뷰에서 선택 영역이 화면에 꽉 차도록 맞춥니다. 보기 → 이동(Ctrl+Alt+M)은 입력한 좌표로 카메라를 옮기거나, 맵 파일의 특정 줄에 해당하는 대상을 선택하거나, 입력한 만큼 선택 영역을 이동합니다.

    #그리드와 스냅

    +와 -는 그리드 크기를 바꾸고, 숫자 키 1~9는 1에서 256 단위까지 크기를 바로 고릅니다. 0 또는 #은 그리드를 표시하거나 숨기고, Alt+0은 스냅을 켜거나 끕니다. S는 선택한 브러시의 정점을 현재 그리드에 스냅하고, Ctrl+Shift+V는 정수 단위에, Ctrl+Alt+Shift+V는 그리드에 스냅합니다.

    #자주 쓰는 단축키

    • Ctrl+S: 맵 저장. Ctrl+Shift+S: 다른 이름으로 저장.
    • Ctrl+Z: 실행 취소. Ctrl+Shift+Z 또는 Ctrl+Y: 다시 실행.
    • Ctrl+C, Ctrl+X, Ctrl+V: 복사, 잘라내기, 붙여넣기. 붙여넣기는 오브젝트를 포인터 위치에 놓고, Ctrl+Alt+V는 원래 좌표를 유지합니다. 면이 선택된 상태에서 복사하면 그 면의 재질과 UV 설정을 가져옵니다.
    • Ctrl+D: 복제. Ctrl+Shift+D: 그룹의 연결된 복제본 만들기.
    • Delete 또는 Backspace: 선택 항목 삭제.
    • Esc: 현재 드래그를 취소하고, 활성 도구에서 한 단계 뒤로 가고, 선택 도구로 돌아가고, 마지막으로 선택을 해제합니다. Shift+Esc는 곧바로 선택 도구로 돌아갑니다.
    • Ctrl+R: 마지막으로 반복 가능한 명령을 반복. Ctrl+Shift+R: 그 기록 지우기.
    • Ctrl+Alt+0 또는 Ctrl+Alt+Num0: 렌더 카메라를 3D 뷰 위치에 배치.
    • F5: 재질 다시 불러오기. F6: 엔티티 정의 다시 불러오기.

    #선택 단축키

    • Ctrl+A: 모두 선택. 정점, 모서리, 면 도구가 활성일 때는 모든 핸들 선택. Ctrl+Shift+A: 선택 해제. Ctrl+Alt+A: 선택 반전.
    • Ctrl+B: 같은 엔티티나 그룹에 속한 다른 오브젝트 선택.
    • Ctrl+T: 선택한 브러시에 닿는 모든 것 선택. Ctrl+E: 브러시 내부의 모든 것 선택. Ctrl+Shift+E: 뷰 축 방향으로 브러시가 이루는 기둥 안의 모든 것 선택. 이 명령들은 선택에 사용한 브러시를 소모합니다.
    • Ctrl+I: 선택 항목만 표시. Ctrl+Alt+I: 선택 항목 숨기기. Ctrl+Shift+I: 모두 다시 표시.
    • Ctrl+G: 그룹 만들기. Ctrl+Shift+G: 그룹 해제.

    #변형 단축키

    • 화살표 키와 Page Up / Page Down은 활성 뷰에서 가리키는 방향으로 선택 영역을 그리드 한 칸만큼 이동합니다. Ctrl과 함께 누르면 이동하면서 복제하고, Alt와 함께 누르면 회전합니다.
    • Alt+X, Alt+Y, Alt+Z: 해당 축을 중심으로 90도 회전. Shift를 더하면 반대 방향으로 회전합니다.
    • Ctrl+F: 뷰 기준 좌우 뒤집기. Ctrl+Alt+F: 상하 뒤집기. Ctrl+Shift+X와 Ctrl+Shift+Y는 X 또는 Y 방향으로 미러링합니다.
    • Insert: 선택 영역 중심에 포인트 엔티티 배치.
    • Tab: 브러시가 선택된 상태에서 선택 → 정점 → 모서리 → 면 → 선택 순으로 도구 전환.

    #Blender 키맵

    환경설정 → 키보드 → 키맵에서 Heron Brush(기본값, 이 매뉴얼 전체에서 사용)과 Blender 중 하나를 고릅니다. Blender 키맵에서는 G가 선택 후 이동, R이 회전, S가 크기 조절, E가 스윕, 1, 2, 3이 각각 정점, 모서리, 면 도구, K가 자르기, B가 선택, A가 모두 선택, Alt+A가 선택 해제, X가 삭제, Shift+D가 복제, H가 숨기기, Alt+H가 모두 표시, Ctrl+Shift+Z가 다시 실행입니다. 나머지는 두 키맵이 같습니다.

    #브러시와 모델링 도구

    브러시는 평면으로 정의되는 볼록 솔리드입니다. 브러시 하나를 오목하게 만들려 하지 말고 단순한 브러시 여러 개로 복잡한 오브젝트를 만드세요. 단순한 모양으로 충분한 곳에서는 브러시 수를 적게 유지하세요.

    #브러시 그리기

    브러시 도구(B)를 고르고 뷰에서 드래그하세요. 도구 모음에 그릴 모양이 표시됩니다. 선택지는 직육면체, 계단, 아치, 원기둥, 원뿔, 회전타원체 (UV), 회전타원체 (정이십면체), 3D 텍스트 삽입입니다. Alt+1~Alt+7로 모양을 바로 고를 수 있습니다. 모양에 따라 도구 모음에 속 비우기와 두께:, 계단에는 계단 높이:와 방향:, 둥근 모양에는 축:, 변:과 원 모드, 구에는 링:, 정이십면체에는 정밀도:가 표시됩니다. 드래그하기 전에 옵션을 설정하고, 결과는 여러 뷰에서 확인하세요.

    #선택하기

    브러시를 클릭하면 선택되고, Ctrl-클릭하면 선택에 추가됩니다. 빈 공간에서 드래그하면 선택 상자가 그려집니다. 3D 뷰에서 Shift-클릭하면 면 하나를 선택하고, Ctrl+Shift-클릭하면 면을 더 추가합니다. 선택된 브러시를 드래그하면 이동하고, 선택되지 않은 브러시를 드래그하면 그 브러시만 선택해서 이동합니다.

    3D 뷰에서 선택한 브러시의 면을 Shift-드래그하면 돌출(익스트루드)합니다. 다른 면을 Alt-클릭하면 선택한 면의 재질과 정렬을 그 면에 복사합니다. Alt+Ctrl은 재질만, Alt+Shift는 회전을 복사합니다.

    #모양 다듬기 도구

    • 선택(Esc): 선택과 이동.
    • 정점(V), 모서리(E), 면(F): 꼭짓점, 모서리, 면을 드래그합니다. 모서리나 면의 가운데에서 Shift-드래그하면 그곳에 꼭짓점을 추가합니다. Delete는 고른 꼭짓점을 제거합니다.
    • 회전(R), 크기 조절(T), 전단(G): 핸들로 선택 영역을 변형합니다.
    • 자르기(C): 점 두세 개를 클릭해 절단 평면을 정합니다. Enter로 자르고, Ctrl+Enter로 남길 쪽을 고르며, Backspace 또는 Esc로 마지막 점을 제거합니다.
    • 조립(N): 볼륨 주위에 점을 배치하고 Enter를 누르면 그 점들로 볼록 브러시를 만듭니다. Backspace는 마지막 점을 제거합니다.
    • 스윕(Y): 아래의 스윕 섹션을 참고하세요.
    • 제어점(P): 패치의 제어 그리드 모양을 바꿉니다.
    • 필렛(O): 모서리를 클릭해 둥글게 하거나, 해당 도구로 모서리나 정점을 고른 뒤 Enter를 누릅니다. 면 수가 많을수록 결과가 매끄러워지지만 지오메트리도 늘어납니다.
    • 칠하기(K): 재질과 UV를 참고하세요.

    #브러시 결합

    • Ctrl+J: 선택한 브러시를 볼록 껍질(convex hull)로 병합합니다.
    • Ctrl+K: 선택한 브러시를 그 브러시가 닿아 있는 브러시에서 빼냅니다.
    • Ctrl+Shift+K: 선택 영역의 속을 비웁니다. 벽 두께는 그리드 한 칸입니다.
    • Ctrl+L: 선택 영역의 교집합을 만듭니다.

    #스윕, 필렛, 패치, 모따기

    스윕은 선택한 면에서 경로를 따라 지오메트리를 만듭니다. 면을 선택하고(스윕 도구에서는 Alt-클릭), 면 탭의 스윕 섹션에서 이동, 회전(축과 각도), 크기 조절, 단계, 경로(정수 또는 자유 정렬, 호, 직선 또는 S자 곡선)를 설정한 다음 스윕을 누르세요. 컨트롤 아래 줄에 만들어질 브러시 수가 표시됩니다.

    필렛 섹션은 반경, 면, 꼭짓점(마이터 또는 둥글게 처리됨)으로 고른 모서리를 둥글게 합니다. 면을 1로 하면 모따기가 됩니다.

    패치는 선택한 패치의 열과 행을 보여 주며, 한 쌍씩 추가하거나 제거하는 버튼이 있습니다. 지오메트리 → 면을 패치로 변환(Ctrl+P)은 선택한 면으로 패치를 만듭니다.

    인셋 및 모따기는 선택한 면에 작동합니다. 인셋은 면을 가장자리에서 안쪽으로 줄이고, 깊이는 면을 바깥으로(음수면 안쪽으로) 밀어냅니다. 면 모따기는 둘 다 적용합니다. 세 번째 버튼은 깊이의 부호에 따라 패널을 덧붙이거나 홈을 파냅니다. 모서리 연결은 두 브러시를 마이터 또는 둥근 모서리로 잇는 대화 상자를 미리보기와 함께 엽니다.

    #3D 텍스트

    지오메트리 → 3D 텍스트 삽입(브러시 도구 모양 목록의 마지막 항목이기도 합니다)은 텍스트로 브러시를 만듭니다. 모서리가 잘린 내장 폴리곤 글꼴 Heron Block을 사용하며, 비례 폭과 체코어 악센트를 지원하고 소문자는 대문자 형태로 표시됩니다. 텍스트를 입력하고 높이(대문자 높이, 악센트는 그 위로 올라감)와 깊이를 설정한 뒤 실시간 미리보기를 확인하고 삽입을 누르세요.

    작업이 올바른 지오메트리를 만들 수 없으면 치수를 조정하거나, 실행 취소한 뒤 모양을 단순하게 바꾸세요.

    #재질과 UV

    #재질 불러오기와 적용

    면 탭의 재질 섹션을 여세요. 폴더 불러오기는 이미지 폴더를, .wad 불러오기는 텍스처 패키지를 추가합니다. 둘 다 컬렉션 아래에 나타나며 X 버튼으로 제거할 수 있습니다. 재질 필터에 입력하면 목록이 좁혀집니다. 재질을 클릭해 현재 재질로 만든 다음 선택 영역에 적용을 누르면 선택한 모든 면에 적용됩니다. 선택에는 이 재질의 브러시 선택과 이 재질의 면 선택이 있습니다. 교체는 맵 전체 또는 선택 영역 안에서만 한 재질을 다른 재질로 바꿉니다.

    칠하기 도구(K)는 포인터 아래의 면에 현재 재질을 입힙니다. 클릭하면 면 하나를, 더블클릭하면 브러시 전체를 칠하고, Shift-클릭하면 스포이트처럼 그 면의 재질을 현재 재질로 가져옵니다.

    #UV 편집기

    면 탭의 UV 섹션에는 선택한 면의 재질과 윤곽이 표시됩니다. 캔버스에서의 마우스 조작은 다음과 같습니다.

    • 휠은 포인터를 중심으로 확대/축소합니다. 오른쪽 또는 가운데 버튼으로 드래그하면 팬합니다. 오른쪽 버튼을 더블클릭하면 면을 다시 화면에 맞추며, 다른 면을 선택하면 자동으로 맞춰집니다.
    • 왼쪽 드래그는 면 윤곽은 그대로 둔 채 재질을 이동합니다. 링은 매핑을 회전하고, 모서리 핸들은 크기를 조절하며, 가운데 핸들은 이러한 변경의 원점을 정합니다.
    • 타일 가장자리에서 Alt-왼쪽 드래그하면 전단 변형이 되며, Shift-가운데 드래그도 마찬가지입니다.
    • 드래그 한 번이 실행 취소 한 단계이며, Esc는 진행 중인 드래그를 취소합니다.

    캔버스 아래에는 오프셋, 크기 조절, 각도, 그리고 게임에서 사용하는 경우 콘텐츠 플래그, 표면 플래그, 표면 값이 있습니다. 버튼은 초기화, 월드 축으로 초기화, 맞추기, 좌우 반전, 상하 반전, 그리고 두 개의 90° 회전 버튼입니다. 정렬은 면의 모서리 중 하나를 따라 재질을 회전합니다(다시 누르면 다음 모서리, Shift를 누르면 이전 모서리). 네 개의 맞춤 버튼은 재질을 한쪽 가장자리에 붙입니다. U 맞추기와 V 맞추기는 정수 개의 반복이 면을 덮도록 크기를 조절합니다. 다시 누르면 다음 개수로 넘어가고, Ctrl을 누르고 있으면 트림 시트의 분할을 유지합니다.

    #UV 키

    면이 선택된 상태에서 화살표 키는 재질을 이동하고, [와 ]는 15°씩 회전하며, ,와 .는 크기를 절반 또는 두 배로 만들고, Ctrl+F와 Ctrl+Alt+F는 뒤집고, Shift+R은 초기화하고, Alt+Shift+R은 월드 축 기준으로 초기화하며, Ctrl+Shift+F는 각 면에 맞춥니다.

    도구 모음의 잠금은 브러시가 이동할 때, UV(U)는 브러시가 회전할 때 매핑을 유지합니다.

    #도구 재질

    • skip: 표시된 면을 엔진 내보내기에서 제외합니다.
    • clip: 보이는 지오메트리 없이 충돌을 만듭니다.
    • origin: 브러시 엔티티의 피벗을 표시합니다.

    이름은 내보내기 창의 도구 재질 카드에서 바꿀 수 있습니다. 확실히 가려지는 면에는 skip을 사용하세요.

    #내보내기에서 면 제외하기

    면을 선택하고 UV 섹션에서 내보내기에서 면 제외를 켜세요. UV 미리보기에서 주황색 빗금으로 표시됩니다. 재질과 칠은 그대로 저장되며, 브러시는 닫힌 상태로 계속 편집할 수 있습니다. 내보낸 렌더 메시에서는 그 면이 빠지지만 충돌은 유지됩니다. 큐브에서 사각형 면 하나만 남기면 렌더 삼각형 두 개가 됩니다. 이 기능은 면을 양면으로 만들거나 메시를 병합하지 않습니다.

    가려진 면 제외는 정적 브러시에 완전히 가려진 면을 표시합니다. 서로 맞닿은 동일한 면과 다른 브러시에 둘러싸인 브러시도 포함됩니다. 선택한 브러시에 작동하며, 아무것도 선택하지 않았으면 보이면서 잠기지 않은 모든 월드 지오메트리에 작동합니다. 브러시 엔티티, 투명 재질, 이미 제외된 면이 있는 브러시는 건너뜁니다. 일부만 가려진 면은 분할하지 않습니다. 실행 취소 한 번으로 모두 복원됩니다. 보기 → 제외된 면 표시로 에디터 뷰에서 이런 면을 숨기거나 표시합니다. 클릭으로 선택할 때는 여전히 브러시 전체가 기준입니다.

    #색상과 그라디언트

    면 탭의 색상 섹션은 재질 위에 단색이나 그라디언트로 면을 칠합니다. 레벨 블록아웃이나 스타일라이즈드 아트에 유용합니다. 칠한 면은 뷰에서 실제 색을 유지하며, 선택은 윤곽선으로 표시됩니다.

    #팔레트와 혼합 색

    팔레트 견본 12개 중 하나를 클릭하면 선택한 면이나 선택한 브러시 전체를 그 색으로 칠합니다. 불투명도는 다음 칠의 불투명도를 백분율로 정합니다. 혼합에는 색상 선택기를 여는 색상 버튼이 있습니다. 선택기에서 드래그하면 선택 영역이 실시간으로 따라 바뀌고, 칠하기를 누르면 혼합 색을 한 단계로 적용합니다. 재질로 돌아가기는 칠을 제거해 면에 다시 재질이 보이게 합니다. 섹션 맨 위 줄에는 무엇이 선택되었고 어떤 칠이 입혀져 있는지 표시됩니다.

    #색상 선택기

    에디터의 모든 색상 버튼은 같은 선택기를 엽니다. 사각형 안에서 드래그해 채도와 명도를, 옆의 띠에서 드래그해 색조를 고릅니다. 아래에는 R, G, B 값과, 색에 불투명도가 있는 경우 불투명도 슬라이더가 있습니다. 16진수 필드에는 #RRGGBB 또는 #RRGGBBAA를 입력하며, 올바른 색이 아니면 빨간색으로 바뀝니다. 복사는 16진수 코드를 클립보드에 복사합니다. 선택기 바깥을 클릭하면 닫힙니다.

    #그라디언트

    그라디언트에서 선형 그라디언트 또는 방사형 그라디언트를 고르며, 옆의 버튼은 양 끝 색을 서로 바꿉니다. 각 정지점에는 색상 버튼과 위치 (%)가 있고, 양 끝 사이의 정지점에는 제거 버튼이 있습니다. 색상 정지점 추가는 가장 넓은 간격에 정지점을 추가하며, 그라디언트에는 정지점을 최대 8개까지 둘 수 있습니다. 그라디언트 각도는 선형 그라디언트의 방향을 정하며, +45°와 −45° 버튼이 있습니다.

    미리보기 아래에는 정지점마다 마커가 있는 레일이 있습니다. 레일을 클릭하면 정지점이 추가되고, 마커를 클릭하면 선택기가 열리며, 마커를 드래그하면 이동하고, 마커를 오른쪽 클릭하면 제거됩니다. 레일 아래의 세 견본은 프리셋으로, 따뜻한 그라디언트, 차가운 그라디언트, 회색조 그라디언트입니다. 그라디언트를 바꾸면 선택 영역에 실시간으로 적용됩니다.

    그라디언트는 방향이 중요합니다. 서로 관련 없는 면들을 가로지르지 말고 지붕 경사나 곡면 오브젝트를 따라 방향을 맞추세요. 칠한 뒤에는 모델을 양쪽에서 확인하세요.

    #표면 재질

    표면 재질은 거칠기(0은 광택, 100은 무광), 금속성(나무, 돌, 플라스틱은 0, 금속은 100), 발광(0~8, 표면이 그라디언트를 포함한 자체 색으로 빛나지만 주변 오브젝트를 비추지는 않음)을 설정합니다. 변경 사항은 선택한 면이나 브러시에 실시간으로 적용됩니다. 기본 표면 사용은 이 재정의를 제거합니다. 모든 변경은 실행 취소할 수 있습니다.

    표면 효과는 조명이 적용된 3D 뷰와 카메라 렌더에 나타납니다. 플랫 및 와이어프레임 표시는 의도적으로 하이라이트를 생략합니다. 블룸을 사용하면 발광 표면 주위에 글로우를 더할 수 있습니다. Godot와 glTF/GLB는 재질 값을 그대로 받으며, Unity 임포터는 거칠기를 스무스니스로 변환합니다. 대상별 제한 사항은 docs/surface-materials.md를 참고하세요.

    #에셋, 레이어, 그룹

    #에셋 라이브러리

    에셋 탭을 여세요. 폴더 추가로 .map 모델 폴더를 추가합니다. 내장 라이브러리는 항상 들어 있습니다. 에셋 필터에 입력해 검색하세요. 모델을 클릭해 선택한 다음, 더블클릭하거나 Enter를 누르거나 삽입을 클릭하면 포인터가 마지막으로 있던 위치에 추가됩니다. 모델을 뷰로 드래그할 수도 있습니다. 에셋 브러시는 하나의 그룹으로 삽입되므로 모델이 통째로 움직입니다.

    선택 영역을 에셋으로 저장은 선택한 브러시를 .map으로 라이브러리에 기록합니다. 라이브러리 에셋은 가져온 메시가 아니라 편집 가능한 일반 브러시입니다.

    #레이어

    맵 탭의 레이어 목록으로 넓은 영역을 정리합니다. 이름을 입력하고 추가를 클릭하면 레이어가 만들어지고, Enter를 누르면 현재 레이어의 이름이 바뀝니다. 각 레이어는 숨기거나, 잠그거나, 내보내기에서 제외할 수 있습니다. 여기로 이동은 선택 영역을 현재 레이어로 옮깁니다. 뷰의 컨텍스트 메뉴에도 레이어로 이동, 활성 레이어로 설정, 레이어 숨기기, 레이어만 표시가 있습니다.

    #그룹과 연결된 그룹

    Ctrl+G는 선택 영역을 그룹으로 묶고 Ctrl+Shift+G는 그룹을 해제합니다. 맵 탭의 그룹 섹션에는 그룹 목록과 열기, 이름 바꾸기, 병합, 그룹 해제, 꺼내기, 추출이 있습니다. 연결된 그룹은 편집 내용을 공유하는 복사본 집합입니다. Ctrl+Shift+D는 연결된 복제본을 만들고, 지오메트리 → 연결된 그룹 동기화는 복사본을 갱신하며, 연결 해제는 복사본을 독립시킵니다. 엔티티 탭에서는 연결된 그룹을 동기화할 때 특정 속성을 그 복사본만의 값으로 유지하도록 지정할 수 있습니다.

    #공통 스케일

    기본 내보내기 스케일은 1미터당 맵 단위 32입니다. 내장 플레이어 시작 마커는 높이가 64단위로, 2미터 기준이 됩니다. 출입구, 차량, 가구, 식물을 이 마커와 비교해 보세요. 내보내기 스케일은 꼭 필요할 때만 바꾸고, 관련 에셋끼리는 일관성을 유지하세요.

    #엔티티와 게임플레이

    자주 쓰는 엔티티 정의는 내장되어 있어 언제나 사용할 수 있습니다. 조명, 플레이어 시작 지점, 문, 버튼, 플랫폼, 트리거, 정적 소품, 사운드, 웨이포인트입니다. 엔티티 탭의 엔티티 정의로 프로젝트 FGD를 불러오면 이름이 같은 클래스는 교체되고 나머지 내장 클래스는 유지됩니다.

    #엔티티 배치

    엔티티 탭의 엔티티 브라우저에서 클래스 필터에 입력하고 클래스를 고르세요. 조명 같은 포인트 클래스는 배치를 클릭하거나 클래스를 더블클릭합니다. Insert는 선택 영역 중심에 하나를 배치합니다. 문이나 트리거 같은 브러시 클래스는 브러시를 선택하고 만들기를 클릭합니다. 클래스를 뷰로 드래그할 수도 있습니다.

    #속성

    속성 목록에서 선택한 엔티티를 편집합니다. 같은 클래스의 엔티티는 함께 편집됩니다. 속성 추가는 정의에 없을 수도 있는 키를 추가하고, 기본값은 기존 속성을 기본값으로 되돌리거나 빠진 속성을 추가합니다. 클래스에 정의되어 있지만 엔티티에 없는 속성은 흐리게 표시되며, 값을 입력하면 추가됩니다. 엔티티끼리 연결하려면 targetname과 target을 사용하세요.

    #내보내기로 할 수 있는 것

    Godot의 지시자는 네이티브 노드, 충돌 바디, 트리거 영역을 만듭니다. Unity와 Unreal은 일반적인 조명을 네이티브로 지원하며, Unreal은 PlayerStart 액터도 만듭니다. 그 밖의 데이터는 대상 임포터가 허용하는 범위에서 유지됩니다.

    문 엔티티만으로는 게임 동작이 추가되지 않습니다. 움직임, 트리거 반응, 플레이어 컨트롤러, 프로젝트 스크립트는 여전히 엔진에서 작업해야 합니다. Defold는 엔티티 속성과 충돌 오브젝트를 내보내고, Flax는 모델과 일반 엔티티를 배치합니다. 게임플레이를 만들기 전에 엔진에서 결과를 확인하세요.

    #애니메이션

    Heron Brush는 간단한 움직임을 미리 보고, 브러시 엔티티의 키프레임 애니메이션을 편집한 뒤 여러 엔진으로 내보낼 수 있습니다.

    #애니메이션 미리보기

    보기 메뉴, 애니메이션 메뉴, 그리드 설정 메뉴 또는 맵 탭의 보기 섹션에서 애니메이션 미리보기를 켜세요. start_on이 활성화되어 있으면 엔티티의 axis, speed, direction, travel, wait 속성을 사용해 func_rotate 회전과 func_shuttle 왕복 운동을 재생하며, 시작 시 재생으로 설정된 키프레임 클립도 재생합니다. 선풍기와 풍차 에셋에는 이미 회전하는 부품이 들어 있습니다.

    미리보기를 끄면 원래 자세로 돌아갑니다. 뷰를 클릭하면 선택이나 편집 전에 재생이 멈추며, 카메라 탐색은 계속 작동합니다. 미리보기는 맵, 실행 취소 기록, 내보내기를 바꾸지 않으며 물리나 게임 로직을 실행하지 않습니다.

    #키프레임 편집기

    애니메이션 → 키프레임 애니메이션 또는 그리드 설정 메뉴에서 엽니다. 뷰 아래에 도킹되며, 3D 창이 분리되어 있을 때는 그 창에 도킹됩니다. 제목 부분의 창 아이콘을 누르면 별도 창으로 옮겨지며, 프레임과 실행 취소 기록은 그대로 유지됩니다. 애니메이션 편집은 뷰를 애니메이션 자세로 전환하고, 맵 편집은 레스트 지오메트리로 돌아갑니다. 애니메이션 모드에서는 각 뷰 하단에 애니메이션 편집과 프레임 번호가 표시됩니다.

    애니메이션을 적용하려면 브러시 엔티티, 또는 브러시나 브러시 그룹을 선택하세요. 엔티티를 포함하지 않은 브러시 그룹은 애니메이션과 피벗 하나를 공유하며, 여러 엔티티를 포함한 그룹은 각각 별도의 애니메이션이 필요합니다.

    #클립

    애니메이션 선택기로 이름 있는 클립 사이를 전환합니다. 애니메이션 이름에 이름을 입력하고 다른 이름으로 저장을 클릭하면 현재 클립을 그 이름으로 복사합니다. 삭제는 클립을 제거합니다. 이동은 회전 없는 translate 클립을 만듭니다. 문 애니메이션은 현재 피벗을 중심으로 90도 회전하는 부드러운 open과 close 클립을 만듭니다. 먼저 피벗을 경첩 위치로 옮기세요. 시작 시 재생을 켜면 레벨이 시작될 때 클립이 재생되며, 문 프리셋은 이 옵션을 끕니다.

    #트랜스포트와 재생

    트랜스포트 버튼은 시작, 이전 키, 재생, 다음 키, 끝입니다. 프레임은 현재 프레임을 표시하고 설정하며, 길이 (초)는 클립 길이를 정합니다. 재생 모드는 한 번, 반복, 왕복 중 하나입니다.

    #타임라인

    타임라인에는 재생 헤드가 있는 눈금자와 위치(X, Y, Z를 함께 키로 기록) 및 각 회전 각도 RX, RY, RZ의 레인이 있습니다. 눈금자를 클릭하거나 드래그하면 재생 헤드가 이동하고 모든 뷰에서 그 자세를 미리 볼 수 있습니다. 가운데 버튼으로 드래그하면 타임라인을 팬합니다. 키를 드래그하면 시간 축에서 이동하고, Shift는 선택에 추가하며, 레인을 더블클릭하면 키를 삽입하고, Ctrl+휠로 확대/축소합니다. 곡선은 레인 대신 값 곡선을 보여 줍니다.

    그 위의 버튼은 키 추가, 제거, 복사, 붙여넣기, 복제입니다. 프레임에 스냅은 키를 정수 프레임에 맞추고, 맞추기는 클립 전체를 보여 줍니다. 키 시간 변경을 누르면 시간 배율, 오프셋 (프레임), 재생 헤드 기준 배율, 길이 늘리기, 선택한 키 시간 변경이 열립니다.

    타임라인 옆의 키 인스펙터는 선택한 키를 편집합니다. 프레임, 값(위치 키의 경우 세 좌표), 보간 방식 선형, 유지, 베지어, 들어오는 기울기와 나가는 기울기, 그리고 접선 부드럽게가 있습니다.

    #편집기의 키

    타임라인이 키보드 입력을 받을 때 Space는 재생/일시 정지, 왼쪽과 오른쪽 화살표는 한 프레임씩 이동, Ctrl+A는 모든 키 선택, Ctrl+C, Ctrl+X, Ctrl+V는 키 복사, 잘라내기, 붙여넣기, Ctrl+D는 복제, Delete는 제거, Ctrl+Z는 실행 취소, Esc는 드래그 취소입니다. 타임라인 밖에서 Esc를 누르면 애니메이션 모드를 종료합니다. 실행 취소해도 확대/축소, 선택, 재생 헤드는 그대로 유지됩니다.

    #뷰에서 포즈 잡기

    타임라인 아래 줄에는 개수와 간격을 지정하는 어니언 스키닝(주변 자세를 고스트로 표시), 피벗 좌표, 자동 키, 그리고 포즈 도구 이동, 회전, 피벗이 있습니다.

    • 키 추가는 자동 키를 켜고 재생을 일시 정지합니다. 자동 키가 켜져 있고 이동이 선택된 상태에서 3D 뷰에서 선택한 엔티티 핸들의 색깔 축을 드래그하면 현재 프레임에 위치 키가 기록됩니다.
    • 2D 뷰에서 선택한 브러시나 그 그룹의 멤버를 드래그하면 보이는 두 축을 따라 이동 키가 그리드 스냅과 함께 기록됩니다. 이때는 자동 키를 켤 필요가 없습니다.
    • 회전을 선택하고 2D 뷰에서 주황색 피벗 마커를 중심으로 브러시를 드래그하세요. 상단 뷰는 RZ, 정면 뷰는 RY, 측면 뷰는 RX에 키를 기록하며, 그리드 각도에 스냅됩니다.
    • 피벗을 선택하고 아무 2D 뷰에서나 노란색 회전 중심을 드래그하세요. 그리드에 스냅되며 깊이는 유지됩니다. 키와 레스트 지오메트리는 바뀌지 않습니다.

    2D와 3D의 청록색 경로는 피벗의 이동 경로를 보여 줍니다. 경로 점을 클릭하면 그 시간과 키를 선택하고, 드래그하면 위치를 바꿉니다. 자동 키가 켜져 있으면 3D 뷰에서도 경로 점을 드래그할 수 있습니다. 레이블은 프레임 번호를 표시하고 점선 구간은 점프를 나타냅니다. Esc는 이러한 드래그를 모두 취소하며, 실행 취소 한 번으로 드래그 전체가 되돌려집니다.

    새 애니메이션은 시간 0에 키가 있는 레스트 상태에서 시작합니다. 다른 프레임에서 자세를 바꾸면 움직임이 만들어집니다. 날카로운 L자 경로를 만들려면 시작점, 꺾이는 점, 끝점에 키를 기록하고 선형과 왕복을 사용하세요.

    #버튼을 애니메이션에 연결하기

    func_button, trigger_multiple 또는 trigger_once를 선택하세요. 엔티티 탭의 속성 위에 애니메이션 트리거가 표시됩니다. 목록에서 대상을 고르거나, 뷰에서 대상 선택을 클릭한 뒤 아무 뷰에서나 애니메이션이 있는 오브젝트를 클릭하세요. Esc로 대상 선택을 취소합니다. 대상이나 클립이 없으면 컨트롤 아래에 알려 줍니다. 링크 표시가 켜져 있으면 엔티티 링크가 대상을 가리키는 화살표로 표시됩니다.

    동작은 활성화될 때 수행할 작업을 고릅니다. 재생은 이름 있는 클립이나 선택한 애니메이션을 시작하고, 전환은 open과 close가 있으면 둘을 번갈아 실행하고 없으면 선택한 애니메이션을 다시 시작합니다. 열기와 닫기는 해당 클립을 시작하고, 일시 정지는 자세를 멈추고, 계속은 이어서 재생하며, 정지는 원래 자세로 되돌립니다. 한 번만은 클래스 기본값을 덮어씁니다. 반복 간격 (초)는 활성화 사이의 최소 시간을 정하며, 첫 번째 활성화를 지연시키지는 않습니다.

    트리거 테스트는 맵을 편집하거나 실행 취소 단계를 추가하지 않고 미리보기에서 동작을 실행합니다. 미리보기 초기화는 원래 자세를 복원하고 한 번 실행 상태와 대기 시간 상태를 지웁니다. 플레이어 충돌이나 게임 스크립트는 시뮬레이션하지 않습니다.

    #내보내기의 애니메이션

    Godot는 곡선과 움직이는 충돌을 포함해 네이티브 AnimationPlayer 및 AnimationLibrary 리소스를 내보냅니다. CharacterBody3D가 버튼 영역에 들어오면 대상이 활성화됩니다. Godot에서 이 클립을 수정해도 맵에는 반영되지 않으며 다음 내보내기 때 덮어쓰입니다.

    Raylib 내보내기는 C 플레이어가 들어 있는 <map>_animation.h와 자유 카메라 미리보기용 <map>_preview.c를 추가합니다. 빌드하려면 <map>_raylib.md를 따르세요. 미리보기에서 SPACE는 일시 정지, R은 기본 클립 재시작, N은 이름 있는 클립을 차례로 전환합니다. Defold는 문서화된 heron_*_animation 메시지와 함께 엔티티 스크립트에 재생 기능을 넣습니다. Unity의 Build Level은 HeronBrushAnimation과 키네마틱 바디를 추가합니다. Bevy 내보내기에는 heron_animation.rs와 설명서가 포함됩니다. Godot, Unity, Defold, Bevy, raylib는 트리거 링크, 한 번 실행 플래그, 반복 간격을 유지합니다. 플레이어를 등록하고 게임 자체의 버튼을 각 런타임 API에 연결하는 작업은 여전히 게임 쪽에서 해야 합니다.

    #Motion lab 예제

    시작 화면의 예제에서 motion_lab을 여세요. L자 경로 플랫폼, 리프트, 회전 플랫폼, 버튼이 달린 경첩 문이 있습니다. 옆에 있는 godot/project.godot를 Godot에서 열고 F5를 누르세요. WASD와 마우스로 플레이어를 움직이고, Space로 점프하며, 1~4로 각 스테이션으로 이동하고, R로 현재 스테이션을 다시 시작합니다. 색깔 패드를 밟으면 대상이 활성화됩니다. 함께 들어 있는 README에 다시 내보내는 방법이 설명되어 있습니다.

    #엔진으로 내보내기

    파일 → 내보내기는 내보내기 창을 엽니다. 왼쪽에는 로고와 함께 엔진 목록이 있습니다. Godot, Defold, three.js, Bevy, raylib, Unity, Unreal Engine, Flax Engine, Cocos Creator, Wavefront .obj, glTF .gltf, GLB .glb, 그리고 마지막으로 .map입니다. 오른쪽 페이지에는 대상이 받게 될 내용이 설명되어 있습니다. 쓰기는 출력하고, 검사는 출력하지 않고 레벨을 빌드해 문제를 나열하며, 닫기는 창을 닫습니다.

    내보내기는 저장과 별개입니다. .map은 계속 편집 가능한 원본으로 남습니다. 모든 컨트롤은 값이 바뀌는 즉시 해당 엔진의 설정을 저장하므로, 엔진마다 자체 설정을 유지하고 창은 마지막 상태 그대로 열립니다.

    #공통 옵션

    • 크기 조절: 미터당 단위, 기본값 32.
    • 출력 내용: 충돌 지오메트리.
    • 최적화: 정적 메시를 1024 단위 셀로 묶기, 지오메트리 내부에 가려진 면 제거, 같은 평면의 면 합치기, 충돌 모양 합치기.
    • 프로젝트 경로: 프로젝트 안에서 레벨과 리소스가 놓일 위치.
    • 도구 재질: clip, skip, origin 재질의 이름.
    • 더 보기: 노드 이름 기준, 레이어와 그룹을 부모 노드로 재구성, 삼각형 감김 순서 반전, 텍스처 좌표 뒤집기, 라이트맵 텍셀을 사용하는 베이크 라이팅용 두 번째 UV 세트 같은 엔진별 스위치.
    • 맵과 동기화 중: 맵을 저장할 때마다 다시 출력. 해당 엔진으로 한 번 내보낸 뒤에 사용할 수 있습니다. 그 내보내기에서 출력 위치가 정해지기 때문입니다.

    정적 셀은 월드 브러시를 중심점 기준으로 셀에 배정하고 각 1024 단위 셀 안에서 재질별로 합치므로, 엔진이 맵을 더 작은 단위로 컬링할 수 있습니다. 충돌은 유지되며 게임플레이 엔티티는 분리된 상태로 남습니다. 월드 메시 하나일 때보다 드로우 콜이 늘어날 수 있으므로 기본값은 꺼짐입니다. 단독 OBJ, glTF, GLB 내보내기는 셀을 사용하지 않습니다.

    #라이브 링크: Godot, Unity, Defold, Flax

    라이브 링크는 작업하는 동안 Heron Brush의 저장하지 않은 편집 내용을 엔진 에디터로 보냅니다. 단방향이므로 엔진에서 한 편집은 돌아오지 않습니다. 맵 창 하나당 라이브 링크는 하나만 실행할 수 있습니다. 엔진을 바꾸기 전에 링크를 중지하고, 바뀐 내보내기 옵션을 적용하려면 다시 시작하세요. 컨트롤은 내보내기 창의 해당 엔진 페이지에 있는 <엔진> 라이브 링크 카드에 있습니다.

    제목 표시줄의 표시기는 링크 상태를 보여 주며, 클릭하면 링크가 중지됩니다. 맵을 닫거나 다른 맵으로 바꾸면 전송이 중지됩니다. 임포트에 실패하면 문제를 해결한 뒤 링크를 다시 시작하세요.

    #Godot

    1. Godot 프로젝트로 한 번 내보내세요.
    2. Godot 애드온 설치를 클릭하세요.
    3. Godot의 프로젝트 설정 → 플러그인에서 Heron Brush Live를 활성화하세요.
    4. 라이브 링크 시작을 클릭하고 Godot 독에서 열려 있는 3D 씬에 맵을 연결하세요.

    애드온은 자신이 생성한 브랜치만 교체하며, 연결 지점의 배치와 다른 노드는 그대로 둡니다. Godot 씬은 직접 저장하고, 직접 만든 스크립트와 노드는 생성된 브랜치 밖에 두세요.

    #Unity

    1. Unity 프로젝트의 Assets 폴더 아래로 한 번 내보내세요.
    2. Unity 애드온 설치를 클릭하고 Unity가 컴파일할 때까지 기다리세요.
    3. Unity에서 Window → Heron Brush → Live Link를 여세요.
    4. 링크를 시작하고 활성 Unity 씬에 맵을 연결하세요.

    Unity 라이브 창은 열어 두세요. Play Mode와 Prefab Mode에서는 업데이트가 일시 정지됩니다. 맵 오브젝트의 Generated 자식만 교체됩니다. 생성된 파일은 편집하지 마세요.

    #Defold

    1. Defold 프로젝트로 한 번 내보내고 Defold에서 프로젝트를 열어 두세요.
    2. 라이브 링크 시작을 클릭하세요. 애드온은 필요 없습니다.
    3. Defold에서 heron_brush_live/preview.collection을 열거나 직접 만든 씬에서 참조하세요.

    링크는 별도의 생성 폴더에 기록하며 최종 내보내기와 game.project는 건드리지 않습니다. 실행 중인 게임 핫 리로드는 Defold에서 시작한 게임도 업데이트합니다. 오브젝트를 추가하거나 충돌을 바꾸면 레벨을 다시 시작해야 할 수 있습니다. 연결에 실패하면 자동으로 다시 시도합니다.

    #Flax

    프로젝트의 Content 폴더로 내보내고 Flax 애드온 설치를 클릭하세요. Flax가 컴파일할 때까지 기다린 뒤 링크를 시작하고, 열려 있는 Flax 씬에서 Tools → Heron Brush: attach live map을 선택하세요. 생성된 루트는 배치를 유지하고 다른 오브젝트는 건드리지 않습니다. 씬은 직접 저장하세요. Play Mode에서는 업데이트가 일시 정지됩니다. Tools → Heron Brush: stop live map은 수신을 일시 정지합니다.

    #공동 라이브 세션

    협업 → 라이브 세션은 다른 Heron Brush 사용자와의 세션을 호스트하거나 그 세션에 참가하는 창을 엽니다. 여러 사람이 맵 편집을 공유하는 기능으로, 엔진 라이브 링크와는 별개입니다.

    #호스트와 참가

    이름을 입력하세요. 호스트하려면 세션 호스트하기를 고르고 세션 시작을 클릭한 뒤 연결 정보 복사로 복사한 정보를 게스트에게 보내세요. 참가하려면 세션 참가를 고르고 정보를 붙여넣은 뒤 참가를 클릭하세요. 참가하면 열려 있는 맵이 호스트의 맵으로 바뀌므로 먼저 작업을 저장하세요.

    표준 빌드는 로컬 네트워크에서 작동하며, 로컬 네트워크 포트로 포트를 설정합니다. 인터넷을 통한 세션(인터넷으로 연결)에는 선택적 네트워킹 기능이 포함된 빌드가 필요합니다. 참가자들은 3D 뷰에서 서로의 카메라 마커와 이름을 볼 수 있습니다.

    창을 닫아도 세션은 계속 실행되며, 제목 표시줄 표시기에 상태가 나타납니다. 세션 중지 또는 세션 나가기로 세션을 끝냅니다. 두 사람이 같은 오브젝트를 편집하면 호스트 쪽 순서에 따라 최종 버전이 정해지며, 실행 취소도 공유되는 편집입니다. 가능하면 서로 다른 영역에서 작업하고 중간중간 저장하세요.

    #3D 표시와 보조 모니터

    #표시 모드

    맵 탭의 보기 섹션에서 뷰에 그릴 대상을 전환합니다. 브러시, 포인트 엔티티, 엔티티 모델, 엔티티 클래스 이름, 그룹 윤곽선, 패치, 재질, 제외된 면 표시, 애니메이션 미리보기, 와이어프레임, 모서리, 브러시 엔티티 윤곽선입니다. 와이어프레임은 대각선과 표면 뒤의 모서리를 포함한 삼각형 모서리를 재질 없이 그립니다. 임시 디버깅용 보기이며 내보내기나 렌더에는 영향을 주지 않습니다.

    3D 뷰의 조명, 그림자, 앰비언트 오클루전, 반사, 블룸, 스무딩은 환경설정 → 렌더러에 있습니다. 이것들은 미리보기 설정이며, 최종 이미지는 렌더 카메라 자체의 설정을 사용합니다.

    #별도의 3D 창

    보기 → 별도 창의 3D 뷰는 3D 뷰를 별도의 창으로 옮기므로 다른 모니터에 둘 수 있습니다. 카메라, 문서, 도구를 공유하며, 메인 창에서는 평면 뷰가 그 공간을 차지합니다. 이 창의 메뉴에는 재질, 솔리드 뷰, 와이어프레임, 제외된 면 표시, 애니메이션 미리보기, 모서리, 그룹 윤곽선, 포인트 엔티티, 엔티티 모델, 브러시 엔티티 윤곽선이 들어 있는 보기 하위 메뉴, 선택 영역에 초점 맞추기, 선택 영역(또는 카메라 앞의 한 점)을 중심으로 카메라를 돌리는 정면, 측면, 상단, 3D 뷰 위치에 카메라 배치, 전체 화면(F11), 이미지 렌더링, 기본 창으로 돌아가기가 있습니다. 창을 닫으면 뷰가 다시 도킹됩니다.

    #절차적 하늘

    절차적 하늘은 3D 뷰에서 기본적으로 켜져 있으며 환경설정 → 렌더러 → 조명에서 끌 수 있습니다. 렌더 카메라에는 맵과 함께 저장되는 별도의 절차적 하늘 스위치가 있습니다. 하늘, 지평선, 지면 색상은 주변 환경 설정에서 가져오며, 태양은 씬 조명을 따릅니다. 하늘에는 지오메트리가 없으며 내보내지지 않습니다.

    #렌더 카메라와 PNG 이미지

    파일 → 이미지 렌더링은 렌더 창을 엽니다. 왼쪽에는 카메라와 설정이, 오른쪽에는 설정을 바꿀 때마다 다시 그려지는 실시간 미리보기가 있습니다. 카메라는 .map 안의 에디터 전용 Render cameras 레이어에 저장되며, 이 레이어는 엔진 내보내기에서 제외됩니다.

    #카메라 배치

    3D 뷰에서 구도를 잡고 Ctrl+Alt+0(또는 Ctrl+Alt+Num0)을 누르거나 3D 뷰 위치에 카메라 배치를 클릭하세요. 선택된 카메라가 없으면 처음 저장된 카메라가 갱신되고, 카메라가 하나도 없으면 새로 만들어집니다. 이 작업은 실행 취소할 수 있으며 출력과 조명 설정은 유지됩니다. 맵에서 카메라 선택, 맵에서 카메라 불러오기, 3D 뷰를 카메라로 이동은 반대 방향으로 작동합니다. 3D 뷰의 카메라 프레임은 출력 경계를 표시하고, 3D 뷰에서 카메라 제어를 켜면 일반 탐색 조작으로 저장된 카메라를 움직일 수 있습니다.

    #설정

    • 카메라 위치: X, Y, Z, 요(yaw), 피치(pitch).
    • 출력 및 렌즈: 프리셋(Full HD, 정사각형, 세로 방향), 너비, 높이, 샘플 수, 세로 시야각, 원거리 클리핑.
    • 조명: 주광, 일몰, 흐림 중에서 고르거나 노출, 태양, 하늘, 지평선, 지면 색상, 절차적 하늘, 그림자, 앰비언트 오클루전, 블룸을 직접 설정합니다.
    • 피사계 심도: 피사계 심도 활성화, 초점 거리, 선명 범위, 블러 반경. 선택 영역에 초점 맞추기는 카메라 앞에 있는 선택한 오브젝트의 중심에 초점을 맞춥니다.

    카메라 및 설정 저장은 입력한 값을 맵에 저장합니다. 디스크에 남기려면 맵을 저장하세요.

    #렌더링

    PNG 렌더링은 저장 위치를 물은 뒤 점진적 렌더링을 시작하며, 미리보기가 샘플 단위로 채워집니다. 샘플이 많을수록 품질이 좋아지지만 시간이 더 걸립니다. 렌더링 취소는 파일을 쓰지 않고 중지합니다. 렌더러는 패스 트레이싱이 아니라 에디터의 래스터 파이프라인을 사용합니다. PNG의 배경은 불투명하며 애니메이션은 렌더링되지 않습니다. 매우 큰 이미지는 에디터를 잠시 멈추게 할 수 있습니다.

    #환경설정

    파일 → 환경설정(Ctrl+,)으로 설정을 엽니다. 변경 사항은 즉시 적용되고 저장됩니다. 사이드바에는 개요, 게임, 보기, 색상, 마우스, 키보드, 렌더러가 있습니다. 맨 위의 검색 필드에서 페이지와 관계없이 이름이나 설명으로 설정을 찾을 수 있습니다. 바뀐 설정마다 기본값으로 되돌리는 버튼이 있으며, 기본값 복원은 현재 페이지를 초기화합니다.

    #페이지

    • 개요: 자주 쓰는 설정 모음. 모양(패널 불투명도 (%), 색 구성표, 레이아웃, 언어), 편집, 보기, 매뉴얼.
    • 게임: 게임, 게임 파일의 위치, 협업에 쓸 이름. 게임은 출력할 맵 형식, 불러올 엔티티 정의, 재질 위치를 정합니다. 게임 구성은 구성 폴더 안의 games 폴더(Linux와 macOS에서는 ~/.config/heron-brush/games, Windows에서는 %LOCALAPPDATA%\heron-brush\games)와 애플리케이션 옆의 games 폴더에서 읽습니다. 패키지는 기본 제공 구성을 후자에 넣습니다.
    • 보기: 레이아웃, 색 구성표, 언어, 월드 축, 그리드 불투명도, 누출 검사 셀 크기, 매핑 잠금.
    • 색상: 뷰, 지오메트리, 핸들의 색상.
    • 마우스: 둘러보기, 팬, 이동 속도와 반전, 비행 속도, 시야각, 2D 뷰 연결, 핸들 크기.
    • 키보드: 키맵(Heron Brush 또는 Blender).
    • 렌더러: 사실적 셰이딩, 선택 윤곽선, 조명, 그림자, 앰비언트 오클루전, 반사, 블룸, 표면.

    #언어

    언어에서 시스템 설정 따르기와 번역된 모든 언어를 고를 수 있습니다. 인터페이스는 즉시 바뀝니다. 매뉴얼은 번역본이 있으면 인터페이스 언어로, 없으면 영어로 열립니다.

    #플러그인과 MCP

    #플러그인

    플러그인은 Rhai 스크립트로 에디터를 확장합니다. 파일 → 플러그인으로 플러그인 창을 엽니다. 플러그인 설치는 .rhai 파일을, 플러그인 폴더 설치는 main.rhai가 들어 있는 폴더를 설치합니다. 선택 사항인 plugin.toml 메타데이터는 플러그인과 그 설정을 설명합니다. 플러그인은 활성 플러그인과 비활성 플러그인으로 나뉘며, 플러그인 활성화로 켜거나 끕니다. 이 설정은 재시작 후에도 유지됩니다. 플러그인 다시 불러오기는 디스크에서 스크립트를 다시 읽고 패널 값을 초기화합니다.

    활성 플러그인은 맵 탭의 플러그인 섹션에도 설정, 동작 버튼(실행), 출력과 함께 나타납니다. 동작은 선택 영역에, 아무것도 선택하지 않았으면 전체에 작동하며 실행 취소 한 단계로 처리됩니다. 기본 포함된 Selection inspector는 개수와 위로 이동, 아래로 이동 동작을 보여 줍니다.

    #MCP

    협업 → 에이전트용 서버 시작 (MCP)을 사용하면 AI 에이전트나 다른 도구가 Model Context Protocol을 통해 열려 있는 에디터를 조작할 수 있습니다. 창에는 로컬 주소와 복사가 표시되고, 서버 중지로 서버를 끝냅니다. 서버가 실행되는 동안 제목 표시줄에 MCP 활성이 표시됩니다. --mcp 명령줄 옵션은 창 없이 같은 인터페이스를 실행합니다. 클라이언트는 지오메트리, 에셋, 속성, 애니메이션, 내보내기, 세션용 도구를 찾을 수 있습니다. MCP와 에디터 플러그인은 서로 다른 인터페이스입니다.

    #명령줄

    프로그램 이름은 heron-brush입니다. 옵션 없이 실행하면 시작 화면이 열립니다.

    #파일 열기

    heron-brush map.map [entities.fgd] [materials/]는 맵을 열며, 선택적으로 엔티티 정의와 재질 폴더를 함께 지정할 수 있습니다. 빈 인수를 주면 해당 항목을 건너뜁니다. 예: heron-brush map.map "" materials/. 에디터가 이미 실행 중이면 맵이 그 에디터에서 열리며, --new-instance를 쓰면 대신 별도의 창이 열립니다.

    #명령

    • --help 또는 -h: 사용법 출력. --version 또는 -V: 버전 출력.
    • --mcp: 창 없이 표준 입출력으로 MCP를 제공합니다.
    • --merge-map <base> <ours> <theirs> [<output>]: git용 .map 파일 3방향 병합. 출력 대상은 기본적으로 ours입니다. 충돌은 화면에 출력되며 0이 아닌 종료 코드를 반환합니다.
    • --obj-to-map <in.obj> <out.map> [size] [thickness] [snap] [material]: 메시를 브러시로 변환합니다. size는 맵 단위로 나타낸 가장 긴 변의 길이(기본값 256), snap은 꼭짓점을 맞출 그리드(0이면 없음)이며, solid 또는 layered라는 단어를 지정하면 얇은 쐐기 대신 그리드 상자나 볼록 판을 만듭니다.
    • --render-preview <in.map> <out.png> [size]: 맵의 PNG 썸네일을 출력합니다. 기본값은 512픽셀입니다.
    • --run-script <script.rhai> <in.map> [out.map] [key=value ...]: 모든 것을 선택한 상태로 맵에 플러그인 스크립트를 실행하고 결과를 출력합니다(기본값은 입력 파일에 덮어쓰기). key=value는 플러그인 설정값을 지정합니다.

    #문제 해결

    #무언가 이상해 보일 때

    • 재질 누락: 재질 폴더나 패키지, 그리고 내보내기의 프로젝트 경로를 확인하세요.
    • 모델 크기가 맞지 않음: 64단위 플레이어 마커 및 내보내기 스케일과 비교하세요.
    • 그라디언트 방향이 잘못됨: 그라디언트 각도와 면의 방향을 확인하세요.
    • 엔진 씬이 비어 있음: 내보내기 경고를 읽고 대상의 임포트 안내를 따르세요.
    • 라이브 링크가 대기 중: 애드온이 설치되었는지, 씬이 연결되었는지, 업데이트가 일시 정지되지 않았는지 확인하세요.
    • 면 없이 선만 보임: 맵 탭의 보기 섹션에서 와이어프레임을 끄거나, 3D 창의 메뉴에서 재질 또는 솔리드 뷰를 고르세요.
    • 뷰에서 오브젝트가 사라짐: Ctrl+Shift+I로 숨긴 오브젝트를 표시하고, 레이어와 보기 섹션의 필터를 확인하세요.
    • 키가 작동하지 않음: 먼저 뷰를 클릭해 키보드 입력을 받게 하고, 환경설정 → 키보드에서 키맵을 확인하세요.
    • 편집이 실패함: 실행 취소하고 지오메트리를 단순화한 뒤 맵 탭의 문제 섹션에서 맵 검사와 누출 검사를 사용하세요.
    • 파일 관리자에서 맵이 열리지 않음: 이미 실행 중인 에디터로 전달되었을 수 있으니 그 창을 찾아보세요.

    #설정과 백업

    환경설정, 최근 맵, 별표, 내보내기 설정, 플러그인은 구성 폴더에 저장됩니다. Linux와 macOS에서는 ~/.config/heron-brush, Windows에서는 %LOCALAPPDATA%\heron-brush입니다. 자동 저장 백업은 각 맵 옆의 autosave 폴더에 있습니다.

    #버그 신고

    에디터 버전(도움말 → 정보), 운영 체제, 문제를 보여 주는 작은 맵, 정확한 재현 단계를 함께 보내 주세요. 출력 창(Ctrl+4)에 무엇이 잘못되었는지 나와 있는 경우가 많습니다. 이것저것 시도하기 전에 사본을 저장하세요.

    #이 매뉴얼 사용하기

    왼쪽 목차에서 장을 고르세요. Ctrl+F는 목차를 표시하고 검색 필드로 이동합니다. Esc는 검색어를 지우고, 검색어가 비어 있으면 매뉴얼을 닫습니다. 목차는 장 목록을 숨기거나 표시하고, 텍스트 크기는 글꼴 크기를 바꿉니다. 두 설정 모두 기억됩니다. 맨 위의 언어 목록에서 사용 가능한 번역본 사이를 전환합니다.
