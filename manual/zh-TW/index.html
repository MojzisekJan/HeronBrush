    #入門

    Heron Brush 是以筆刷為基礎的關卡編輯器。您可以用凸面筆刷搭建關卡、為筆刷的面塗色並貼上材質、放置實體、為門和平台製作動畫，再把成果匯出到遊戲引擎。它也內建素材、參數化形狀、與引擎編輯器的即時連結、多人共同編輯的工作階段，以及靜態影像算繪。本手冊隨應用程式一起安裝，離線也能閱讀。

    在 macOS 上，本手冊中提到 Ctrl 的地方都可以改用 Cmd，Alt 則是 Option 鍵。

    #歡迎畫面

    Heron Brush 在沒有開啟地圖的情況下啟動時，會顯示歡迎畫面。左側有 繼續（上次開啟的地圖）、新增地圖、用來開啟現有 .map 的 瀏覽，以及 遊戲、使用手冊 和 偏好設定。右側是附縮圖的最近使用地圖清單，下方接著 範例。星號（保持在最上層）會把地圖固定在清單頂端；垃圾桶（移到垃圾桶）會把檔案移到系統的垃圾桶，之後仍可還原。方向鍵可在畫面中移動，Enter 會開啟目前聚焦的項目。隨時都可以用 檔案 → 歡迎 回到這個畫面。

    #您的第一張地圖

    1. 在歡迎畫面選擇 新增地圖，或使用 檔案 → 新增地圖（Ctrl+N）。
    2. 在工具列中選取筆刷工具（B），在 2D 視圖中拖曳，畫出所選的形狀。再到另一個 2D 視圖確認它的深度。
    3. 選取筆刷並拖曳來移動它。在 面 分頁中為它指定材質或顏色。
    4. 用 Ctrl+S 儲存原始地圖。準備好在遊戲中使用時，開啟 檔案 → 匯出，為您的引擎寫出場景。

    #檔案與儲存

    .map 檔案是您可以編輯的原始檔。請經常儲存：匯出、即時連結和算繪都不會替您儲存地圖。檔案 → 另存新檔（Ctrl+Shift+S）在您省略副檔名時會自動加上 .map。檔案 → 還原為已儲存的地圖 會捨棄未儲存的變更並重新載入檔案。如果在有未儲存變更時關閉視窗或開啟另一張地圖，Heron Brush 會詢問要 儲存、捨棄 還是 取消。

    已儲存過的地圖有未儲存的變更時，每十分鐘會在地圖旁的 autosave 資料夾寫入一份編號備份，並保留最新的 50 份。

    在 Heron Brush 已經執行時開啟地圖，地圖會交給正在執行的視窗，該視窗會移到最前面。如果想要另開一個視窗，請在命令列加上 --new-instance（請參閱「命令列」）。

    #介面

    主視窗包含：上方有選單的標題列、其下的工具列、地圖視圖、右側的檢閱器，以及底部的狀態列。

    #標題列與選單

    標題列顯示標誌、選單、中間的地圖名稱，以及視窗按鈕。在 macOS 上，常見的紅、黃、綠按鈕位於左側。拖曳標題列可以移動視窗，按兩下則可最大化。有工作在背景執行時，標題列尾端附近會出現指示器：引擎即時連結、即時工作階段或 MCP 已啟用。按一下指示器可以停止即時連結，或開啟對應的視窗。

    • 檔案：歡迎、新增地圖（Ctrl+N）、開啟地圖（Ctrl+O）、儲存（Ctrl+S）、另存新檔（Ctrl+Shift+S）、還原為已儲存的地圖、匯出、算繪影像、外掛程式和偏好設定（Ctrl+,）。
    • 編輯：復原（Ctrl+Z）、重做（Ctrl+Shift+Z）、剪下、複製、貼上、再製（Ctrl+D）、刪除、全選（Ctrl+A）、重複上次的指令（Ctrl+R）和清除可重複的指令。
    • 檢視：在獨立視窗中顯示 3D 視圖、前往、貼齊格線（Alt+0）、顯示格線（0）、預覽動畫和顯示省略的面。
    • 幾何體：插入 3D 文字、接合角落、將面轉換為曲面片、將選取範圍移出其實體和同步連結群組。
    • 動畫：關鍵影格動畫、預覽動畫和依 3D 視圖放置攝影機（Ctrl+Alt+0）。
    • 地圖：載入、重新載入和卸載點檔案；載入、重新載入和卸載入口檔案。這些檔案會顯示地圖編譯器寫出的洩漏路徑和入口（portal）。
    • 協作：即時工作階段和為 AI 代理提供服務（MCP）。
    • 說明：使用手冊和關於。

    #工具列

    工具列收納了所有工具。第一組是最常用的：選取、筆刷、裁切、頂點、邊、面、旋轉和縮放。第二組包含斜切、組合、掃掠、控制點、圓角和塗色。將滑鼠游標停在按鈕上，可以看到它的名稱和快速鍵。再按一次目前使用中的工具，就會回到選取工具。

    工具之後是 水平翻轉 和 垂直翻轉，接著是兩個開關：鎖定 會在筆刷移動時保持材質的貼圖對應，UV 則在筆刷旋轉時保持（用 U 切換）。再來是目前工具本身的設定：筆刷工具會顯示形狀及其選項，圓角工具會顯示半徑、面數、角和 套用。最右端是工具名稱、格線大小（格線 16 等；按一下可選擇其他大小），以及 格線設定 選單，內含貼齊格線、顯示格線、預覽動畫、顯示省略的面和關鍵影格動畫。

    #地圖視圖

    共有四個視圖：3D 視圖和三個平面視圖，分別是俯視（XY）、前視（XZ）和側視（YZ）。偏好設定 → 檢視 → 版面配置 可以選擇單窗格、雙窗格、三窗格或四窗格。拖曳分隔線可以調整窗格大小。在視圖中按一下，鍵盤輸入就會交給該視圖。Space 會讓一次只顯示一個視圖的窗格切換到下一個視圖，Ctrl+Space 會把目前接收鍵盤輸入的視圖最大化，再按一次則恢復原本的版面。

    在任一視圖中按右鍵（不要拖曳），會開啟針對選取範圍和游標下物件的右鍵選單。其中提供群組、圖層、連結群組、建立實體、將筆刷移入或移出實體、複製材質名稱，以及在材質瀏覽器中顯示該材質等功能。

    #檢閱器

    右側的檢閱器有四個分頁。拖曳它的左緣可以調整寬度。

    • 地圖（Ctrl+1）：圖層、群組、外掛程式、問題、檢視篩選和標籤。
    • 實體（Ctrl+2）：實體瀏覽器、實體定義、所選實體的屬性，以及按鈕和觸發器專用的動畫觸發器。
    • 面（Ctrl+3）：UV、材質、顏色、掃掠、圓角、曲面片，以及內縮與倒角。每個區段都可以收合。
    • 素材：可重複使用的筆刷模型庫。

    Ctrl+5 會隱藏或顯示檢閱器，Ctrl+Alt+T 會隱藏或顯示工具列，讓視圖有更多空間。

    #狀態列與輸出窗格

    底部的狀態列會顯示編輯器的最新訊息，錯誤以紅色表示。按一下狀態列或按 Ctrl+4，可以開啟包含完整訊息記錄的輸出窗格。大多數指令都會在這裡回報執行結果，例如裁切了多少個筆刷。

    #對話框與外觀

    偏好設定、匯出和算繪影像等對話框會以獨立視窗開啟。偏好設定 → 檢視 → 色彩配置 可以選擇跟隨系統、淺色或深色。概覽頁面上的 面板不透明度（%） 可以讓面板在視圖上呈半透明。視窗會依照您的系統風格繪製自己的按鈕：macOS 上是原生樣式，Windows 上是 Windows 11 樣式，Linux 上則是 GNOME 樣式。

    #導覽與鍵盤

    #在 3D 視圖中移動

    按住滑鼠右鍵拖曳可以環顧四周。用中鍵拖曳可以平移。滾輪會向前或向後移動。W、A、S 和 D 分別向前、向左、向後和向右飛行，Q 上升，X 下降；按住 Shift 可以加大步幅。在偏好設定 → 滑鼠中開啟 Alt + 中鍵拖曳可移動攝影機 後，按住 Alt 再用中鍵拖曳會沿視線方向移動。速度、反轉和視野都在偏好設定 → 滑鼠中設定。

    #在 2D 視圖中移動

    用中鍵拖曳可以平移，用滾輪則以游標為中心縮放。平移或縮放某個平面視圖時，其他平面視圖會保持對齊；這由偏好設定 → 滑鼠中的 連動 2D 視圖 控制。Ctrl+Alt+Z 會重設縮放，Ctrl+Shift+U 會把平面視圖重設回原點。

    Ctrl+U 會在每個視圖中框選顯示選取範圍。檢視 → 前往（Ctrl+Alt+M）可以把攝影機移到輸入的座標、選取地圖檔中某一行的物件，或依輸入的數值移動選取範圍。

    #格線與貼齊

    + 和 - 會變更格線大小，數字鍵 1 到 9 則直接選擇 1 到 256 單位的大小。0 或 # 會顯示或隱藏格線，Alt+0 會開啟或關閉貼齊。S 會把所選筆刷的頂點貼齊目前的格線，Ctrl+Shift+V 會貼齊到整數單位，Ctrl+Alt+Shift+V 則貼齊到格線。

    #常用快速鍵

    • Ctrl+S：儲存地圖。Ctrl+Shift+S：另存新檔。
    • Ctrl+Z：復原。Ctrl+Shift+Z 或 Ctrl+Y：重做。
    • Ctrl+C、Ctrl+X、Ctrl+V：複製、剪下和貼上。貼上會把物件放在游標位置；Ctrl+Alt+V 會保留原本的座標。選取了面時，複製會取得它們的材質和 UV 設定。
    • Ctrl+D：再製。Ctrl+Shift+D：建立群組的連結複本。
    • Delete 或 Backspace：刪除選取範圍。
    • Esc：取消目前的拖曳、在使用中的工具裡退回上一步、回到選取工具，最後清除選取範圍。Shift+Esc 會直接回到選取工具。
    • Ctrl+R：重複上次可重複的指令。Ctrl+Shift+R：清除這些指令。
    • Ctrl+Alt+0 或 Ctrl+Alt+Num0：將算繪攝影機放到 3D 視圖的位置。
    • F5：重新載入材質。F6：重新載入實體定義。

    #選取快速鍵

    • Ctrl+A：全選；在使用頂點、邊或面工具時則選取所有控制點。Ctrl+Shift+A：取消選取。Ctrl+Alt+A：反轉選取範圍。
    • Ctrl+B：選取同一實體或群組中的其他物件。
    • Ctrl+T：選取所選筆刷接觸到的所有物件。Ctrl+E：選取它們內部的所有物件。Ctrl+Shift+E：選取沿視圖軸向、位於它們範圍內的所有物件。這些指令會用掉作為選取依據的筆刷。
    • Ctrl+I：隔離選取範圍。Ctrl+Alt+I：隱藏選取範圍。Ctrl+Shift+I：重新顯示所有物件。
    • Ctrl+G：建立群組。Ctrl+Shift+G：解散群組。

    #變形快速鍵

    • 方向鍵和 Page Up / Page Down 會依它們在目前視圖中指向的方向，將選取範圍移動一個格線單位。搭配 Ctrl 會在移動的同時再製，搭配 Alt 則改為旋轉。
    • Alt+X、Alt+Y、Alt+Z：繞該軸旋轉四分之一圈；加上 Shift 則反方向旋轉。
    • Ctrl+F：沿視圖左右翻轉；Ctrl+Alt+F：上下翻轉。Ctrl+Shift+X 和 Ctrl+Shift+Y 沿 X 或 Y 鏡像。
    • Insert：在選取範圍中心放置一個點實體。
    • Tab：選取筆刷時，依序循環切換 選取 → 頂點 → 邊 → 面 → 選取。

    #Blender 按鍵配置

    偏好設定 → 鍵盤 → 按鍵配置 提供 Heron Brush（預設值，本手冊全篇都使用它）和 Blender 兩種。使用 Blender 時：G 選取並移動，R 旋轉，S 縮放，E 掃掠，1、2 和 3 選擇頂點、邊和面工具，K 裁切，B 框選，A 全選，Alt+A 取消選取，X 刪除，Shift+D 再製，H 隱藏，Alt+H 顯示全部，Ctrl+Shift+Z 重做。其餘操作兩者都相同。

    #筆刷與建模工具

    筆刷是由平面定義的凸面實體。複雜的物件請用多個簡單的筆刷組成，不要試圖讓單一筆刷變成凹面。簡單的形狀就足夠時，請盡量減少筆刷數量。

    #繪製筆刷

    選擇筆刷工具（B），在視圖中拖曳。工具列會顯示 要繪製的形狀：長方體、樓梯、拱形、圓柱、圓錐、球體（UV）、球體（二十面體）和插入 3D 文字。Alt+1 到 Alt+7 可以直接選擇形狀。視形狀而定，工具列會顯示 挖空 和 厚度：，樓梯的 階高： 和 方向：，圓形形狀的 軸：、邊數： 和圓周模式，球體的 環數：，以及二十面體的 精確度：。請在拖曳前設定好選項，並在不只一個視圖中檢查結果。

    #選取

    按一下筆刷即可選取，按住 Ctrl 再按一下可以加入選取範圍。從空白處拖曳會畫出選取框。在 3D 視圖中，按住 Shift 再按一下可選取單一個面，按住 Ctrl+Shift 再按一下可加選更多面。拖曳已選取的筆刷會移動它；拖曳未選取的筆刷則只選取並移動那一個。

    在 3D 視圖中，按住 Shift 拖曳已選取筆刷的某個面，可以將它擠出。按住 Alt 按一下另一個面，可以把所選面的材質和對齊複製過去；Alt+Ctrl 只複製材質，Alt+Shift 則複製旋轉。

    #塑形工具

    • 選取（Esc）：選取並移動。
    • 頂點（V）、邊（E）、面（F）：拖曳角點、邊或面。按住 Shift 從邊或面的中間拖曳，會在該處新增一個角點。Delete 會刪除所挑選的角點。
    • 旋轉（R）、縮放（T）、斜切（G）：用控制點變形選取範圍。
    • 裁切（C）：依序點選兩個或三個點來定義切割平面。Enter 執行切割，Ctrl+Enter 選擇要保留哪一側，Backspace 或 Esc 會移除最後一個點。
    • 組合（N）：在一個體積周圍放置點，然後按 Enter，用這些點建立凸面筆刷。Backspace 會移除最後一個點。
    • 掃掠（Y）：請參閱下方的掃掠一節。
    • 控制點（P）：調整曲面片的控制網格。
    • 圓角（O）：按一下某條邊即可將它倒圓，或用對應的工具挑選邊或頂點後按 Enter。面數越多，結果越平滑，幾何體也越多。
    • 塗色（K）：請參閱「材質與 UV」。

    #組合筆刷

    • Ctrl+J：將所選筆刷合併為它們的凸包。
    • Ctrl+K：從所選筆刷接觸到的筆刷中減去所選筆刷。
    • Ctrl+Shift+K：將選取範圍挖空，牆壁厚度為一個格線單位。
    • Ctrl+L：取選取範圍的交集。

    #掃掠、圓角、曲面片與倒角

    掃掠 會從所選的面沿路徑建立幾何體。先選取面（在掃掠工具中按住 Alt 按一下），再到面分頁的掃掠區段設定 行程、轉向（軸和角度）、縮放、階數 和 路徑（整數或自由對齊；弧形、直線或 S 形彎），然後按 掃掠。控制項下方的說明會告訴您將建立多少個筆刷。

    圓角 區段會依 半徑、面 和 角（斜接或圓角）將所挑選的邊倒圓；只用一個面時會形成倒斜角。

    曲面片 會顯示所選曲面片的 欄 和 列，並有按鈕可以新增或移除一對。幾何體 → 將面轉換為曲面片（Ctrl+P）會從所選的面建立曲面片。

    內縮與倒角 作用於所選的面：內縮 會從邊緣向內縮小面，深度 會把面推出（數值為負時則推入）。倒角面 會同時套用兩者；第三個按鈕則依深度的正負，加上一塊面板或切出一個凹槽。接合角落 會開啟對話框，以斜接或圓角將兩個筆刷接合在一個角落，並提供預覽。

    #3D 文字

    幾何體 → 插入 3D 文字（也是筆刷工具形狀清單中的最後一項）會用文字建立筆刷。它使用 Heron Block，這是一款內建的多邊形字型，具有切角、比例字寬和捷克語重音符號；小寫字母會使用大寫字形。輸入 文字，設定 高度（大寫字母高度；重音符號會高出這個高度）和 深度，觀察即時預覽，然後按 插入。

    如果某項操作無法產生有效的幾何體，請調整它的尺寸，或復原後簡化形狀。

    #材質與 UV

    #載入與套用材質

    開啟面分頁的 材質 區段。載入資料夾 會加入一個圖片資料夾，載入 .wad 會加入一個紋理套件；兩者都會出現在 材質集 底下，按叉號即可移除。在 篩選材質 中輸入文字可以縮小清單範圍。按一下某個材質將它設為目前材質，再按 套用至選取範圍 就會把它套用到每個選取的面。選取 提供選取使用它的筆刷和選取使用它的面。取代 會在整張地圖或僅在選取範圍內，將某個材質換成另一個。

    塗色 工具（K）會把目前的材質套用到游標下的面：按一下為單一個面塗色，按兩下為整個筆刷塗色，按住 Shift 再按一下則像滴管一樣，把該面的材質取為目前材質。

    #UV 編輯器

    面分頁的 UV 區段會顯示所選面的材質和輪廓。畫布上的滑鼠操作如下：

    • 滾輪以游標為中心縮放。用右鍵或中鍵拖曳可以平移。按兩下右鍵會重新框選顯示該面；選取另一個面時會自動框選顯示它。
    • 用左鍵拖曳會移動材質，而面的輪廓保持不動。圓環用於旋轉貼圖對應，角落的控制點用於縮放，中心的控制點則設定這些變更的原點。
    • 在圖塊邊緣按住 Alt 用左鍵拖曳可以斜切，按住 Shift 用中鍵拖曳也一樣。
    • 每次拖曳都是一個復原步驟，Esc 會取消進行中的拖曳。

    畫布下方是 偏移、縮放、角度，以及遊戲有用到時的 內容旗標、表面旗標 和 表面值。按鈕有 重設、依世界座標重設、符合、水平翻轉、垂直翻轉 和兩個 90° 旋轉。對齊 會讓材質沿著面的其中一條邊轉向（再按一次換下一條邊，按住 Shift 則換上一條）。四個靠齊按鈕會把材質推向某一條邊。符合 U 和 符合 V 會縮放材質，讓整數個複本剛好覆蓋該面；再按一次會換下一個數量，按住 Ctrl 則保留裁切貼圖（trim sheet）的細分。

    #UV 按鍵

    選取了面時，方向鍵會移動材質，[ 和 ] 會將它旋轉 15°，, 和 . 會將縮放減半或加倍，Ctrl+F 和 Ctrl+Alt+F 會翻轉它，Shift+R 會重設它，Alt+Shift+R 會依世界座標軸重設，Ctrl+Shift+F 則讓它符合每個面。

    工具列中的 鎖定 會在筆刷移動時保持貼圖對應，UV（U）則在筆刷旋轉時保持。

    #工具材質

    • skip：將標記的面從引擎匯出中移除。
    • clip：建立沒有可見幾何體的碰撞。
    • origin：標記筆刷實體的旋轉軸心。

    這些名稱可以在匯出視窗的 工具材質 卡片中變更。對於您確定會被遮住的面，請使用 skip。

    #匯出時省略面

    選取一個面，然後在 UV 區段中開啟 匯出時省略此面。UV 預覽會以橘色斜線標示它。它的材質和塗色仍會保存，筆刷也仍然封閉、可以編輯。匯出的算繪網格會省略該面，但保留碰撞。立方體只留下一個四邊形時，會產生兩個算繪三角形。這不會讓面變成雙面，也不會合併網格。

    省略被覆蓋的面 會標記被靜態筆刷完全覆蓋的面，包括相同且相貼的面以及被包住的筆刷。它作用於所選的筆刷；未選取任何物件時，則作用於所有可見且未鎖定的世界幾何體。筆刷實體、透明材質，以及已經有省略面的筆刷會被略過。部分被覆蓋的面不會被分割。只要一次復原就能還原全部。檢視 → 顯示省略的面 會在編輯器視圖中隱藏或顯示這類面；點選時仍會以整個筆刷為準。

    #顏色與漸層

    面分頁的 顏色 區段會在面的材質上塗上純色或漸層。這在規劃關卡草模和製作風格化美術時很實用。塗色的面在視圖中會保持真實的顏色；選取範圍則以外框表示。

    #調色盤與混合顏色

    按一下十二個調色盤色塊中的一個，即可用它為所選的面或所選的整個筆刷塗色。不透明度 以百分比設定下一次塗色的不透明程度。混合 有一個顏色按鈕，可以開啟顏色選擇器；在選擇器中拖曳時，選取範圍會即時跟著變化，或按 塗色 以一個步驟套用混合顏色。返回材質 會移除塗色，讓面重新顯示材質。區段頂端的說明會告訴您選取了什麼，以及它目前的外觀。

    #顏色選擇器

    編輯器中的每個顏色按鈕都會開啟同一個選擇器。在方塊中拖曳可以選擇飽和度和亮度，在旁邊的色條中拖曳則選擇色相。下方有 R、G 和 B 數值，以及顏色具有不透明度時的 不透明度 滑桿。十六進位欄位接受 #RRGGBB 或 #RRGGBBAA；文字不是有效的顏色時會變成紅色。複製 會把十六進位色碼放到剪貼簿。按一下選擇器外面即可關閉它。

    #漸層

    漸層 可以選擇線性漸層或放射狀漸層，旁邊的按鈕會把顏色頭尾對調。每個色標都有一個顏色按鈕和 位置（%），兩端之間的色標還有移除按鈕。新增色標 會在最大的間隔中加入一個色標；一個漸層最多可以有八個色標。漸層角度 設定線性漸層的方向，並附有 +45° 和 −45° 按鈕。

    預覽下方有一條軌道，每個色標都有一個標記。按一下軌道可以新增色標，按一下標記可以開啟它的選擇器，拖曳標記可以移動它，在標記上按右鍵則可以移除它。軌道下方的三個色塊是預設集：暖色漸層、冷色漸層和灰階漸層。對漸層所做的變更會即時套用到選取範圍。

    漸層的方向很重要：請讓它順著屋頂斜面或彎曲的物件，而不是橫跨不相關的面。塗色後請從兩側檢查模型。

    #表面材質

    表面材質 設定 粗糙度（0 為光滑，100 為霧面）、金屬度（木材、石材或塑膠為 0，金屬為 100）和 自發光（0 到 8；表面會以自身的顏色發光，包括漸層，但不會照亮附近的物件）。變更會即時套用到所選的面或筆刷。使用預設表面 會移除這些覆寫設定。所有變更都可以復原。

    表面效果會顯示在有光照的 3D 視圖和攝影機算繪中。平面和線框顯示刻意不呈現高光。光暈可以在自發光表面周圍加上光芒。Godot 和 glTF/GLB 會收到材質數值，Unity 匯入器則會把粗糙度轉換為平滑度。各匯出目標的限制請參閱 docs/surface-materials.md。

    #素材、圖層與群組

    #素材庫

    開啟 素材 分頁。用 新增資料夾 加入一個 .map 模型資料夾；內建素材庫則一直都在。在 篩選素材 中輸入文字即可搜尋。按一下模型將它選取，然後按兩下、按 Enter 或按 插入，就會把它加到游標最後所在的位置。您也可以把模型拖曳到視圖中。素材的筆刷會以一個群組插入，讓模型整體一起移動。

    將選取範圍儲存為素材 會把所選的筆刷以 .map 寫入素材庫。素材庫中的素材是一般可編輯的筆刷，而不是匯入的網格。

    #圖層

    地圖分頁的 圖層 清單用來整理大型區域。輸入名稱後按 新增 可以建立圖層，按 Enter 則重新命名目前的圖層。每個圖層都可以隱藏、鎖定或排除在匯出之外。移到這裡 會把選取範圍移入目前的圖層。視圖中的右鍵選單也提供移至圖層、設為作用中圖層、隱藏圖層和隔離圖層。

    #群組與連結群組

    Ctrl+G 會將選取範圍建立為群組，Ctrl+Shift+G 則解散群組。地圖分頁的 群組 區段會列出群組，並提供 開啟、重新命名、合併、解散群組、移出 和 擷取。連結群組是一組共用編輯的複本：Ctrl+Shift+D 會建立連結複本，幾何體 → 同步連結群組 會更新各個複本，取消連結 則讓某個複本獨立出來。在實體分頁中，可以讓某個屬性在連結群組同步時保留為該複本自己的值。

    #共用的比例

    預設的匯出比例是每公尺 32 個地圖單位。內建的玩家起點標記高 64 單位，相當於 2 公尺的參考高度。請以它為基準比較門口、車輛、家具和植物。只有在確實需要時才變更匯出比例，並讓相關素材保持一致。

    #實體與遊戲玩法

    常用的實體定義都已內建且隨時可用：燈光、玩家起點、門、按鈕、平台、觸發器、靜態道具、音效和路徑點。在實體分頁中用 實體定義 載入專案的 FGD 時，會取代同名的類別，並保留其他內建類別。

    #放置實體

    在實體分頁的 實體 瀏覽器中，於 篩選類別 輸入文字並選擇一個類別。對於燈光這類點類別，按 放置 或按兩下該類別；Insert 會在選取範圍中心放置一個。對於門或觸發器這類筆刷類別，請先選取筆刷，再按 產生。類別也可以直接拖曳到視圖中。

    #屬性

    屬性清單用來編輯所選的實體。相同類別的實體會一起編輯。新增屬性 可以加入定義中可能沒有的鍵；預設值 可以把現有屬性還原為預設值，或補上缺少的屬性。類別有定義但實體尚未設定的屬性會以淡色顯示；輸入數值即可加入。請使用 targetname 和 target 來連結實體。

    #匯出能做到什麼

    Godot 的指示會建立原生節點、碰撞體和觸發區域。Unity 和 Unreal 支援原生的常用燈光，Unreal 還會建立 PlayerStart actor。其他資料會在目標匯入器允許的範圍內保留。

    單獨一個門實體並不會加入遊戲行為。移動、觸發反應、玩家控制器和專案指令碼仍需要在引擎中處理。Defold 會匯出實體屬性和碰撞物件；Flax 會放置模型和通用實體。在以匯出結果建構遊戲玩法之前，請先在引擎中檢查它。

    #動畫

    Heron Brush 可以預覽簡單的運動、編輯筆刷實體的關鍵影格動畫，再將它們匯出到多種引擎。

    #預覽動畫

    在檢視選單、動畫選單、格線設定選單或地圖分頁的檢視區段中開啟 預覽動畫。當 start_on 啟用時，它會依實體的 axis、speed、direction、travel 和 wait 屬性播放 func_rotate 的旋轉和 func_shuttle 的來回運動，也會播放設為啟動時播放的關鍵影格片段。風扇和風車素材本身已包含旋轉的部件。

    關閉預覽會還原原本的姿勢。在視圖中按一下，會先停止播放，再進行選取或編輯；攝影機導覽仍可正常使用。預覽不會變更地圖、復原記錄或匯出結果，也不會執行物理或遊戲邏輯。

    #關鍵影格編輯器

    用 動畫 → 關鍵影格動畫 或從格線設定選單開啟它。它會停駐在視圖下方；3D 視窗獨立時則停駐在 3D 視窗中。標題中的視窗圖示會把它移到獨立的視窗；目前的影格和復原記錄都會保留。編輯動畫 會讓視圖切換到動畫姿勢，編輯地圖 則回到靜止時的幾何體。在動畫模式中，每個視圖底部都會顯示 編輯動畫 和影格編號。

    選取一個筆刷實體，或一個筆刷或筆刷群組，即可為它製作動畫。單層的筆刷群組共用一個動畫和軸心；包含多個實體的群組則需要分別製作動畫。

    #片段

    動畫 選擇器可以在具名的片段之間切換。在 動畫名稱 中輸入名稱並按 另存為，即可用該名稱複製目前的片段；刪除 會移除片段。平移 會建立一個不含旋轉的 translate 片段。門動畫 會建立平滑的 open 和 close 片段，繞目前的軸心轉動 90 度；請先把軸心移到鉸鏈的位置。啟動時播放 會讓片段在關卡開始時播放；門的預設集會將它關閉。

    #播放控制

    播放控制按鈕有 開始、上一個關鍵影格、播放、下一個關鍵影格 和 結束。影格 會顯示並設定目前的影格，長度（秒） 設定片段的長度。模式有 一次、循環 或 來回。

    #時間軸

    時間軸有一把附播放頭的尺規，以及 位置（X、Y 和 Z 一起設定關鍵影格）和各個旋轉角度 RX、RY 與 RZ 的軌道。在尺規上按一下或拖曳可以移動播放頭，並在每個視圖中預覽該姿勢。用中鍵拖曳可以平移時間軸。拖曳關鍵影格可以在時間上移動它們；Shift 會加入選取範圍；在軌道上按兩下會插入關鍵影格；Ctrl+滾輪可以縮放。曲線 會改為顯示數值曲線，而不是軌道。

    上方的按鈕有 新增關鍵影格、移除、複製、貼上 和 再製。貼齊影格 讓關鍵影格維持在整數影格上，符合 會顯示整個片段。調整關鍵影格時間 會開啟 時間縮放、偏移（影格）、從播放頭縮放、延長長度 和 調整選取項目的時間。

    時間軸旁的關鍵影格檢閱器用來編輯所選的關鍵影格：影格、值（或位置關鍵影格的三個座標）、內插方式 線性、保持 或 貝茲、入切線斜率 和 出切線斜率，以及 平滑切線。

    #編輯器中的按鍵

    時間軸接收鍵盤輸入時：Space 播放或暫停，左右方向鍵前進或後退一個影格，Ctrl+A 選取所有關鍵影格，Ctrl+C、Ctrl+X 和 Ctrl+V 複製、剪下和貼上關鍵影格，Ctrl+D 再製它們，Delete 移除它們，Ctrl+Z 復原，Esc 取消拖曳。在時間軸之外，Esc 會離開動畫模式。復原時，縮放、選取範圍和播放頭都會維持原位。

    #在視圖中調整姿勢

    時間軸下方的那一列有 洋蔥皮（附數量和 間距，會把前後的姿勢顯示為殘影）、軸心 座標、自動關鍵影格，以及姿勢工具 平移、旋轉 和 軸心。

    • 新增關鍵影格 會開啟自動關鍵影格並暫停播放。開啟自動關鍵影格並選擇 平移 時，在 3D 視圖中拖曳所選實體控制點的彩色軸，即可在目前影格設定其位置的關鍵影格。
    • 在 2D 視圖中，拖曳所選的筆刷或其群組中的成員，即可沿兩個可見的軸設定平移的關鍵影格，並會貼齊格線。這不需要開啟自動關鍵影格。
    • 使用 旋轉 時，在 2D 視圖中繞著橘色軸心標記拖曳筆刷。俯視設定 RZ，前視設定 RY，側視設定 RX，並貼齊格線角度。
    • 使用 軸心 時，在任一 2D 視圖中拖曳黃色的旋轉中心。它會貼齊格線並保持深度。關鍵影格和靜止時的幾何體都不會改變。

    2D 和 3D 中的青色路徑顯示軸心的移動軌跡。按一下路徑上的點可以選取該時間和其關鍵影格，拖曳它則可以變更位置；開啟自動關鍵影格時，也可以在 3D 視圖中拖曳路徑點。標籤會顯示影格編號，虛線段表示跳躍。Esc 會取消上述任何拖曳，一次復原就能還原整個拖曳。

    新的動畫一開始處於靜止狀態，關鍵影格位於時間零點。在另一個影格改變姿勢即可產生運動。若要做出銳利的 L 形路徑，請在起點、轉角和終點設定關鍵影格，並使用線性搭配來回模式。

    #將按鈕連接到動畫

    選取一個 func_button、trigger_multiple 或 trigger_once。實體分頁會在屬性上方顯示 動畫觸發器。從清單中選擇目標，或按 挑選目標 再到任一視圖中按一下有動畫的物件；Esc 會取消挑選。缺少的目標或片段會在控制項下方回報。開啟連結顯示時，實體連結會以箭頭指向其目標。

    動作 決定啟動時要做什麼：播放 會開始播放具名片段或所選的動畫；切換 在 open 和 close 存在時輪流播放它們，否則會重新播放所選的動畫；開啟 和 關閉 會播放對應的片段；暫停 會停在目前姿勢，繼續 會接著播放，停止 則還原原本的姿勢。僅一次 會覆寫類別的預設值。重複間隔（秒） 設定兩次啟動之間的最短時間；它不會延遲第一次啟動。

    測試觸發器 會在預覽中執行該動作，而不會編輯地圖或新增復原步驟。重設預覽 會還原原本的姿勢，並清除「僅一次」和冷卻狀態。這不會模擬玩家碰撞或遊戲指令碼。

    #匯出中的動畫

    Godot 會匯出原生的 AnimationPlayer 和 AnimationLibrary 資源，包括曲線和會移動的碰撞。CharacterBody3D 進入按鈕的區域時，會啟動其目標。在 Godot 中對這些片段所做的編輯不會傳回地圖，下次匯出時會被取代。

    Raylib 匯出會加入含 C 語言播放器的 <map>_animation.h，以及含自由攝影機預覽的 <map>_preview.c；請依照 <map>_raylib.md 建置。在預覽中，SPACE 暫停，R 重新播放預設片段，N 循環切換具名片段。Defold 會把播放功能嵌入實體指令碼，並附有說明文件記載的 heron_*_animation 訊息。Unity 的 Build Level 會加入 HeronBrushAnimation 和一個運動學剛體。Bevy 匯出包含 heron_animation.rs 和使用說明。Godot、Unity、Defold、Bevy 和 raylib 會保留觸發連結、僅一次旗標和重複間隔。您的遊戲仍需自行註冊玩家，並把自己的按鈕連接到各執行環境的 API。

    #Motion lab 範例

    從歡迎畫面的範例中開啟 motion_lab。它包含一個 L 形路徑平台、一部升降梯、一個旋轉平台，以及一扇附按鈕的鉸鏈門。在 Godot 中開啟它旁邊的 godot/project.godot，然後按 F5。WASD 和滑鼠控制玩家移動，Space 跳躍，1 到 4 前往各個展示站，R 重新開始目前的展示站。踩上彩色踏板即可啟動它的目標。隨附的 README 說明如何重新匯出。

    #匯出到引擎

    檔案 → 匯出 會開啟匯出視窗。左側列出各引擎及其標誌：Godot、Defold、three.js、Bevy、raylib、Unity、Unreal Engine、Flax Engine、Cocos Creator、Wavefront .obj、glTF .gltf、GLB .glb，最後是 .map。右側頁面說明該目標會得到什麼。寫入 會寫出結果，檢查 會建構關卡但不寫出，並列出問題，關閉 則關閉視窗。

    匯出和儲存是分開的：.map 仍然是您可編輯的原始檔。每個控制項一變更就會儲存該引擎的設定，因此每個引擎都會保留各自的設定，視窗下次開啟時也會維持您離開時的樣子。

    #通用選項

    • 縮放：每公尺單位數，預設為 32。
    • 寫入內容：碰撞幾何體。
    • 最佳化：將靜態網格依 1024 單位的格子分組、捨棄埋在幾何體內部的面、合併共平面的面 和 合併碰撞形狀。
    • 專案路徑：關卡及其資源在專案中的存放位置。
    • 工具材質：clip、skip 和 origin 材質的名稱。
    • 更多：引擎專屬的開關，例如 節點命名依據、將圖層與群組重建為父節點、反轉三角形的頂點順序、紋理座標翻轉，以及用於烘焙光照的第二組 UV（搭配 光照貼圖紋素）。
    • 隨地圖同步更新：每次儲存地圖時重新寫入。在該引擎匯出過一次之後才能使用，因為那次匯出決定了寫入的位置。

    靜態格子會依世界筆刷的中心點分配筆刷，並在每個 1024 單位的格子內依材質合併，讓引擎可以剔除地圖中較小的部分。碰撞會保留，遊戲玩法實體也會保持獨立。這可能比單一世界網格產生更多繪製呼叫，因此預設為關閉。獨立的 OBJ、glTF 和 GLB 匯出不使用格子。

    #各目標注意事項

    • Godot：紋理和材質的 res:// 路徑、觸發器的物理層，以及光照貼圖 UV2。請在 Godot 專案內選擇匯出資料夾。
    • Defold：素材資源目錄、模型材質和紋理取樣器，該取樣器必須存在於所選的材質中。
    • Unity：OBJ 網格和一個編輯器匯入器；請匯出到專案的 Assets 資料夾底下。
    • Unreal Engine：產生的匯入指令碼和內容路徑，通常是 /Game/。
    • Flax Engine：相對於專案 Content 資料夾的模型內容路徑。
    • three.js、Bevy、raylib 和 Cocos Creator：適用於這些執行環境的場景或程式碼，使用說明會放在匯出結果旁。
    • glTF / GLB：供相容工具使用的可攜式幾何體；GLB 是二進位格式。OBJ：供建模工具使用的幾何體和材質。
    • .map：寫入為 可選擇 Valve 220、Standard、Quake 2 或 Quake 2 (Valve)。視窗會說明所選格式會遺失哪些資訊。

    寫入後請閱讀警告，例如缺少紋理。檢查結果 會在視窗中列出這些警告。

    #即時連結：Godot、Unity、Defold 和 Flax

    即時連結會在您工作時，把 Heron Brush 中未儲存的編輯傳送到引擎編輯器。它是單向的：在引擎中所做的編輯不會傳回。每個地圖視窗同時只能執行一個即時連結。切換引擎前請先停止它，變更匯出選項後請重新啟動，才能套用新的設定。控制項位於匯出視窗中該引擎頁面的 與 Godot 即時連結（依引擎名稱而定）卡片中。

    標題列中的指示器會顯示連結的狀態；按一下即可停止連結。關閉或替換地圖會停止發布。匯入失敗後，請修正問題，再重新啟動連結。

    #Godot

    1. 先匯出一次到 Godot 專案中。
    2. 按 安裝 Godot 附加元件。
    3. 在 Godot 的 Project Settings → Plugins 中啟用 Heron Brush Live。
    4. 按 啟動即時連結，並從 Godot 的停駐面板將地圖附加到開啟中的 3D 場景。

    附加元件只會替換它自己產生的分支，並保留附加點的位置和其他節點。請自行儲存 Godot 場景，並把您自己的指令碼和節點放在產生的分支之外。

    #Unity

    1. 先匯出一次到 Unity 專案的 Assets 資料夾底下。
    2. 按 安裝 Unity 附加元件，並讓 Unity 編譯它。
    3. 在 Unity 中開啟 Window → Heron Brush → Live Link。
    4. 啟動連結，並將地圖附加到目前的 Unity 場景。

    請保持 Unity 的即時連結視窗開啟。在 Play Mode 和 Prefab Mode 中會暫停更新。只有地圖物件底下的 Generated 子物件會被替換。請勿編輯產生的檔案。

    #Defold

    1. 先匯出一次到您的 Defold 專案，並讓專案在 Defold 中保持開啟。
    2. 按 啟動即時連結。不需要附加元件。
    3. 在 Defold 中開啟 heron_brush_live/preview.collection，或在您自己的場景中參照它。

    連結會寫入一個獨立的產生資料夾，不會動到最終匯出結果和 game.project。熱重新載入執行中的遊戲 也會更新從 Defold 啟動的遊戲；新增物件或變更碰撞可能需要重新啟動關卡。連線失敗時會自動重試。

    #Flax

    匯出到專案的 Content 資料夾，然後按 安裝 Flax 附加元件。讓 Flax 編譯它，啟動連結，再於開啟中的 Flax 場景選擇 Tools → Heron Brush: attach live map。產生的根物件會保留其位置，其他物件不受影響。請自行儲存場景。在 Play Mode 中會暫停更新。Tools → Heron Brush: stop live map 會暫停接收。

    #協作即時工作階段

    協作 → 即時工作階段 會開啟一個視窗，用來主持工作階段或加入其他 Heron Brush 使用者的工作階段。這是讓多人共同編輯地圖的功能，與引擎即時連結無關。

    #主持與加入

    輸入 您的名稱。若要主持，請選擇 主持工作階段，按 啟動工作階段，再把 複製連線資訊 複製的內容傳給您的來賓。若要加入，請選擇 加入工作階段，貼上連線資訊，然後按 加入。加入時會以主持人的地圖取代目前開啟的地圖，所以請先儲存您的工作。

    標準版本可在區域網路中使用，區域網路連接埠 用來設定連接埠。透過網際網路的工作階段（透過網際網路連線）需要包含選用網路功能的版本。參與者可以在 3D 視圖中看到彼此的攝影機標記和名稱。

    關閉視窗後，工作階段仍會繼續執行；標題列的指示器會顯示其狀態。停止工作階段 或 離開工作階段 會結束它。兩個人編輯同一個物件時，以主持人端的順序決定最終版本，而復原也是一項共用的編輯。請盡可能在不同區域工作，並適時儲存檢查點。

    #3D 顯示與第二台螢幕

    #顯示模式

    地圖分頁的 檢視 區段會切換視圖要繪製的內容：筆刷、點實體、實體模型、實體類別名稱、群組外框、曲面片、材質、顯示省略的面、預覽動畫、線框、邊和筆刷實體外框。線框會繪製三角形的邊，包括對角線和表面後方的邊，且不顯示材質。這是暫時性的除錯檢視，不會影響匯出或算繪。

    3D 視圖的光照、陰影、環境光遮蔽、反射、光暈和平滑處理都在偏好設定 → 算繪器中設定。這些是預覽設定；最終影像會使用算繪攝影機本身的設定。

    #獨立的 3D 視窗

    檢視 → 在獨立視窗中顯示 3D 視圖 會把 3D 視圖移到獨立的視窗，您可以把它放到另一台螢幕上。它共用攝影機、文件和工具，主視窗中則由平面視圖占用空間。它的選單提供：材質、實體顯示和線框；含有顯示省略的面、預覽動畫、邊、群組外框、點實體、實體模型和筆刷實體外框的檢視子選單；對焦至選取範圍；前視、側視和俯視，會讓攝影機繞著選取範圍（或攝影機前方的一點）轉動；依 3D 視圖放置攝影機；全螢幕（F11）；算繪影像；以及返回主視窗。關閉這個視窗會讓視圖重新停駐回主視窗。

    #程序化天空

    3D 視圖預設會開啟程序化天空，可以在偏好設定 → 算繪器 → 光照中關閉。算繪攝影機有自己的 程序化天空 開關，會隨地圖一起儲存。天空、地平線和地面的顏色來自環境設定，太陽則跟隨場景照明。天空沒有幾何體，也不會被匯出。

    #算繪攝影機與 PNG 影像

    檔案 → 算繪影像 會開啟算繪視窗：左側是攝影機及其設定，右側是即時預覽，會在您變更設定時重新繪製。攝影機會儲存在 .map 中一個僅供編輯器使用的 Render cameras 圖層，此圖層不會包含在引擎匯出中。

    #放置攝影機

    在 3D 視圖中構好畫面，然後按 Ctrl+Alt+0（或 Ctrl+Alt+Num0），或按 依 3D 視圖放置攝影機。若沒有選取攝影機，會更新第一個已儲存的攝影機；若一個都沒有，則會建立一個新的。這個動作可以復原，並會保留輸出和照明設定。在地圖中選取攝影機、從地圖載入攝影機 和 將 3D 視圖移至攝影機 則是反方向操作。在 3D 視圖中顯示攝影機框 會顯示輸出範圍的邊界，從 3D 視圖控制攝影機 則讓一般的導覽操作移動已儲存的攝影機。

    #設定

    • 攝影機位置：X、Y、Z、偏擺角（yaw）和俯仰角（pitch）。
    • 輸出與鏡頭：預設集（Full HD、正方形、直向）、寬度、高度、取樣數、垂直視野 和 遠裁切面。
    • 照明：日光、日落或陰天，或自行設定曝光、太陽、天空、地平線和地面的顏色、程序化天空、陰影、環境光遮蔽 和 光暈。
    • 景深：啟用景深、對焦距離、清晰範圍和模糊半徑。對焦至選取範圍 會對焦到攝影機前方所選物件的中心。

    儲存攝影機與設定 會把表單內容存入地圖；請儲存地圖，才能保存到磁碟上。

    #算繪

    算繪 PNG 會詢問儲存位置，然後開始漸進式算繪，在預覽中一個取樣接一個取樣地逐步填滿畫面。取樣數越多，畫面越好看，但耗時也越久。取消算繪 會停止算繪且不寫出檔案。算繪器使用的是編輯器的點陣化管線，而不是路徑追蹤。PNG 的背景為不透明，且不會算繪動畫。非常大的影像可能會讓編輯器短暫停頓。

    #偏好設定

    檔案 → 偏好設定（Ctrl+,）會開啟設定。變更會立即套用並儲存。側邊欄列出概覽、遊戲、檢視、顏色、滑鼠、鍵盤和算繪器。頂端的搜尋欄位可以在任何頁面中依名稱或描述尋找設定。每個變更過的設定都有自己的按鈕可還原預設值，還原預設值 則會重設目前的頁面。

    #各個頁面

    • 概覽：集中放置常用設定：外觀（面板不透明度（%）、色彩配置、版面配置、語言）、編輯、檢視和使用手冊。
    • 遊戲：遊戲、其檔案的位置，以及您的協作名稱。遊戲決定要寫入的地圖格式、要載入的實體定義，以及材質的位置。遊戲設定會從設定資料夾中的 games 資料夾（Linux 和 macOS 上為 ~/.config/heron-brush/games，Windows 上為 %LOCALAPPDATA%\heron-brush\games）以及應用程式旁的 games 資料夾讀取；安裝套件會把內附的設定放在後者。
    • 檢視：版面配置、色彩配置、語言、世界座標軸、格線不透明度、洩漏檢查的格子大小，以及貼圖對應鎖定。
    • 顏色：視圖、幾何體和控制點的顏色。
    • 滑鼠：環顧、平移和移動的速度與反轉、飛行速度、視野、連動 2D 視圖和控制點大小。
    • 鍵盤：按鍵配置，Heron Brush 或 Blender。
    • 算繪器：寫實著色、選取範圍外框、光照、陰影、環境光遮蔽、反射、光暈和表面。

    語言 提供跟隨系統和所有已翻譯的語言。介面會立即變更。若本手冊有該介面語言的翻譯，就會以該語言開啟，否則以英文開啟。

    #外掛程式與 MCP

    #外掛程式

    外掛程式以 Rhai 指令碼擴充編輯器的功能。檔案 → 外掛程式 會開啟外掛程式視窗。安裝外掛程式 會安裝一個 .rhai 檔案，安裝外掛程式資料夾 會安裝一個包含 main.rhai 的資料夾；選用的 plugin.toml 中繼資料可描述外掛程式及其設定。外掛程式會分成 已啟用的外掛程式 和 未啟用的外掛程式 兩組，啟用外掛程式 可以開啟或關閉個別外掛程式，重新啟動後仍會保留。重新載入外掛程式 會從磁碟重新讀取指令碼，並重設其面板中的數值。

    已啟用的外掛程式也會連同其設定、動作按鈕（執行）和輸出，一起顯示在地圖分頁的 外掛程式 區段中。動作會作用於選取範圍，未選取任何物件時則作用於全部，且是一個復原步驟。隨附的 Selection inspector 會顯示數量，並提供上移和下移的動作。

    #MCP

    協作 → 為 AI 代理提供服務（MCP） 讓 AI 代理或其他工具透過 Model Context Protocol 操控開啟中的編輯器。視窗會顯示本機位址並附有 複製 按鈕，停止伺服器 會將它結束；伺服器執行期間，標題列會顯示 MCP 已啟用。--mcp 命令列選項會在不開啟視窗的情況下執行相同的介面。用戶端可以探索幾何體、素材、屬性、動畫、匯出和工作階段相關的工具。MCP 和編輯器外掛程式是不同的介面。

    #命令列

    程式名稱是 heron-brush。不加任何選項時，會開啟歡迎畫面。

    #開啟檔案

    heron-brush map.map [entities.fgd] [materials/] 會開啟地圖，並可選擇性地一併載入實體定義和材質資料夾。空白引數表示略過該項，例如 heron-brush map.map "" materials/。如果編輯器已在執行，地圖會在其中開啟；--new-instance 則會改為開啟獨立的視窗。

    #指令

    • --help 或 -h：顯示用法。--version 或 -V：顯示版本。
    • --mcp：透過標準輸入和輸出提供 MCP 服務，不開啟視窗。
    • --merge-map <base> <ours> <theirs> [<output>]：供 git 使用的 .map 檔案三方合併。輸出預設寫入 ours。衝突會被印出，並傳回非零的結束代碼。
    • --obj-to-map <in.obj> <out.map> [size] [thickness] [snap] [material]：將網格轉換為筆刷。size 是最長邊的長度，以地圖單位計（預設為 256），snap 是角點使用的格線（0 表示不貼齊），而 solid 或 layered 這兩個字會改為建立格線方塊或凸面板塊，而不是薄楔形。
    • --render-preview <in.map> <out.png> [size]：為地圖寫出 PNG 縮圖，預設為 512 像素。
    • --run-script <script.rhai> <in.map> [out.map] [key=value ...]：在選取全部物件的情況下，對地圖執行外掛程式指令碼並寫出結果（預設寫回輸入檔）。key=value 用來回答外掛程式的設定。

    #疑難排解

    #當畫面看起來不對時

    • 缺少材質：檢查材質資料夾或套件，以及匯出的專案路徑。
    • 模型尺寸錯誤：與 64 單位的玩家標記和匯出比例比較。
    • 漸層方向錯誤：檢查漸層角度和面的方向。
    • 引擎場景是空的：閱讀匯出警告，並依照該目標的匯入說明操作。
    • 即時連結一直在等待：確認附加元件已安裝、場景已附加，且更新沒有被暫停。
    • 只有線條、沒有面：在地圖分頁的檢視區段中關閉線框，或在 3D 視窗的選單中選擇材質或實體顯示。
    • 視圖中少了物件：Ctrl+Shift+I 會顯示隱藏的物件；請檢查圖層和檢視篩選。
    • 按鍵沒有反應：先在視圖中按一下，讓它接收鍵盤輸入，並到偏好設定 → 鍵盤檢查按鍵配置。
    • 編輯失敗：復原、簡化幾何體，並使用地圖分頁 問題 區段中的 檢查地圖 和 檢查洩漏。
    • 從檔案管理員無法開啟地圖：它可能已交給正在執行的編輯器；請找找那個視窗。

    #設定與備份

    偏好設定、最近使用的地圖、星號、匯出設定和外掛程式都存放在設定資料夾中：Linux 和 macOS 上是 ~/.config/heron-brush，Windows 上是 %LOCALAPPDATA%\heron-brush。自動儲存的備份位於每張地圖旁的 autosave 資料夾中。

    #回報錯誤

    請附上編輯器版本（說明 → 關於）、您的作業系統、一張能重現問題的小地圖，以及確切的操作步驟。輸出窗格（Ctrl+4）通常會說明出了什麼問題。進行實驗之前，請先儲存一份複本。
