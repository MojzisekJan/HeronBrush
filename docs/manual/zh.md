# 入门
Heron Brush 是一款基于笔刷（brush）的关卡编辑器。你可以用凸笔刷搭建关卡，为它们的面上色和贴材质，放置实体，为门和平台制作动画，然后把结果导出到游戏引擎。它还提供内置素材、参数化形状、与引擎编辑器的实时连接、多人协同编辑会话以及静态图像渲染。本手册随程序一同提供，可离线使用。

在 macOS 上，本手册中凡是写 `Ctrl` 的地方都可以用 `Cmd`，Option 即 Alt。

## 欢迎界面
Heron Brush 在没有打开地图的情况下启动时，会显示欢迎界面。左侧是 **继续**（上次打开的地图）、**新建地图** 和用于打开现有 `.map` 的 **浏览**，以及 **游戏**、**手册** 和 **首选项**。右侧是带缩略图的最近地图列表，下方是 **示例**。星标（**置顶**）把地图固定在列表顶部；垃圾桶（**移到回收站**）把文件移到系统回收站，之后仍可恢复。方向键可在界面中移动焦点，Enter 打开当前选中的项目。随时可以通过 文件 → 欢迎 回到这个界面。

## 你的第一张地图
1. 在欢迎界面选择 **新建地图**，或使用 文件 → 新建地图（`Ctrl+N`）。
2. 在工具栏中选择笔刷工具（`B`），在 2D 视图中拖动，画出所选形状。在另一个 2D 视图中检查它的深度。
3. 选中笔刷并拖动来移动它。在 **面** 选项卡中为它指定材质或颜色。
4. 用 `Ctrl+S` 保存源地图。准备在游戏中使用时，打开 文件 → 导出，为你的引擎写出场景。

## 文件与保存
`.map` 文件是你的可编辑源文件。请经常保存：导出、实时连接和渲染都不会替你保存地图。文件 → 另存为（`Ctrl+Shift+S`）会在你省略扩展名时自动补上 `.map`。文件 → 还原到已保存的地图 会丢弃未保存的更改并重新加载文件。如果在有未保存更改时关闭窗口或打开另一张地图，Heron Brush 会询问是 **保存**、**放弃** 还是 **取消**。

当已保存过的地图有未保存的更改时，每隔十分钟会在地图旁的 `autosave` 文件夹中写入带编号的备份，并保留最新的 50 份。

如果在 Heron Brush 已经运行时打开地图，地图会交给正在运行的窗口，该窗口会被带到前台。需要单独的窗口时，请在命令行中使用 `--new-instance`（见“命令行”）。

# 界面
主窗口顶部是带菜单的标题栏，其下是工具栏，然后是地图视图、右侧的检查器和底部的状态栏。

## 标题栏和菜单
标题栏显示徽标、菜单、居中的地图名称和窗口按钮。在 macOS 上，常见的红、黄、绿按钮位于左侧。拖动标题栏可以移动窗口，双击可以最大化。当有任务在后台运行时，标题栏末端附近会出现指示器：引擎实时连接、实时会话或 **MCP 已启用**。点击指示器可以停止实时连接或打开对应的窗口。

- **文件**：欢迎、新建地图（`Ctrl+N`）、打开地图（`Ctrl+O`）、保存（`Ctrl+S`）、另存为（`Ctrl+Shift+S`）、还原到已保存的地图、导出、渲染图像、插件和首选项（`Ctrl+,`）。
- **编辑**：撤销（`Ctrl+Z`）、重做（`Ctrl+Shift+Z`）、剪切、复制、粘贴、复制副本（`Ctrl+D`）、删除、全选（`Ctrl+A`）、重复上次命令（`Ctrl+R`）和清除可重复的命令。
- **视图**：在独立窗口中显示 3D 视图、转到、吸附到网格（`Alt+0`）、显示网格（`0`）、预览动画和显示被忽略的面。
- **几何体**：插入 3D 文字、连接转角、把面转换为面片、将所选移出其实体和同步关联组。
- **动画**：关键帧动画、预览动画和按 3D 视图放置相机（`Ctrl+Alt+0`）。
- **地图**：加载点文件、重新加载点文件和关闭点文件；加载传送门文件、重新加载传送门文件和关闭传送门文件。它们显示地图编译器写出的漏洞轨迹和传送门。
- **协作**：实时会话和向智能体提供服务（MCP）。
- **帮助**：手册和关于。

## 工具栏
工具栏包含所有工具。第一组是最常用的：选择、笔刷、切割、顶点、边、面、旋转和缩放。第二组包括剪切、拼合、扫掠、控制点、圆角和上色。把鼠标悬停在按钮上可以看到名称和快捷键。再次点击当前工具会回到“选择”。

工具之后是 **水平翻转** 和 **垂直翻转**，然后是两个开关：**锁定** 在笔刷移动时保持材质贴图，**UV** 在笔刷旋转时保持贴图（用 `U` 切换）。接下来是当前工具自己的设置：笔刷工具显示形状及其选项，圆角工具显示半径、面数和转角，以及 **应用** 按钮。最右端是工具名称、网格大小（**网格 16** 等，点击可选择其他大小），以及 **网格设置** 菜单，其中包含吸附到网格、显示网格、预览动画、显示被忽略的面和关键帧动画。

## 地图视图
共有四个视图：3D 视图和三个平面视图，即俯视（XY）、前视（XZ）和侧视（YZ）。在 首选项 → 视图 → 布局 中可以选择单视图、双视图、三视图或四视图。拖动分隔条可以调整面板大小。点击某个视图会让它获得键盘焦点。`Space` 把一次只显示一个视图的面板切换到下一个视图，`Ctrl+Space` 最大化拥有键盘焦点的视图，再按一次恢复布局。

在任意视图中右键单击（不拖动）会打开上下文菜单，针对当前选择和指针下的对象。菜单提供编组、图层、关联组、创建实体、把笔刷移入或移出实体、复制材质名称以及在材质浏览器中定位该材质等功能。

## 检查器
右侧的检查器有四个选项卡。拖动它的左边缘可以调整宽度。

- **地图**（`Ctrl+1`）：图层、组、插件、问题、视图筛选和标签。
- **实体**（`Ctrl+2`）：实体浏览器、实体定义、所选实体的属性，以及按钮和触发器的动画触发器。
- **面**（`Ctrl+3`）：UV、材质、颜色、扫掠、圆角、面片以及内缩与倒角。每个区块都可以折叠。
- **素材**：可复用的笔刷模型库。

`Ctrl+5` 隐藏或显示检查器，`Ctrl+Alt+T` 隐藏或显示工具栏，让视图获得更多空间。

## 状态栏和输出面板
底部的状态栏显示编辑器的最新消息，错误以红色显示。点击状态栏或按 `Ctrl+4` 可以打开输出面板，查看完整的消息历史。大多数命令都会在这里报告执行结果，例如切割了多少个笔刷。

## 对话框和外观
首选项、导出和渲染图像等对话框会以独立窗口打开。在 首选项 → 视图 → 配色方案 中可以选择跟随系统、浅色或深色。“概览”页面上的 **面板不透明度 (%)** 可以让面板半透明地叠加在视图上。窗口会按你的系统风格绘制自己的按钮：macOS 上为原生样式，Windows 上为 Windows 11 风格，Linux 上为 GNOME 风格。

# 导航与键盘
## 在 3D 视图中移动
按住鼠标右键拖动可以环顾四周，按住中键拖动可以平移，滚轮前进和后退。`W`、`A`、`S` 和 `D` 分别向前、向左、向后和向右飞行，`Q` 上升，`X` 下降；按住 `Shift` 可以加大步幅。在 首选项 → 鼠标 中开启 **Alt + 中键拖动移动相机** 后，按住 Alt 并用中键拖动会沿视线方向移动相机。速度、反转和视野都在 首选项 → 鼠标 中设置。

## 在 2D 视图中移动
按住中键拖动可以平移，用滚轮以指针为中心缩放。平移和缩放一个平面视图时，其他平面视图会保持对齐；这由 首选项 → 鼠标 中的 **联动 2D 视图** 控制。`Ctrl+Alt+Z` 重置缩放，`Ctrl+Shift+U` 把平面视图重置到原点。

`Ctrl+U` 在所有视图中框显所选对象。视图 → 转到（`Ctrl+Alt+M`）可以把相机移动到输入的坐标、选中地图文件某一行对应的对象，或按输入的数值移动所选对象。

## 网格与吸附
`+` 和 `-` 改变网格大小，数字键 `1` 到 `9` 直接选择 1 到 256 单位的网格大小。`0` 或 `#` 显示或隐藏网格，`Alt+0` 开启或关闭吸附。`S` 把所选笔刷的顶点吸附到当前网格，`Ctrl+Shift+V` 吸附到整数单位，`Ctrl+Alt+Shift+V` 吸附到网格。

## 常用快捷键
- `F3` 或 `Ctrl+Shift+P`：按名称搜索任意菜单命令，按 `Enter` 运行。`F10` 打开菜单，方向键在菜单中移动。
- `Ctrl+S`：保存地图。`Ctrl+Shift+S`：另存为。
- `Ctrl+Z`：撤销。`Ctrl+Shift+Z` 或 `Ctrl+Y`：重做。
- `Ctrl+C`、`Ctrl+X`、`Ctrl+V`：复制、剪切和粘贴。粘贴会把对象放在指针处；`Ctrl+Alt+V` 保留原始坐标。选中面时，复制会复制它们的材质和 UV 设置。
- `Ctrl+D`：复制副本。`Ctrl+Shift+D`：创建组的关联副本。
- `Delete` 或 `Backspace`：删除所选内容。
- `Esc`：取消当前拖动，在当前工具中后退一步，回到“选择”，最后清除选择。`Shift+Esc` 直接回到“选择”。
- `Ctrl+R`：重复上次的可重复命令。`Ctrl+Shift+R`：清除这些命令。
- `Ctrl+Alt+0` 或 `Ctrl+Alt+Num0`：把渲染相机放到 3D 视图的位置。
- `F5`：重新加载材质。`F6`：重新加载实体定义。

## 选择快捷键
- `Ctrl+A`：全选；当顶点、边或面工具处于活动状态时，选择所有控制点。`Ctrl+Shift+A`：取消全部选择。`Ctrl+Alt+A`：反选。
- `Ctrl+B`：选择同一实体或组中的其他对象。
- `Ctrl+T`：选择所选笔刷接触到的所有对象。`Ctrl+E`：选择它们内部的所有对象。`Ctrl+Shift+E`：选择它们沿视图轴方向那一列中的所有对象。这些操作会消耗用来选择的笔刷。
- `Ctrl+I`：隔离所选内容。`Ctrl+Alt+I`：隐藏所选内容。`Ctrl+Shift+I`：重新显示全部。
- `Ctrl+G`：编组。`Ctrl+Shift+G`：取消编组。

## 变换快捷键
- 方向键和 `Page Up` / `Page Down` 会把所选内容沿它们在当前视图中指向的方向移动一个网格单位。配合 `Ctrl` 会边移动边复制，配合 `Alt` 则是旋转。
- `Alt+X`、`Alt+Y`、`Alt+Z`：绕对应轴旋转 90 度；加上 `Shift` 则反向旋转。
- `Ctrl+F`：沿视图横向翻转；`Ctrl+Alt+F`：上下翻转。`Ctrl+Shift+X` 和 `Ctrl+Shift+Y` 沿 X 或 Y 镜像。
- `Insert`：在所选内容的中心放置一个点实体。
- `Tab`：选中笔刷时，按 选择 → 顶点 → 边 → 面 → 选择 的顺序循环切换。

## Blender 键位方案
首选项 → 键盘 → 键位方案 提供 Heron Brush（默认，本手册通篇使用）和 Blender 两种。使用 Blender 方案时：`G` 选择并移动，`R` 旋转，`S` 缩放，`E` 扫掠，`1`、`2` 和 `3` 选择顶点、边和面工具，`K` 切割，`B` 框选，`A` 全选，`Alt+A` 取消选择，`X` 删除，`Shift+D` 复制，`H` 隐藏，`Alt+H` 显示全部，`Ctrl+Shift+Z` 重做。其余操作在两种方案中相同。

# 笔刷与建模工具
笔刷是由平面围成的凸体。复杂对象应由多个简单笔刷组合而成，而不要试图做出一个凹形笔刷。在简单形状就够用的地方，尽量减少笔刷数量。

## 绘制笔刷
选择笔刷工具（`B`），在视图中拖动。工具栏会显示 **要绘制的形状**：长方体、楼梯、拱形、圆柱、圆锥、椭球（UV）、椭球（二十面体） 和插入 3D 文字。`Alt+1` 到 `Alt+7` 可直接选择形状。根据形状的不同，工具栏会显示 **掏空** 和 **厚度：**，楼梯的 **台阶高度：** 和 **方向：**，圆形形状的 **轴：**、**边数：** 和圆形模式，球体的 **环数：**，以及二十面体的 **精度：**。请在拖动前设置好选项，并在多个视图中检查结果。

## 选择
点击笔刷即可选中，按住 `Ctrl` 点击可加入选择。从空白处拖动会画出选择框。在 3D 视图中，按住 `Shift` 点击可选中单个面，按住 `Ctrl+Shift` 点击可添加更多面。拖动已选中的笔刷会移动它；拖动未选中的笔刷则只选中并移动这一个。

在 3D 视图中，按住 `Shift` 拖动所选笔刷的某个面可以挤出它。按住 `Alt` 点击另一个面，可以把所选面的材质和对齐方式复制过去；`Alt+Ctrl` 只复制材质，`Alt+Shift` 复制旋转。

## 造型工具
- **选择**（`Esc`）：选择并移动。
- **顶点**（`V`）、**边**（`E`）、**面**（`F`）：拖动角点、边或面。按住 `Shift` 从边或面的中点拖动会在那里添加一个角点。`Delete` 删除所选的角点。
- **旋转**（`R`）、**缩放**（`T`）、**剪切**（`G`）：用控制柄变换所选内容。
- **切割**（`C`）：点击两个或三个点来定义切割平面。`Enter` 执行切割，`Ctrl+Enter` 选择保留哪一侧，`Backspace` 或 `Esc` 删除最后一个点。
- **拼合**（`N`）：在一个体积周围放置点，按 `Enter` 用这些点生成凸笔刷。`Backspace` 删除最后一个点。
- **扫掠**（`Y`）：见下文的扫掠部分。
- **控制点**（`P`）：调整面片的控制网格形状。
- **圆角**（`O`）：点击一条边将其倒圆，或用相应工具选取边或顶点后按 `Enter`。面数越多结果越平滑，几何体也越多。
- **上色**（`K`）：见“材质与 UV”。

## 组合笔刷
- `Ctrl+J`：把所选笔刷合并为它们的凸包。
- `Ctrl+K`：从所选笔刷接触到的笔刷中减去所选笔刷。
- `Ctrl+Shift+K`：掏空所选内容，壁厚为一个网格单位。
- `Ctrl+L`：对所选内容求交集。

## 扫掠、圆角、面片和倒角
**扫掠** 从所选面出发，沿路径生成几何体。先选择面（在扫掠工具中按住 `Alt` 点击），然后在“面”选项卡的扫掠区块中设置 **行程**、**旋转**（轴和角度）、**缩放**、**步数** 和 **路径**（整数或自由对齐；圆弧、直线或 S 形弯），再按 **扫掠**。控件下方的一行文字会说明将生成多少个笔刷。

**圆角** 区块用 **半径**、**面** 和 **角**（斜接或圆角）对选取的边进行倒圆；面数为 1 时得到的是倒角。

**面片** 显示所选面片的 **列** 和 **行**，并提供按钮来增加或删除一对。几何体 → 把面转换为面片（`Ctrl+P`）会用所选面生成面片。

**内缩与倒角** 作用于所选面：**内缩** 把面从边缘向内收缩，**深度** 把面向外推出（为负值时向内）。**倒角面** 同时应用两者；第三个按钮根据深度的正负添加凸起面板或切出凹槽。**连接转角** 会打开一个对话框，以斜接或圆角方式连接两个笔刷，并提供预览。

## 3D 文字
几何体 → 插入 3D 文字（也是 笔刷工具形状列表中的最后一项）可以用文字生成笔刷。它使用内置的多边形字体 Heron Block，该字体带切角、按比例设定字宽并支持捷克语重音符号；小写字母使用大写字形。输入 **文字**，设置 **高度**（大写字母高度，重音符号会超出它）和 **深度**，查看实时预览，然后按 **插入**。

如果某项操作无法生成有效的几何体，请调整其尺寸，或撤销后简化形状。

## 阵列
几何体 → 阵列 会复制所选内容，并在你修改数值时在地图中显示副本。数量包含原始对象，一个阵列最多生成 1024 个副本。

- **直线** 将每个副本相对前一个移动 **间距 X**、**间距 Y** 和 **间距 Z**，并绕所选轴旋转 **每个副本的旋转（度）**。
- **网格** 按 **间距 X**、**间距 Y** 和 **间距 Z** 的间距排满 **数量 X**、**数量 Y** 和 **数量 Z** 个项目。
- **环形** 将项目在 **角度（度）** 范围内分布在一个中心周围，该中心距所选内容 **半径（单位）**。开启 **朝向中心** 后，每个副本会随环形一起旋转。
- **散布** 将副本放在半径内的随机位置，横跨所选轴。相同的 **种子** 会得到相同的布局，**随机旋转** 会旋转每个副本。

当所选内容是一个完整的组时，**链接副本** 会让每个副本成为链接副本，修改其中一个会同步到全部。**应用** 保留副本，并将它们与原始对象一起选中；**取消** 删除副本。整个阵列可一步撤销。

## 雕刻地形
地形由许多小笔刷组成，雕刻笔刷会把它们的表面向外推或向内拉。选择一个或多个笔刷，然后选择 几何体 → 分成柱体，再选择柱体形状：三角形、正方形或六边形。它会沿网格线把它们切成宽一个网格步长的柱体，并把柱体放入名为 Terrain 的组。切口沿着世界网格，因此相邻的笔刷会在相同位置被切开，并共享角点。每个柱体沿笔刷较薄的一边竖立：在地板或天花板中竖直，在墙壁中水平。洞穴也是同样的做法：把一个方块挖空（Hollow selection），墙厚设为一个网格步长，选中墙壁后再分割。

**雕刻** 窗口由雕刻工具条末端的按钮打开，也可以在其中分割所选内容，分割成它的 柱体形状 一行中选定的形状。两处都会记住上次使用的形状。**三角形** 每个网格单元生成两个柱体，无论怎样雕刻，三角形的顶面都保持平整。**正方形** 每个单元生成一个，笔刷数量减半；它的顶面会沿对角线弯折。**六边形** 用两个网格步长宽的六边形铺满笔刷，每个六边形绕中心分成六个三角形，因此每个顶面都保持平整。

选择 **雕刻** 工具（`J`），在 3D 视图中于表面上拖动。按住按钮不移动鼠标时，笔刷会在同一位置继续作用，每秒十次，因此只要按住，山丘就会不断隆起。橙色圆环表示笔刷。未选择任何内容时，笔刷会改变其下的所有笔刷；有选择时只改变所选的。窗口顶部的工具条决定一笔的效果：

- **抬高** 和 **降低** 将表面向外或向内移动，圆环中心最多，边缘完全不动。按住 `Shift` 可互换二者。
- **平滑** 抹平起伏。
- **压平** 将表面压到笔画开始的位置。

在同一窗口中，**方向** 决定朝哪个方向移动：

- **向上** 将表面竖直上下移动，范围是地面上的一个圆。这用于地形。
- **相机** 将表面朝视图移近或移远，范围是指针周围的一个球。看向地板、墙壁或天花板，就会雕刻它。
- **法线** 将表面沿笔画开始时指针下方的那个面向外移动。

两个数字是 **半径（单位）** 和 **强度 (%)**。只有笔画移动的那一侧的角点会移动；背面保持不变，柱体至少保留一个单位的厚度。笔刷共享的角点会一起移动，因此表面保持封闭。一笔可以一步撤销。在 2D 视图中，此工具的选择方式与选择工具相同。

雕刻完成后，选中地形并选择 几何体 → **合并柱体**，或点击 **雕刻** 窗口中的按钮。相邻柱体若合起来是凸笔刷且外观相同，就会合并成一个笔刷，因此平坦区域会变成少数几个大笔刷。表面不会移动，合并可一步撤销。

**保持形状合并** 就在菜单和窗口中它的旁边，合并方式相同，但不管面的外观：两个面合成一个时，会采用其中一个面的材质。它适用于任何选中的笔刷，不只是地形。摆成 L 形的四个方块会变成两个，绝不会变成填满 L 的一个；整片雕刻过的地形会减少到合并相邻笔刷所能达到的最少数量。只有同一组或实体中的笔刷才会合并，因此门绝不会吞并旁边的墙。

要做体素游戏那样的地形，请分成 **正方形** 柱体，并在 **雕刻** 窗口的 **笔画** 中选择 **方块**。此时每一笔会把每个柱体的整个顶面按整格网格步长移动，侧面保持竖直，地面呈台阶状升高。所有模式照常工作；小的笔画会累积，直到柱体升高一整格。其他形状的柱体保持不变。

**自由** 不需要柱体，可用于任何笔刷。抬高在指针周围的球体内添加地形，降低则移除，因此地形可以悬垂并挖出洞穴。平滑使其平整，压平把它拉到笔画开始处的高度。每次轻触都会在网格上带圆角地重建所触及的笔刷，球体外的一切保持原样，包括锐利的边。结果是普通笔刷，其他所有工具都能使用，之后可用 **合并柱体** 减少数量。网格越细，表面越平滑，笔刷也越多。

# 材质与 UV
## 加载和应用材质
打开“面”选项卡的 **材质** 区块。**加载文件夹** 添加一个图片文件夹，**加载 .wad** 添加一个纹理包；两者都会出现在 **材质集** 下，点击叉号即可移除。在 **筛选材质** 中输入文字可以缩小列表范围。点击某个材质将其设为当前材质，然后 **应用到所选** 会把它应用到所有选中的面。**选择** 提供“选择用到它的 brush”和“选择用到它的面”。**替换** 在整张地图或仅在所选范围内把一种材质替换为另一种。

**上色** 工具（`K`）把当前材质应用到指针下的面：单击为一个面上材质，双击为整个笔刷上材质，按住 `Shift` 点击则像吸管一样把该面的材质设为当前材质。

## UV 编辑器
“面”选项卡的 **UV** 区块显示所选面的材质和轮廓。画布上的鼠标操作：
- 滚轮以指针为中心缩放。用右键或中键拖动可以平移。双击右键重新框显该面；选择另一个面时会自动框显。
- 左键拖动会移动材质，面的轮廓保持不动。圆环旋转贴图，角上的控制柄缩放贴图，中心控制柄设置这些变换的原点。
- 按住 `Alt` 用左键拖动图块边缘可以进行切变，按住 `Shift` 用中键拖动也一样。
- 每次拖动都是一个撤销步骤，`Esc` 可以取消正在进行的拖动。

画布下方是 **偏移**、**缩放**、**角度**，如果游戏用到，还有 **内容标志**、**表面标志** 和 **表面值**。按钮有 **重置**、**按世界坐标重置**、**适配**、**水平翻转**、**垂直翻转** 以及两个 90° 旋转按钮。**对齐** 让材质沿面的某条边对齐（再按一次换到下一条边，按住 `Shift` 换到上一条边）。四个靠齐按钮把材质推到某条边上。**适配 U** 和 **适配 V** 缩放材质，使面上正好铺满整数个重复；再按一次切换到下一个数量，按住 `Ctrl` 可保留修边贴图（trim sheet）的分区。

## UV 快捷键
选中面时，方向键移动材质，`[` 和 `]` 将其旋转 15°，`,` 和 `.` 把缩放减半或加倍，`Ctrl+F` 和 `Ctrl+Alt+F` 翻转材质，`Shift+R` 重置，`Alt+Shift+R` 按世界坐标轴重置，`Ctrl+Shift+F` 让材质适配每个面。

工具栏上的 **锁定** 在移动笔刷时保持贴图，**UV**（`U`）在旋转笔刷时保持贴图。

## 工具材质
- skip：在引擎导出中移除标记的面。
- clip：生成不可见的碰撞体。
- origin：标记笔刷实体的轴心。

可以在“导出”窗口的 **工具材质** 卡片中修改这些名称。对于你确定被遮挡的面，请使用 skip。

## 导出时忽略面
选择一个面，在 UV 区块中开启 **导出时忽略面**。UV 预览中会用橙色斜线标出它。它的材质和颜色仍会保存，笔刷依然封闭、可编辑。导出的渲染网格会省略这个面，但保留碰撞。立方体只保留一个四边形面时，会生成两个渲染三角形。此功能不会让面变成双面，也不会合并网格。

**忽略被遮挡的面** 会标记被静态笔刷完全遮挡的面，包括相互贴合的相同面和被包在内部的笔刷。它作用于所选笔刷；若未选择任何内容，则作用于所有可见且未锁定的世界几何体。笔刷实体、透明材质以及已有被忽略面的笔刷会被跳过。部分遮挡的面不会被分割。一次撤销即可恢复全部。视图 → 显示被忽略的面 可以在编辑器视图中隐藏或显示这些面；点选时仍以整个笔刷为准。

# 颜色与渐变
“面”选项卡的 **颜色** 区块可以在材质之上为面涂纯色或渐变。它适合关卡的白模搭建（blockout）和风格化美术。上色的面在视图中保持真实颜色；选中状态通过轮廓显示。

## 调色板和混合颜色
点击十二个调色板色块之一，即可用它为所选面或整个所选笔刷上色。**不透明度** 以百分比设置下一次上色的不透明度。**混合** 带有一个颜色按钮，可以打开取色器；在取色器中拖动时，所选内容会实时跟随变化，也可以按 **上色** 一次性应用混合颜色。**回到材质** 去除颜色，使面重新显示其材质。区块顶部的一行文字说明当前选择了什么，以及它当前的外观。

## 取色器
编辑器中的所有颜色按钮都会打开同一个取色器。在方块中拖动选择饱和度和亮度，在旁边的色条中拖动选择色相。下方是 **R**、**G** 和 **B** 数值，以及颜色带透明度时的 **不透明度** 滑块。十六进制字段接受 `#RRGGBB` 或 `#RRGGBBAA`；文本不是有效颜色时会变红。**复制** 把十六进制代码复制到剪贴板。点击取色器外部即可关闭。

## 渐变
**渐变** 用于选择线性渐变或径向渐变，旁边的按钮可以把颜色首尾对调。每个色标都有一个颜色按钮和 **位置 (%)**，两端之间的色标还有删除按钮。**添加色标** 会在最大的间隙中添加一个色标；一个渐变最多可以有八个色标。**渐变角度** 设置线性渐变的方向，并带有 **+45°** 和 **−45°** 按钮。

预览下方有一条滑轨，每个色标对应一个标记。点击滑轨添加色标，点击标记打开它的取色器，拖动标记移动它，右键点击标记将其删除。滑轨下方的三个色块是预设：暖色渐变、冷色渐变和灰度渐变。对渐变的更改会实时应用到所选内容。

渐变的方向很重要：应沿屋顶坡度或曲面物体的走向设置，而不是横跨互不相关的面。上色后请从两侧检查模型。

## 表面材质
**表面材质** 可设置 **粗糙度**（0 为光滑，100 为哑光）、**金属度**（木头、石头或塑料为 0，金属为 100）和 **自发光**（0 到 8；表面以自身颜色发光，包括渐变，但不会照亮附近物体）。更改会实时应用到所选面或笔刷。**使用默认表面** 移除覆盖设置。所有更改都可以撤销。

表面效果会在有光照的 3D 视图和相机渲染中显示。平面显示和线框显示有意不显示高光。泛光（Bloom）可以在自发光表面周围加上光晕。Godot 和 glTF/GLB 会获得材质数值，Unity 导入器会把粗糙度转换为光滑度（smoothness）。各导出目标的限制见 `docs/surface-materials.md`。

# 素材、图层和组
## 素材库
打开 **素材** 选项卡。用 **添加文件夹** 添加一个包含 `.map` 模型的文件夹；内置素材库始终可用。在 **筛选素材** 中输入文字进行搜索。点击模型将其选中，然后双击它、按 `Enter` 或点击 **插入**，即可把它添加到指针最后所在的位置。也可以把模型拖到视图中。素材中的笔刷会作为一个组插入，因此模型会整体移动。

**将所选保存为素材** 会把所选笔刷以 `.map` 的形式写入素材库。素材库中的素材是普通的可编辑笔刷，而不是导入的网格。

## 图层
“地图”选项卡中的 **图层** 列表用于组织大型区域。输入名称并点击 **添加** 可以创建图层，按 `Enter` 可以重命名当前图层。每个图层都可以隐藏、锁定或排除在导出之外。**移到这里** 把所选内容移到当前图层。视图中的上下文菜单也提供移动到图层、设为活动图层、隐藏图层和隔离图层。

## 组和关联组
`Ctrl+G` 对所选内容编组，`Ctrl+Shift+G` 取消编组。“地图”选项卡的 **组** 区块列出所有组，并提供 **打开**、**重命名**、**合并**、**取消编组**、**移出** 和 **提取**。关联组是一组共享编辑的副本：`Ctrl+Shift+D` 创建关联副本，几何体 → 同步关联组 更新各个副本，**取消关联** 让某个副本独立出来。在“实体”选项卡中，可以让某个属性在关联组同步时保留为该副本自身的值。

## 统一的比例
默认导出比例为每米 32 个地图单位。内置的玩家起点标记高 64 个单位，即 2 米的参考高度。可以用它来对照门洞、载具、家具和植物的大小。只有在确有需要时才更改导出比例，并保持相关素材的比例一致。

# 实体与玩法
常用的实体定义已经内置并始终可用：灯光、玩家起点、门、按钮、平台、触发器、静态道具、声音和路径点。通过“实体”选项卡中的 **实体定义** 加载项目的 FGD 后，同名类别会被替换，其他内置类别则保留。

## 放置实体
在“实体”选项卡的 **实体** 浏览器中，在 **筛选类别** 中输入文字并选择一个类别。对于点类别（例如灯光），点击 **放置** 或双击该类别；`Insert` 会在所选内容的中心放置一个。对于笔刷类别（例如门或触发器），先选择笔刷，然后点击 **生成**。也可以把类别拖到视图中。

## 属性
属性列表用于编辑所选实体。同一类别的实体会一起编辑。**添加属性** 可以添加定义中可能没有的键；**默认值** 可以把现有属性恢复为默认值，或补上缺少的属性。类别定义了但实体尚未设置的属性会以暗色显示，输入值后即被添加。用 targetname 和 target 来连接实体。

## 导出能做什么
Godot 的指令会创建原生节点、碰撞体和触发区域。Unity 和 Unreal 原生支持常见灯光，Unreal 还会创建 PlayerStart Actor。其他数据会在目标导入器允许的范围内保留。

单独一个门实体并不会带来游戏行为。移动、触发响应、玩家控制器和项目脚本仍然需要在引擎中实现。Defold 会导出实体属性和碰撞对象；Flax 会放置模型和通用实体。在此基础上开发玩法之前，请先在引擎中检查结果。

# 动画
Heron Brush 可以预览简单的运动，为笔刷实体编辑关键帧动画，并将其导出到多种引擎。

## 预览动画
在“视图”菜单、“动画”菜单、“网格设置”菜单或“地图”选项卡的“视图”区块中开启 **预览动画**。当 start_on 启用时，它会根据实体的轴、速度、方向、行程和等待属性播放 func_rotate 的旋转和 func_shuttle 的往返运动，并播放设置为“启动时播放”的关键帧片段。风扇和风车素材已经包含会旋转的部件。

关闭预览会恢复原始姿态。在视图中点击会先停止播放，再进行选择或编辑；相机导航不受影响。预览不会更改地图、撤销历史或导出结果，也不会运行物理或游戏逻辑。

## 关键帧编辑器
通过 动画 → 关键帧动画 或“网格设置”菜单打开它。它停靠在视图下方；当 3D 窗口独立时，则停靠在 3D 窗口中。标题中的窗口图标可以把它移到独立窗口中，当前帧和撤销历史都会保留。**编辑动画** 把视图切换到动画姿态，**编辑地图** 则回到静止几何体。在动画模式下，每个视图底部都会显示 **编辑动画** 和帧号。

选择一个笔刷实体、一个笔刷或一个笔刷组即可为其制作动画。一个扁平的笔刷组共用一个动画和轴心；包含多个实体的组需要分别制作动画。

## 片段
**动画** 选择器用于在命名片段之间切换。在 **动画名称** 中输入名称并点击 **另存为**，即可把当前片段复制为该名称；**删除** 删除片段。**平移** 创建一个不含旋转的 `translate` 片段。**门动画** 创建平滑的 `open` 和 `close` 片段，绕当前轴心旋转 90 度；请先把轴心移到门铰处。**启动时播放** 让片段在关卡开始时播放；门预设会关闭此选项。

## 播放控制
播放控制按钮有 **开始**、**上一关键帧**、**播放**、**下一关键帧** 和 **结束**。**帧** 显示并设置当前帧，**时长（秒）** 设置片段长度。模式可选 **一次**、**循环** 或 **往返**。

## 时间轴
时间轴有一条带播放头的标尺，以及 **位置**（X、Y、Z 一起设置关键帧）和每个旋转角度 RX、RY、RZ 各自的轨道。在标尺上点击或拖动可以移动播放头，并在所有视图中预览该姿态。用中键拖动可以平移时间轴。拖动关键帧可以在时间上移动它们；`Shift` 加入选择；双击轨道插入关键帧；`Ctrl`+滚轮缩放。**曲线** 会显示数值曲线而不是轨道。

时间轴上方的按钮有 **添加关键帧**、**移除**、**复制**、**粘贴** 和 **复制副本**。**吸附到帧** 让关键帧保持在整数帧上，**适配** 显示整个片段。**调整关键帧时间** 会展开 **时间缩放**、**偏移（帧）**、**从播放头缩放**、**延长时长** 和 **调整所选关键帧时间**。

时间轴旁的关键帧检查器用于编辑所选关键帧：**帧**、**值**（或位置关键帧的三个坐标）、插值方式 **线性**、**保持** 或 **贝塞尔**、**入切线斜率** 和 **出切线斜率**，以及 **平滑切线**。

## 编辑器中的按键
当时间轴拥有键盘焦点时：`Space` 播放或暂停，左右方向键逐帧移动，`Ctrl+A` 选择所有关键帧，`Ctrl+C`、`Ctrl+X` 和 `Ctrl+V` 复制、剪切和粘贴关键帧，`Ctrl+D` 复制副本，`Delete` 删除，`Ctrl+Z` 撤销，`Esc` 取消拖动。在时间轴之外，`Esc` 退出动画模式。撤销时，缩放、选择和播放头都保持原样。

## 在视图中摆姿态
时间轴下方的一行包括带数量设置的 **洋葱皮** 和 **间距**（以虚影显示相邻姿态）、**轴心** 坐标、**自动关键帧**，以及姿态工具 **平移**、**旋转** 和 **轴心**。

- **添加关键帧** 会开启自动关键帧并暂停播放。开启自动关键帧并选择 **平移** 后，在 3D 视图中拖动所选实体控制柄上的彩色轴，即可在当前帧记录位置关键帧。
- 在 2D 视图中拖动所选笔刷或其所在组的成员，可以沿两个可见轴记录平移关键帧，并吸附到网格。此操作无需开启自动关键帧。
- 使用 **旋转** 时，在 2D 视图中围绕橙色轴心标记拖动笔刷。俯视记录 RZ，前视记录 RY，侧视记录 RX，并吸附到网格角度。
- 使用 **轴心** 时，在任意 2D 视图中拖动黄色的旋转中心。它会吸附到网格并保持深度不变。关键帧和静止几何体保持不变。

2D 和 3D 中的青色路径显示轴心的运动轨迹。点击路径点可以选中其时间和关键帧，拖动路径点可以更改位置；开启自动关键帧时，也可以在 3D 视图中拖动路径点。标签显示帧号，虚线段表示跳变。`Esc` 可取消上述任何拖动，一次撤销即可还原整个拖动。

新动画从静止状态开始，关键帧位于时间零点。在其他帧改变姿态即可产生运动。若要制作有尖角的 L 形路径，请在起点、拐角和终点设置关键帧，并使用线性插值配合往返模式。

## 把按钮连接到动画
选择一个 func_button、trigger_multiple 或 trigger_once。“实体”选项卡会在属性上方显示 **动画触发器**。从列表中选择目标，或点击 **在视图中选择目标**，然后在任意视图中点击一个动画对象；`Esc` 取消选取。缺失的目标或片段会在控件下方报告。开启连线显示时，实体连接会显示指向目标的箭头。

**动作** 决定激活时执行什么：**播放** 启动一个命名片段或所选动画；**切换** 在 `open` 和 `close` 存在时交替播放它们，否则重新开始所选动画；**打开** 和 **关闭** 启动对应片段；**暂停** 保持当前姿态，**继续** 继续播放，**停止** 恢复原始姿态。**仅一次** 覆盖类别的默认设置。**重复间隔（秒）** 设置两次激活之间的最短时间；它不会延迟第一次激活。

**测试触发器** 在预览中执行该动作，不会编辑地图，也不会添加撤销步骤。**重置预览** 恢复原始姿态，并清除“仅一次”和冷却状态。它不会模拟玩家碰撞或游戏脚本。

## 导出中的动画
Godot 会导出原生的 AnimationPlayer 和 AnimationLibrary 资源，包括曲线和随动的碰撞体。CharacterBody3D 进入按钮区域时会激活其目标。在 Godot 中对这些片段所做的修改不会回到地图，并会在下一次导出时被覆盖。

raylib 导出会添加带 C 语言播放器的 `<map>_animation.h` 和带自由相机预览的 `<map>_preview.c`；按照 `<map>_raylib.md` 构建即可。在预览中，`SPACE` 暂停，`R` 重新开始默认片段，`N` 循环切换命名片段。Defold 会把播放功能嵌入实体脚本，并提供有文档说明的 `heron_*_animation` 消息。Unity 的 Build Level 会添加 `HeronBrushAnimation` 和一个运动学刚体。Bevy 导出包含 `heron_animation.rs` 及说明。Godot、Unity、Defold、Bevy 和 raylib 都会保留触发连接、“仅一次”标志和重复间隔。你的游戏仍需注册播放器，并把自己的按钮连接到各运行时的 API。

## Motion lab 示例
从欢迎界面的“示例”中打开 `motion_lab`。其中有一个沿 L 形路径移动的平台、一部升降机、一个旋转平台和一扇带按钮的铰链门。在 Godot 中打开旁边的 `godot/project.godot` 并按 `F5`。WASD 和鼠标控制玩家移动，空格键跳跃，1 到 4 前往各个展台，R 重新开始当前展台。踩上彩色踏板即可激活它的目标。附带的 README 说明了如何重新导出。

# 导出到引擎
文件 → 导出 会打开“导出”窗口。左侧列出各个引擎及其徽标：Godot、Defold、three.js、Babylon.js、PlayCanvas、Bevy、raylib、Unity、Unreal Engine、Flax Engine、Cocos Creator、Wavefront .obj、glTF .gltf、GLB .glb，最后是 `.map`。右侧页面说明目标将得到什么。**写入** 执行写出，**检查** 构建关卡但不写出，并列出问题，**关闭** 关闭窗口。

导出与保存相互独立：`.map` 始终是你的可编辑源文件。每个控件在更改后会立即保存对应引擎的设置，因此每个引擎都会记住自己的选项，窗口也会保持你上次离开时的状态。

## 通用选项
- **缩放**：**每米多少单位**，默认为 32。
- **写入什么**：**碰撞几何体**。
- **优化**：**按 1024 单位单元分组静态网格**、**丢弃埋在几何体内部的面**、**合并共面的面** 和 **合并碰撞形体**。
- **项目路径**：关卡及其资源在项目中的存放位置。
- **工具材质**：clip、skip 和 origin 材质的名称。
- **更多**：各引擎特有的开关，例如 **节点命名依据**、**将图层和组重建为父节点**、**反转三角形顶点绕序**、纹理坐标翻转，以及带 **光照贴图纹素** 设置、用于烘焙光照的第二套 UV。
- **随地图保持更新**：**每次保存地图时重新写入**。只有在对该引擎导出过一次之后才可用，因为那次导出确定了写入位置。

静态单元按中心点分配世界笔刷，并在每个 1024 单位的单元内按材质合并，使引擎能够剔除地图中较小的部分。碰撞会保留，玩法实体保持独立。这可能比单个世界网格产生更多的绘制调用（draw call），因此默认关闭。独立的 OBJ、glTF 和 GLB 导出不使用单元。

## 各目标说明
- Godot：纹理和材质的 `res://` 路径、触发器的物理层以及光照贴图 UV2。请选择 Godot 项目内的导出文件夹。
- Defold：素材资源目录、模型材质和纹理采样器，该采样器必须存在于所选材质中。
- Unity：OBJ 网格和一个编辑器导入器；请导出到项目的 Assets 文件夹下。
- Unreal Engine：生成的导入脚本和内容路径，通常为 /Game/<level>。
- Flax Engine：相对于项目 Content 文件夹的模型内容路径。
- three.js、Babylon.js、PlayCanvas、Bevy、raylib 和 Cocos Creator：适用于这些运行时的场景或代码，导出文件旁附有说明。
- glTF / GLB：供兼容工具使用的可移植几何体；GLB 是二进制形式。OBJ：供建模工具使用的几何体和材质。
- `.map`：**写入为** 可选择 Valve 220、Standard、Quake 2 或 Quake 2 (Valve)。窗口会说明所选格式会丢失哪些内容。

写出后请阅读警告，例如缺失纹理。**检查结果** 会在窗口中列出这些警告。

# 实时连接：Godot、Unity、Defold 和 Flax
实时连接会在你工作时把 Heron Brush 中未保存的编辑发送到引擎编辑器。它是单向的：在引擎中所做的编辑不会传回。每个地图窗口同时只能运行一个实时连接。切换引擎前请先停止它，更改导出选项后请重新启动以使其生效。这些控件位于“导出”窗口中该引擎页面的实时连接卡片中（例如 **与 Godot 实时连接**）。

标题栏中的指示器显示连接状态；点击它可以停止连接。关闭或替换地图会停止发布。导入失败后，请修复问题并重新启动连接。

## Godot
1. 先导出一次到 Godot 项目中。
2. 点击 **安装 Godot 插件**。
3. 在 Godot 的 Project Settings → Plugins 中启用 Heron Brush Live。
4. 点击 **启动实时连接**，然后在 Godot 的停靠面板中把地图附加到打开的 3D 场景。

插件只替换它自己生成的分支，并保留附加点的位置和其他节点。请自行保存 Godot 场景，并把你自己的脚本和节点放在生成的分支之外。

## Unity
1. 先导出一次到 Unity 项目的 Assets 文件夹下。
2. 点击 **安装 Unity 插件**，等待 Unity 完成编译。
3. 在 Unity 中打开 Window → Heron Brush → Live Link。
4. 启动连接，并把地图附加到当前的 Unity 场景。

请保持 Unity 的实时连接窗口打开。在 Play Mode 和 Prefab Mode 下更新会暂停。只有地图对象的 Generated 子对象会被替换。请勿编辑生成的文件。

## Defold
1. 先导出一次到你的 Defold 项目中，并在 Defold 中保持该项目打开。
2. 点击 **启动实时连接**。无需安装插件。
3. 在 Defold 中打开 heron_brush_live/preview.collection，或在你自己的场景中引用它。

实时连接写入一个单独生成的文件夹，不会改动最终导出和 game.project。**热重载运行中的游戏** 也会更新从 Defold 启动的游戏；添加对象或更改碰撞可能需要重新启动关卡。连接失败时会自动重试。

## Flax
导出到项目的 Content 文件夹中，然后点击 **安装 Flax 插件**。等待 Flax 编译完成，启动连接，再在打开的 Flax 场景中选择 Tools → Heron Brush: attach live map。生成的根节点会保留其位置，其他对象不受影响。请自行保存场景。在 Play Mode 下更新会暂停。Tools → Heron Brush: stop live map 会暂停接收。

# 协同实时会话
协作 → 实时会话 会打开一个窗口，用于主持会话或加入其他 Heron Brush 用户的会话。这是多人共享地图编辑，与引擎实时连接是两回事。

## 主持与加入
填写 **你的名字**。要主持会话，选择 **主持会话**，点击 **启动会话**，然后把 **复制连接信息** 得到的信息发给访客。要加入会话，选择 **加入会话**，粘贴连接信息并点击 **加入**。加入会用主持者的地图替换当前打开的地图，所以请先保存你的工作。

标准版本可在局域网中使用，**本地网络端口** 用于设置端口。通过互联网进行的会话（**通过互联网连接**）需要启用了可选网络功能的版本。参与者可以在 3D 视图中看到彼此的相机标记和名字。

关闭窗口不会结束会话；标题栏中的指示器会显示其状态。**停止会话** 或 **离开会话** 会结束会话。当两个人编辑同一个对象时，以主持者的顺序决定最终版本，而撤销也是一次共享编辑。尽可能分区域工作，并适时保存检查点。

# 3D 显示与第二台显示器
## 显示模式
“地图”选项卡的 **视图** 区块用于切换视图中绘制的内容：笔刷、点实体、实体模型、实体类名、组轮廓、面片、材质、显示被忽略的面、预览动画、线框、边和笔刷实体轮廓。线框模式会绘制三角形的边，包括对角线和位于表面后方的边，不显示材质。这是一个临时的调试视图，不会影响导出或渲染。

3D 视图的光照、阴影、环境光遮蔽、反射、泛光和平滑设置位于 首选项 → 渲染器。这些都是预览设置；最终图像使用渲染相机自己的设置。

## 独立的 3D 窗口
视图 → 在独立窗口中显示 3D 视图 会把 3D 视图移到单独的窗口中，你可以把它放到另一台显示器上。它与主窗口共享相机、文档和工具，平面视图则占据主窗口的空间。它的菜单提供材质、实体视图和线框；“视图”子菜单，其中有显示被忽略的面、预览动画、边、组轮廓、点实体、实体模型和笔刷实体轮廓；对焦到选中对象；前视、侧视和俯视，它们会让相机绕所选内容（或相机前方的一个点）转动；按 3D 视图放置相机；全屏（`F11`）；渲染图像；以及返回主窗口。关闭该窗口会把视图重新停靠回去。

## 程序化天空
3D 视图默认开启程序化天空，可以在 首选项 → 渲染器 → 光照 中关闭。渲染相机有自己的 **程序化天空** 开关，随地图一起保存。天空、地平线和地面的颜色来自环境设置，太阳则跟随场景光照。天空没有几何体，也不会被导出。

# 渲染相机与 PNG 图像
文件 → 渲染图像 会打开渲染窗口：左侧是相机及其设置，右侧是实时预览，随着你修改设置而重绘。相机保存在 `.map` 中一个仅供编辑器使用的 Render cameras 图层里，该图层不会包含在引擎导出中。

## 放置相机
在 3D 视图中构好图，然后按 `Ctrl+Alt+0`（或 `Ctrl+Alt+Num0`），或点击 **按 3D 视图放置相机**。如果没有选中相机，会更新第一个已保存的相机；如果还没有相机，则新建一个。此操作可以撤销，并会保留输出和光照设置。**在地图中选择相机**、**从地图加载相机** 和 **将 3D 视图移到相机** 的作用方向正好相反。**在 3D 视图中显示相机框** 显示输出图像的边界，**通过 3D 视图控制相机** 让常规导航直接移动已保存的相机。

## 设置
- **相机位置**：X、Y、Z、偏航（yaw）和俯仰（pitch）。
- **输出和镜头**：**预设**（全高清、正方形、竖向）、宽度、高度、采样数、**垂直视野** 和 **远裁剪面**。
- **照明**：日光、日落或阴天，或自行设置曝光、太阳、天空、地平线和地面颜色、**程序化天空**、**阴影**、**环境光遮蔽** 和 **泛光**。
- **景深**：**启用景深**、对焦距离、清晰范围和模糊半径。**对焦到选中对象** 会对焦到相机前方所选对象的中心。

**保存相机和设置** 把表单内容存入地图；保存地图后才会写入磁盘。

## 渲染
**渲染 PNG** 会询问保存位置，然后开始渐进式渲染，预览中的画面会逐个采样地完善。采样越多效果越好，但耗时也越长。**取消渲染** 会停止渲染且不写入文件。渲染器使用编辑器的光栅化管线，而不是路径追踪。PNG 背景不透明，且不会渲染动画。渲染非常大的图像时，编辑器可能会短暂停顿。

# 首选项
文件 → 首选项（`Ctrl+,`）打开设置。更改会立即生效并自动保存。侧栏列出概览、游戏、视图、颜色、鼠标、键盘和渲染器。顶部的搜索框可以按名称或描述在任意页面中查找设置。每项改动过的设置都有单独的按钮可恢复默认值，**恢复默认值** 会重置当前页面。

## 各个页面
- **概览**：汇集常用设置：外观（面板不透明度 (%)、配色方案、布局、语言）、编辑、视图和手册。
- **游戏**：游戏、其文件位置以及你在协作中使用的名字。游戏决定写出哪种地图格式、加载哪些实体定义以及材质所在位置。游戏配置从配置文件夹中的 `games` 文件夹（Linux 和 macOS 上为 `~/.config/heron-brush/games`，Windows 上为 `%LOCALAPPDATA%\heron-brush\games`）以及应用程序旁边的 `games` 文件夹读取；安装包会把附带的配置放在后者中。如果游戏文件夹中缺少游戏配置指定的文件夹，例如 OpenArena 安装中 Quake 3 的 `baseq3`，Heron 会使用配置已知的替代文件夹（`baseoa`），否则使用其中唯一含有 `.pak` 或 `.pk3` 包的文件夹，并在**模组**下注明。在**模组**中填写的文件夹仍会挂载在其上。
- **视图**：布局、配色方案、语言、世界坐标轴、网格不透明度、漏洞检查的单元大小以及贴图锁定。
- **颜色**：视图、几何体和控制柄的颜色。
- **鼠标**：环视、平移和移动的速度与反转、飞行速度、视野、联动 2D 视图以及控制柄大小。
- **键盘**：键位方案，Heron Brush 或 Blender。
- **渲染器**：真实感着色、选择轮廓、光照、阴影、环境光遮蔽、反射、泛光和表面。

## 语言
**语言** 提供跟随系统以及所有已翻译的语言。界面会立即切换。如果手册有对应界面语言的译本，就以该语言打开，否则以英文打开。

# 插件与 MCP
## 插件
插件通过 Rhai 脚本扩展编辑器。文件 → 插件 打开“插件”窗口。**安装插件** 安装一个 `.rhai` 文件，**安装插件文件夹** 安装一个包含 `main.rhai` 的文件夹；可选的 `plugin.toml` 元数据用于描述插件及其设置。插件分为 **已启用插件** 和 **已停用插件** 两组，**启用插件** 可以开启或关闭某个插件，该设置在重启后依然有效。**重新加载插件** 会从磁盘重新读取脚本，并重置其面板中的数值。

已启用的插件还会出现在“地图”选项卡的 **插件** 区块中，显示其设置、操作按钮（**运行**）和输出。操作作用于所选内容；若未选择任何内容，则作用于全部内容，并且只算一个撤销步骤。随附的 Selection inspector 插件会显示数量统计，并提供上移和下移操作。

## MCP
协作 → 向智能体提供服务（MCP）可以让 AI 智能体或其他工具通过 Model Context Protocol 控制当前打开的编辑器。窗口会显示本地地址并提供 **复制** 按钮，**停止服务器** 用于关闭服务；服务运行期间，标题栏会显示 **MCP 已启用**。命令行选项 `--mcp` 会在无窗口的情况下运行同样的接口。客户端可以发现用于几何体、素材、属性、动画、导出和会话的工具。MCP 与编辑器插件是两种不同的接口。

# 命令行
程序名为 `heron-brush`。不带任何选项时，它会打开欢迎界面。

## 打开文件
`heron-brush map.map [entities.fgd] [materials/]` 会打开一张地图，并可选地加载实体定义和材质文件夹。用空参数可以跳过其中一项，例如 `heron-brush map.map "" materials/`。如果编辑器已在运行，地图会在其中打开；`--new-instance` 则会改为打开一个单独的窗口。

## 命令
- `--help` 或 `-h`：打印用法。`--version` 或 `-V`：打印版本。
- `--mcp`：通过标准输入输出提供 MCP 服务，不打开窗口。
- `--merge-map <base> <ours> <theirs> [<output>]`：供 git 使用的 `.map` 文件三方合并。输出默认写入 ours。冲突会被打印出来，并返回非零退出码。
- `--obj-to-map <in.obj> <out.map> [size] [thickness] [snap] [material]`：把网格转换为笔刷。size 是最长边的长度，以地图单位计（默认 256）；snap 是角点吸附的网格（0 表示不吸附）；使用 `solid` 或 `layered` 时，会生成网格方块或凸板，而不是薄楔形。
- `--render-preview <in.map> <out.png> [size]`：写出地图的 PNG 缩略图，默认 512 像素。
- `--run-script <script.rhai> <in.map> [out.map] [key=value ...]`：在全选状态下对地图运行插件脚本并写出结果（默认写回输入文件）。`key=value` 用于填写插件的设置。

# 故障排除
## 出现异常时
- 材质缺失：检查材质文件夹或材质包，以及导出的项目路径。
- 模型尺寸不对：与 64 单位高的玩家标记和导出比例进行对比。
- 渐变方向不对：检查渐变角度和面的朝向。
- 引擎场景为空：阅读导出警告，并按照目标的导入说明操作。
- 实时连接处于等待状态：检查插件是否已安装、场景是否已附加、更新是否被暂停。
- 只有线条、没有面：在“地图”选项卡的“视图”区块中关闭线框，或在 3D 窗口的菜单中选择材质或实体视图。
- 视图中的对象不见了：`Ctrl+Shift+I` 显示隐藏的对象；检查图层和视图筛选。
- 按键没有反应：先点击视图让它获得键盘焦点，再到 首选项 → 键盘 中检查键位方案。
- 编辑失败：撤销，简化几何体，并使用“地图”选项卡 **问题** 区块中的 **检查地图** 和 **检查漏洞**。
- 无法从文件管理器打开地图：它可能已被交给正在运行的编辑器；请找找那个窗口。

## 设置和备份
首选项、最近地图、星标、导出设置和插件都存放在配置文件夹中：Linux 和 macOS 上为 `~/.config/heron-brush`，Windows 上为 `%LOCALAPPDATA%\heron-brush`。自动保存的备份位于每张地图旁边的 `autosave` 文件夹中。

## 报告问题
请附上编辑器版本（帮助 → 关于）、操作系统、一张能重现问题的小地图以及准确的操作步骤。输出面板（`Ctrl+4`）通常会说明出了什么问题。在尝试之前请先保存一份副本。

## 使用本手册
在左侧目录中选择章节。`Ctrl+F` 显示目录并跳到搜索框；`Esc` 清空搜索，搜索框为空时则关闭手册。**目录** 隐藏或显示章节列表，**字号** 调整文字大小；这两项都会被记住。顶部的语言列表可以在现有译本之间切换。
