# scene_export

Engine-ready levels built from a map: geometry, collision, the optimisations and one
writer per engine. It reads the editor's `.map` text rather than sharing its types. It
began as a separate MIT-licensed project by the same author and is kept close to it, so
fixes can be carried between the two. See [the export contract](../../docs/engine-export-contract.md).

Part of [Heron Brush](../../README.md).
