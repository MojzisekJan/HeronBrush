# render_wgpu

The default 3D view: a retained wgpu renderer fed by changes from `editor_core`, with
image-based lighting, cascaded and point-light shadows, clustered lights, ambient
occlusion, screen-space reflections and temporal anti-aliasing. See
[the renderer](../../docs/renderer-wgpu.md).

Part of [Heron Brush](../../README.md).
